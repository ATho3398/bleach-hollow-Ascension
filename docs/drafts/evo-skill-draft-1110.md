## 0. 요약 (v5)
- 사용자 원문(11-11 02:3x): "그리고 특성이, 만해쓴다고 강화되는게 아냐. 특성은 한번 달면 못뺀다했잖아. 만해한다고 강화되는게 아님. / 그리고 특성 말고 진화체 능력이나 뭐 그럴듯한 이름 신설해서, 특성은 아닌데, 블록에 넣기 애매한 능력들 그쪽으로 넘기자."
- **특성은 해방해도 그대로** — 5단계(해방) 행의 특성 칸은 비어 있다(= 특성 그대로, 147장 영구). 해방 때 바뀌는 것은 **고유 능력 + 특수 블록**뿐.
- **새 묶음 '고유 능력'**(엔진 공용 이름, 표시 이름 = 종족 설정: 사신 **'고유 능력'** · 호로 **'고유 능력'** — 마스터 추천, 바꾸려면 말하기). 특성도 블록도 아닌 진화체 고유 효과(블록 생성 규칙 바꾸기, 쌓인 블록 수 비례 버프, 스택 버프, 적 디버프 스택 등). **4단계부터**.
- **단계 규칙**: 2단계 = 없음 · 3단계 = 특성만(두 종족 공통, 39장) · 4단계 = **특성 1(한 줄 상시 효과) + 고유 능력 1 + 특수 블록 1** — 셋 다 꼭 있을 필요는 없고 비면 '없음'.
- **사신**: 36종 — 3단계 7 · 4단계 28종 = 고유 능력 28 · 특수 블록 27 · 해방 강화 15 / 변경 13.
- **호로**: 36종 — 3단계 7 · 4단계 28종 = 고유 능력 28 · 특수 블록 28 · 해방 강화 15 / 변경 13.
- **사용자 엑셀 코멘트 그대로 반영**: 사신 백련(특성 = 공속 +10% · 고유 능력 = 허 블록 말고는 블록 생성 없음, 평타 n대당 1개, 쌓인 블록당 공속·공격력 +m% · 해방 = n 차감), 사신 노도(고유 능력 = 수 블록 쓸 때마다 n초 물리 치명 +m%p, 최대 k스택 · 해방 = 지속·치명 수치 ↑ + 스택당 치명 피해).
- **화상 = 걸린 적을 때리면 추가 피해(디버프)** · **독 = 지속 피해**(사용자 확정). 초안의 화상은 전부 이 정의(시간 동안 맞을 때마다 +x%), 터뜨림·지속 피해형 화상 없음.
- 해방 능력은 **레스렉시온/만해 때만**(확정, 영력 해방 때는 4단계 그대로).
- 표기: 고유 능력 효과의 n·m·k·x 는 '수치' 칸에 값이 있다(사용자 코멘트 방식). 해방 행 수치 칸은 바뀌는 값(앞 → 뒤).
- 성격(그대로): 사신 권 / 호로 조 = **평타캐** · 사신 참 / 호로 교 = **하이브리드** · 사신 귀 / 호로 탄 = **블록캐**. 사용자 예시: 예시 1 = 호로 **에스칼레라**, 예시 2 = 사신 **현음 칠성**.

## 2. 공통 규칙 (제안)
- **특수 블록**: 표시 이름은 두 종족 모두 '특수 블록' · 바 맨 오른쪽 빈 칸에 생김 · 단독(체인 안 됨) · 누적은 전투마다 0부터 · 상한·대기는 능력마다(공통 규칙 없음).
- **고유 능력**: 블록을 만들지 않고 그 자리에서 효과만(블록 생성 규칙 교체·추가형은 예외). 발동 때 작은 글자(39장 5). 런 로그에 발동 횟수.
- **화상**: 화상 = 걸린 적을 때릴 때마다 그 공격 피해 +x% 추가(디버프, 시간 지나면 풀림). 같은 적에게 다시 걸면 시간만 새로(추가 피해 % 는 큰 쪽).
- **한 판 길이(62장)**: 권장 ★ 일반 약 16초, 강적 약 33초. 구현 뒤 `npm run balance` 로 다시 맞춘다(진화체 밸런스 조정 금지 142장 — 가드 넘치면 고유 능력·특수 블록 수치만).
- **종족 구조(코드 분기 없음)**: 특성·고유 능력·특수 블록 정의는 공용 데이터(id → 조건 종류·효과 종류), 수치는 `balance.ts` provisional, 어느 진화체가 어느 것을 쓰는지·표시 이름은 종족 설정(`src/data/factions/*.json`).
