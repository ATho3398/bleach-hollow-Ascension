## 2. 공통 규칙 (제안, v1 그대로)
- **갈래가 이어진다**: 2단계 뿌리 → 3단계 속성 씨앗 → 4단계는 그 씨앗을 성격별로 키운다. **3단계 효과는 4단계에서도 유지**(덧붙임)를 제안. 종족마다 갈래가 따로다.
- **기존 특성은 그대로**: 성향 특성(20-3)·속성 특성(39장)·4단계 물공 기본 공격 블록과 특성(49장 physBlocks) 위에 고유 효과 1칸을 얹는다.
- **특수 블록 공통**: 바 맨 오른쪽 빈 칸에 생김 · 단독(체인 안 됨) · 바가 가득이면 1개 대기 · **한 전투 생성 상한 3개**(provisional) · 누적은 전투마다 0부터 · 해방 중에도 생기고 보스 봉인 대상.
- **한 판 길이(62장)**: 권장 ★ 일반 약 16초, 강적 약 33초. 조건 수치는 특수 블록이 일반 적 0~2번(대개 1번), 강적 2~3번 나오게 잡았다. 구현 뒤 `npm run balance`로 전투 시간·승률을 다시 맞춘다.
- **피해는 규칙 3 방식**: '평타 N회분'·'체인3 블록 1개분'처럼 내 공격 기준 배수.
- **종족 구조(코드 분기 없음)**: 능력 정의는 공용 데이터 파일 하나(예: `src/data/evolution/signatures.json`, 능력 id → 조건 종류·효과 종류·이름), 수치는 `balance.ts` provisional. **어느 진화체가 어느 능력을 쓰는지는 종족 설정**(`src/data/factions/*.json`의 예: `formSignatures: { "t4:fire:physical": "sig.soro" }`)이 고른다. 엔진은 조건·효과 종류만 알고 종족을 모른다 — 3번째 종족도 설정 파일 하나로 자기 능력 표를 고른다. 특수 블록 묶음 표시 이름(`specialBlockName`)은 **[미정]**.
