## 0. 요약
- 대상: `src/data/evolution/forms.json` 진화체 **36종 전부**(2단계 1 · 3단계 5 + 히든 2 · 4단계 18 + 히든 10). 두 종족이 같은 진화체를 쓰고 **이름·표시만 종족별**.
- 종류: **특수 블록 21개**, **추가 옵션 17개**(비보라·나다 2종은 둘 다 — 진화체마다 하나 이상).
- 성격(사용자 지시): 사신 권 / 호로 조(물리) = **평타캐** 9종 · 사신 참 / 호로 교(혼합) = **하이브리드** 11종 · 사신 귀 / 호로 탄(특수) = **블록캐** 8종 · 공격 타입이 갈리기 전(2·3단계) = **공통** 8종.
  - 평타캐 = 조건이 평타 횟수·평타 치명·피격·체력, 효과가 평타 강화. 블록캐 = 조건이 블록 사용·체인·바 상태, 효과가 블록 생성·바 조작·블록 위력. 하이브리드 = 한쪽으로 모아 다른 쪽을 키움(블록→평타, 평타→블록).
- 사용자 예시 2개는 그대로 넣음: 예시 1(블록 사용 → 공속 +4% 누적 → 특수 블록 → 평타 ×2) = **에스칼레라 / 천평 일격**(노멀 혼합), 예시 2(체인2 연속 3회 → 특수 블록 → 무작위 블록 5개) = **부오의 눈 / 현음 칠성**(노멀 특수).

## 1. 공통 규칙 (제안)
- **갈래가 이어진다**: 2단계(뿌리) → 3단계 속성 씨앗(물=치명·흐름, 불=화상, 흙=막기·보호막, 뇌=바 조작·체인, 노멀=누적) → 4단계는 그 씨앗을 성격(평타캐·블록캐·하이브리드)별로 키운다. **3단계 효과는 4단계에서도 유지**(덧붙임)하는 것을 제안 — 진화할수록 쌓여서 강해진다. 히든 3단계(실패·통로)는 히든 4단계로 잇는다.
- **기존 특성은 그대로**: 성향 특성(20-3)·속성 특성(39장)·4단계 물공(조·권) 기본 공격 블록과 특성(49장 physBlocks)은 건드리지 않고 그 위에 고유 효과 1칸을 얹는다.
- **특수 블록 공통**: 바 맨 오른쪽 빈 칸에 생긴다 · **단독**(체인 안 됨, 같은 특수 블록이 붙어도 하나씩) · 바가 가득이면 1개까지 대기했다가 자리가 나면 생김 · **한 전투 생성 상한 3개**(provisional) · 누적 카운터는 전투마다 0부터(3-5: 전투 간 이월 없음) · 해방 중에도 생기고, 보스 봉인 기믹의 대상이 된다.
- **한 판 길이(62장)**: 지금 권장 ★ 일반 적 약 16초, 강적 약 33초. 평타 1초 간격이면 일반 판 평타 약 15회, 피격 약 10회 — 조건 수치는 **일반 적에서 특수 블록이 0~2번(대개 1번), 강적에서 2~3번** 나오게 잡았다. 효과는 일반 판 피해량 +10~15% 정도를 노린 값이라, 구현 뒤 `npm run balance`로 전투 시간·승률(62장 가드)을 다시 맞춰야 한다.
- **피해 수치는 규칙 3 방식**: 특수 블록의 직접 피해는 '평타 N회분'·'체인3 블록 1개분'처럼 내 공격 기준 배수로 적었다(절대값 없음).
- **종족 구조**: 엔진은 조건 종류·효과 종류만 안다. 진화체별 데이터는 새 데이터 파일(예: `src/data/evolution/signatures.json` — 이름 `{hollow, shinigami}`), 수치는 `balance.ts` provisional 구역. 블록 묶음 이름(3-5의 `specialBlockName`)은 종족 설정에서 읽는다 — 표시 이름은 **[미정]**(사용자 결정).

## 4. 사용자 확인할 것
- 3단계 효과를 4단계에서 **유지(덧붙임)**할지, 4단계 효과로 **바꿀지** (초안은 유지).
- 특수 블록 한 전투 상한(초안 3개)과 바 가득일 때 대기 1개 규칙.
- 특수 블록 묶음의 종족별 표시 이름(`specialBlockName`) — [미정].
- 나다(허무형)의 '공허 블록 리스크 상승 −50%'는 전투 밖 리스크(11-4 임시값)와 닿는다 — 넣을지.
