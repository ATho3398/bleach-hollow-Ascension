## 0. 출발점 — 지금 확정된 것과 지금 코드

**사용자 말(242장)**: "슬슬 붕옥 시스템도 구현하자. 호로, 사신 투트랙 합체를 위한 시스템. 붕옥은 스토리 다 깨면 자연스럽게 나오는 거로."

**22-3 확정(v5.2)** — 그대로 둘 뼈대
- 투트랙: 한 캐릭터가 5단계에 닿으면 다른 종족 트랙이 열린다(241-0 수정 뒤에는 '해방 클리어' 때). 먹이·타일·영혼 결정은 공유, 수련권은 트랙별.
- 영혼 결정: 붕옥 전용 재화. 강적 +1 · 등급전 승리 +3 · 환생 +10. 붕옥이 열리기 전에도 쌓인다.
- 붕옥 1단계: 영혼 결정 100 → **붕옥 해방** → 두 캐릭터 전 능력치 +5%(영구).
- 붕옥 2단계: 300 + **두 트랙 모두 등급 1위** → **초월체 합체**(확인 2번, 되돌릴 수 없음).
- 합체 결과: 두 캐릭터 → 초월체 도감, 새 호로·새 사신이 1단계부터. 해방·남은 결정·도감·스토리 진행은 유지, 2단계 게이지는 0.
- 초월체 6종(유하바하·아이젠·이치고·철혈 패왕·영식 현자·균열 방랑자), 두 캐릭터 상태로 결정, 가진 것은 건너뜀 → 6번 합체하면 6종 다 모임. 보유 1종마다 +2%.

**지금 코드(이미 구현됨)**
- `src/game.ts` `hogyoku { tabOpen, tabNotice, fed, liberated, liberatedAt, fusionFed }`, `transcendentDex`, `slotLog.fusions`.
- 개방 판정 `game.ts:796` = **모든 트랙(2개)이 5단계에 닿음** → 242장에서 '스토리 전부 클리어'로 바뀌어야 함.
- 합체 막힘 이유 `FusionBlock` = tab·liberation·tracks·gauge·rank·expedition·complete.
- 화면 `src/ui/hogyokuView.ts`(게이지·합체 조건·미리보기·도감 6칸), 결정 `src/engine/transcend.ts`, 데이터 `src/data/transcendents/`.
- 즉 **해방·합체·도감은 이미 돌아간다.** 이번에 정할 것은 "어떻게 등장하고, 등장 뒤 무엇을 목표로 어떤 순서로 하게 되는가"다.

**바뀐 조건 때문에 생기는 빈틈(안을 고를 때 핵심)**
1. **스토리 클리어가 두 번째 트랙보다 먼저 올 수 있다.** 스토리 3장은 4단계(`unlockTierIndex 3`)에 열리고, 두 번째 트랙은 해방 클리어(5단계 쪽) 때 열린다. → 붕옥이 나타났는데 합체 상대가 아직 없는 기간이 생긴다.
2. **스토리 진행은 종족별로 저장된다**(`story` 종족별 키). "스토리 다 깨면" = 지금 트랙 하나의 스토리인지, 두 종족 스토리 모두인지 정해야 한다.
3. **합체 뒤 스토리 진행은 남는다.** → 등장 조건은 처음 1번만 의미가 있고, 2~6번째 합체의 '반복 동기'는 따로 있어야 한다.
4. 영혼 결정 총량: 해방 100 + 합체 300 × 6 = **1,900개**. 강적 1개씩이면 길다(지금은 환생 +10이 가장 큰 공급원).

## 안 A — "등장만 바꾸기" (22-3 그대로)

**한 줄**: 스토리 3장 보스를 깨면 붕옥이 홈에 나타나고, 나머지는 지금 구현된 22-3 흐름 그대로.

**흐름**
1. 어느 트랙이든 **자기 종족 스토리 3장 마지막 화(보스)** 클리어 → 클리어 대사 직후 붕옥 등장 컷 한 장면("모래 속에서 무언가가 빛난다…") → 홈에 붕옥 아이콘(242장 2 자리), 토스트.
2. 등장 순간 그동안 쌓인 영혼 결정 수를 처음 보여 준다("그동안 거둔 영혼 결정 n개").
3. 붕옥 화면: 1단계 해방(100) → 2단계 합체(300 + 두 트랙 1위). 두 번째 트랙이 아직 없으면 합체 조건 줄에 "다른 종족이 깨어나야 한다(해방 클리어)" 한 줄.
4. 합체 → 새 두 트랙 → 다시 결정 300 + 두 트랙을 1위까지 → 다음 합체. 6종이면 '붕옥 완성'.

**보상**: 22-3 그대로(+5%, 초월체 1종마다 +2%, 첫 초월체 영옥 10, 칭호 '붕옥 완성').
**반복성**: 합체마다 두 캐릭터를 1단계→1위까지 다시 키움. 다음 초월체를 노리는 빌드(같은 속성·히든·환생 수)가 유일한 변주.

**구현 규모: 작** — `game.ts:796` 개방 판정 교체 + 등장 컷 1개 + 합체 조건 줄 문구 1개 + 홈 아이콘 연결(코딩269가 자리 잡는 중). 세이브 구조 변화 없음(이미 열린 세이브는 그대로 열림).

**사용자가 정해야 할 것**
- '스토리 다 깸' = 지금 트랙 종족의 스토리만? 두 종족 모두?
- 이미 붕옥 탭이 열린 옛 세이브(두 트랙 5단계)는 그대로 둘지(추천: 그대로).
- 등장 컷 대사(마스터 초안 → 검토).

**약점**: 두 번째 트랙이 열리기 전에는 붕옥이 '결정 먹이는 통'일 뿐. 2~6번째 합체는 같은 일을 다섯 번 더 하는 느낌.

## 안 B — "두 이야기가 붕옥을 깨운다" (공명 단계 추가) ★ 마스터 추천

**한 줄**: 붕옥은 첫 스토리 클리어 때 **반쯤 깨어난 채** 나타나고, 두 번째 종족의 스토리까지 깨면 **완전히 깨어나 합체가 열린다.** 합체 때마다 다음에 노릴 초월체를 보여 줘 반복 목표를 만든다.

**흐름(단계)**
| 단계 | 조건 | 홈 아이콘 모습 | 할 수 있는 것 |
|---|---|---|---|
| 0. 잠든 조각 | (안 보임) | — | 영혼 결정은 계속 쌓임(지금처럼) |
| 1. **반각성** | 어느 트랙이든 자기 스토리 전부 클리어 | 금이 간 붕옥(빛 약함) | 영혼 결정 먹이기 → **붕옥 해방**(100, +5%) |
| 2. **공명** | 다른 종족 트랙도 자기 스토리 전부 클리어 | 빛나는 붕옥(두 색) | 2단계 게이지 열림(300) |
| 3. **합체 가능** | 2단계 300 + 두 트랙 등급 1위 | 맥동 | 초월체 합체(미리보기 → 확인 2번) |
| 4. 다음 합체 | 합체 뒤 새 두 트랙 | 공명 상태 유지 | 2단계 게이지 0부터 + 1위 다시 |

- 스토리가 종족별이라 **두 번째 트랙도 스토리를 한 바퀴 깨야** 붕옥이 완전히 깨어난다 → 투트랙 둘 다 '이야기를 끝낸 몸'이 되어야 합체한다는 서사가 붙는다. 스토리 진행은 합체 뒤에도 남으므로 이 조건은 **처음 한 번만**(2번째 합체부터는 결정 + 1위만).
- 각 종족 스토리 마지막 대사 뒤 짧은 컷이 1번씩: 첫째 "무언가가 금이 간 채 빛난다", 둘째 "두 영압에 붕옥이 답한다".

**화면 흐름**: 홈 붕옥 아이콘 → 붕옥 화면(지금 `hogyokuView` 그대로 쓰고 위에 단계 띠 하나 추가: 반각성 / 공명 / 합체 가능) → 왼쪽 게이지·조건, 오른쪽 초월체 도감.
- **"다음 초월체" 줄(새로 추가)**: 도감 아래에 "지금 두 캐릭터라면 → 「이치고」" 실시간 미리보기 + 아직 못 모은 초월체의 조건을 한 줄씩 공개(예 "두 캐릭터 모두 히든 진화체 → ???"). 합체 미리보기 로직(`transcend.ts`)을 그대로 불러 보여 주기만 한다.

**보상**: 22-3 그대로 + 공명 순간 영혼 결정 +30(provisional, 2단계 시작을 밀어 줌).
**반복성**: 합체마다 "다음엔 아이젠 노리자 → 둘 다 히든 진화로 키우자"처럼 **육성 방향이 바뀌는 목표**가 생긴다. 같은 일을 반복하는 게 아니라 빌드 퍼즐 6개를 푸는 구조.

**구현 규모: 중**
- `hogyoku` 에 단계 필드 1개(`stage: 'half' | 'resonant'`) 또는 '두 종족 스토리 클리어' 판정 함수 → 세이브 형식 +1, 마이그레이션(이미 열린 세이브 = 공명으로).
- 등장 컷 2개, 홈 아이콘 2가지 모양(디자인 토큰·기존 아이콘으로, 새 색 없음), 단계 띠, "다음 초월체" 줄.
- 합체 조건 `FusionBlock` 에 'resonance' 추가.

**사용자가 정해야 할 것**
- 공명 조건 = '두 종족 스토리 모두 클리어'로 할지(추천), 아니면 '두 번째 트랙 해방 클리어'처럼 더 가볍게.
- 못 모은 초월체 조건을 처음부터 공개할지 / 합체할 때마다 하나씩 공개할지(추천: 처음부터 공개 — 목표가 보여야 반복이 산다).
- 공명 보너스 결정 +30 넣을지.
- 컷 대사 2개(마스터 초안 → 검토).

## 안 C — "붕옥의 장" (엔드게임 스토리 4장 + 시련)

**한 줄**: 스토리를 다 깨면 붕옥과 함께 **4장 「붕옥」**이 열리고, 해방·합체가 **스토리 화와 시련 전투**로 진행된다.

**흐름**
1. 스토리 3장 클리어 → 붕옥 등장 + 4장 열림(두 종족 공통 줄거리, 대사만 종족별).
2. 4장 1화 「깨어나는 돌」: 영혼 결정 100을 바치면 화가 열림 → 클리어 = 붕옥 해방.
3. 4장 2~3화 「두 개의 영압」: 지금 트랙과 다른 트랙이 각각 한 화씩(두 번째 트랙 필요).
4. 4장 4화 「초월」: 300 + 두 트랙 1위면 열리는 **합체 시련** — 한 판에서 앞 절반은 호로, 뒤 절반은 사신으로 싸우는 교대 보스전 → 이기면 합체.
5. 합체 뒤 4장 4화만 다시 열림(결정·1위 재충전), 6번까지.

**보상**: 22-3 그대로 + 화 클리어 골드·영옥, 시련 첫 클리어마다 영옥.
**반복성**: 합체마다 시련 보스가 그 초월체 컨셉의 기믹으로 바뀜(6종) — 가장 '이벤트감'이 크다.

**구현 규모: 대** — 새 장 데이터·대사 2종족, 교대 전투(두 캐릭터를 한 전투에서 바꿔 쓰는 기능 = 새 전투 시스템), 초월체별 보스 기믹 6종, 승률 가드.

**사용자가 정해야 할 것**
- 교대 전투를 만들지(엔진에 없는 새 시스템 — 13장 로드맵 밖).
- 4장을 '붕옥 장'으로 둘지, 결정·1위만으로 충분한지.
- 시련 보스 6종 기믹·그림.

**약점**: 22-3의 "초월체를 직접 조작하는 플레이는 넣지 않는다(무거운 시스템 금지)"와 부딪힐 수 있다. 규모 대비 반복 가치는 B와 비슷.

## 22-3 변경 제안 (어느 안이든 공통으로 손봐야 할 곳)

1. **개방 조건 교체**: "두 트랙 모두 5단계" → "**스토리 전부 클리어**"(242장 1). 안 A·C는 어느 트랙이든 1번, 안 B는 1번(반각성) + 다른 종족 1번(공명). `game.ts:796` 판정 교체, 이미 열린 옛 세이브는 닫지 않음.
2. **'붕옥 탭' → '홈 붕옥 아이콘'**: 22-3·22-5 문구의 '둥지 붕옥 탭 / 독 더보기 [붕옥]'을 홈 아이콘(242장 2)으로. 더보기 진입은 남길지 사용자 결정.
3. **두 번째 트랙이 없을 때의 표시**: 22-3에는 이 상황이 없었다(개방 = 두 트랙 5단계였으므로). 합체 조건 줄에 "다른 종족 트랙이 필요(해방 클리어 때 열림)"를 추가.
4. **영혼 결정 공급 점검(수치 제안)**: 1,900개를 모으려면 지금 공급(강적 1·등급전 3·환생 10)으로 길다. 제안 — 스토리 화 첫 클리어 +5, 장 보스 첫 처치 +20(지금까지 쌓인 것은 붕옥 등장 때 한꺼번에 보여 줌). 또는 2회차 이후 합체 비용 300 → 200. 전부 provisional, `npm run balance` 로 확인 필요.
5. **등급 1위 조건 유지 여부**: 6번 합체 × 두 캐릭터 = 1위를 12번 찍어야 한다. 그대로 둘지, 2회차부터 '두 트랙 모두 해방 클리어 + 상위 3위'로 완화할지 사용자 결정(마스터는 처음엔 그대로 두고 플레이해 보고 판단 추천).

## 마스터 추천: 안 B

- **사용자 말과 가장 잘 맞는다**: "스토리 다 깨면 자연스럽게 나온다" + "투트랙 합체를 위한 시스템". 안 B는 첫 스토리 클리어로 붕옥이 나타나고, 두 번째 종족의 이야기까지 끝내야 합체가 열려 **투트랙이 서사적으로 하나로 묶인다**. 안 A의 빈틈(합체 상대가 없는데 붕옥만 덩그러니)을 '반각성' 단계가 자연스럽게 메운다.
- **반복의 이유가 생긴다**: "다음 초월체" 줄 하나로 2~6번째 합체가 '같은 노동'이 아니라 '다음 조건에 맞춰 키우는 빌드 퍼즐'이 된다. 이미 있는 `transcend.ts` 판정을 화면에 보여 주기만 하면 돼서 비용이 작다.
