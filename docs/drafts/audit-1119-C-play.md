### 1. 결과 화면에서 다시 켜면 진화 창이 사라짐 (높음)
- 재현: 걸음이 진화 기준(1단계 40)을 넘은 채 모험에서 귀환 → 결과 화면("몸에 변화가 일어난다…")에서 새로고침/앱 다시 켜기 → [이어하기] → 결과 화면 다시 뜸 → [둥지로].
- 기대(GDD 8-5): 둥지로 오면 진화 연출 전에 [진화] [미루기]를 묻는다.
- 실제: 방으로 바로 가고 아무것도 묻지 않는다. 세이브 = `tierIndex 0 · steps 57 · deferrals 0`(진화도 미루기도 아님). 다음 귀환 때 다시 묻는다.
- 원인 추정: `src/ui/app.ts` endExpedition 의 `afterResult = () => evolveChoiceDialog(...)` 가 메모리 콜백뿐이라, 결과 화면 복원 경로에는 이 창이 없다. 방 진입 때 `evolutionChoicePending` 을 다시 보는 곳이 없음.
- 영향: 진화가 한 원정 늦어지고, **미루기 횟수에 안 잡히는 '공짜 미루기'** — 허무형 조건(미루기 0회)을 우회할 수 있다.
- (다시 켜지 않으면 정상: 창 C01 → [미루기] = `deferrals 1`·런 로그 `tiers.deferrals` 1건 / 다음 귀환 [진화] → 길리안 진화 확인.)

### 2. 패배 결과 화면에서 다시 켜면 패배 무효 (높음)
- 재현: 원정 전투에서 체력 0 → "패배 — 가면이 깨져 쓰러짐 · [결과 보기]" 화면에서 새로고침 → [이어하기].
- 기대(GDD 6절 자동 저장 '전투 끝'): 패배가 확정돼 결과·빈사로 이어진다.
- 실제: '전투 재시작' 경로로 그 전투 직전 상태(체력 9/115, 적 가득)에서 처음부터 다시 싸운다. [결과 보기]를 누르기 전까지는 패배가 저장되지 않는 것으로 보임.
- 영향: 빈사 중 패배 = 사망(3-6)도 같은 방법으로 피할 수 있다(같은 시드라 조작을 바꾸면 결과가 바뀜). 기획 의도인지 확인 필요.

### 3. 테스트 모드 '이 몸으로'가 4단계 특성을 안 넣음 (높음 — 사용자 시험 도구)
- 재현: 테스트 → 진화체 → 사신 '공화 (히든)' 또는 호로 '나다 (히든)' → [이 몸으로] → 바로 전투 → 적 체력 8% 아래.
- 기대: 4단계 대표 특성 '소멸선'으로 일반 공격 처형(8-8, evo-impl 3절).
- 실제: 처형 없음. 세이브 `evolution.abilities = { owned: {}, equipped: [] }`, 전투 `params.abilityEffects.execute` 없음. 특성을 직접 넣으면(`evo:obliteration`) '처형!' 정상 발동(공화·나다 모두 확인).
- 같은 이유로 백련(공속 +10%)·노도·연우·니에블라·루시에르나가·천평환의 한 줄 특성도 테스트 전투에선 빠진다. 반대로 진화체를 바꿔도 이전 특성이 그대로 남는다(나다 특성이 프레네시·초월자 트랙까지 따라감).
- 영향: 사용자가 테스트 모드로 1차 구현을 확인하면 "처형이 안 된다"로 보인다.

### 4. 소로 여우불 5개 미도달 (중간 — 수치는 기록만)
- 재현: 테스트 → 호로 소로 → 바로 전투(★4 테스트 적 A), 기본 능력치.
- 실제: 여우불 수 = 2~3(만료 시각 25틱 간격 기록), 레스렉시온 중 4. 필드 상태 `stacks.fox.n` 최대 3. '5개 이상일 때 불 블록 → 화상'이 한 번도 켜지지 않음. 칩 '3'(C03).
- 기록: 평타 간격 약 0.8초 × 여우불 2.5초 = 최대 3개. C.507 사용자 "2.5초에 5스텍"과 맞지 않음 — 공격속도가 얼마일 때를 기준으로 했는지 확인 필요(보정 제안 안 함).
- 덧: 테스트 칸 기본 블록(기합 일격)은 노멀이라 불 블록 조건을 따로 맞춰야 시험 가능.
