# 진화체 고유 능력 밸런스 기준 (C.520, 2026-11-23)

- 사용자 원문(11-23): "10.진화체는 지금 구현한 애들 밸런스 맞춰놓고, 다음 짤 애들은 이 밸런스에 맞춰서 진행하자." (같은 묶음 '9. 후반 밸런스 경고' = "아직 다 안짜서 ㄱㅊ" — 탑·등급전·★5 등 후반 보류(LATE_HOLD)는 그대로)
- 기준(마스터AR provisional): 고유 능력 기여 = **강적 처치 시간 단축률**(1 − 켬 ÷ 끔). 같은 단계 진화체 **중앙값 ±10%p**, 강적 승률(켬) **중앙값 ±15%p**. 해방형은 해방 구간 포함 전체 전투, 특수 조건형(처형·스택·필드)도 같은 표.
- 이 파일 = 다음 진화체 수치를 정할 때 마스터가 쓰는 기준. 도구 `npm run balance -- --only=evoUnique`(약 70초), 가드 = `npm run balance:check` 의 '진화체 고유 능력' 구간(새 진화체는 uniques.json 에 넣으면 저절로 검사).

## 1. 재는 법 (scripts/lib/evoUniqueBalance.ts)
- 대상: `uniques.json` 에 고유 능력(ability)이 있는 4단계 진화체 × 종족 전부(retired 제외). 고유 능력 없는 칸(호로 부오·프레네시)은 켬 = 끔이라 뺀다.
- 기준 몸: 그 진화체 4단계 몸(타입·한 줄 특성·물공 블록 그대로) · 능력치 = 4단계 기준 능력치 균일(97.5, 종족값 차 뺌) · 노력치 0.
- 표준 빌드: 그 진화체 속성의 공격 특성 2개 = 그 진화체 타입 계열 + 다음 계열(예 호로 물·특수 = 물 탄 + 물 조). 노멀·허무형·속성 없는 히든 몸은 노멀 특성이 기본 블록이라 밸런스 도구 표준 '뇌 + 불'.
- 몸 2개를 같은 무게로: **해방 전 몸**(기본 해방만) · **레스렉시온/만해 몸**(아란칼화/구상화를 깬 몸). 기여·승률 = 두 몸 평균 → 해방 능력도 들어감.
- 권장 ★(4단계 = ★4) 적: 일반 24종 × 4판 · 강적 24종 × 32판 · ★4 보스(canyon-king·forest-lord) × 16판, 켬/끔 같은 시드. 사람형 봇. 기준 리스크 50(흑귀 호로화 게이지). 펫 쓰는 능력(추성)만 기준 펫 1마리(+켬일 때 2번째 칸).
- 측정 제외(가드 밖, 출력만): 능력치 높은 쪽·평균 기반 능력(사신 천평환 — 균일 기준 몸에선 0).

## 2. 4단계 기준 값 (BALANCE 157)
| 항목 | 값 |
|---|---|
| 기여(강적 처치 시간 단축) 중앙값 | **1.3%** (34칸, 사분위 0.5~4.1%) |
| 허용 범위 | **−8.7% ~ +11.3%** |
| 강적 승률(켬) 중앙값 | **95.5%** |
| 허용 범위 | **80.5% ~ 100%** |
| 참고: 끔 강적 처치 시간 | 물리 몸 약 22~28초 · 혼합 18~21초 · 특수 17~19초 |

→ **다음 진화체 수치 목표**: 기여 +1~4%(사분위 안)를 기본, 센 능력이라도 +11% 이하, 약화가 있는 능력(평타 느림·블록 제외 등)도 −8% 이상. 강적 승률은 몸(타입) 차가 크므로 물리 몸은 80%대 초중반이 정상.

## 4. 이번 보정·목표 미달
| 진화체 | 전 | 후 | 수치 |
|---|---|---|---|
| 사신 백련 | 기여 −46.5% · 강적 64% | 기여 +2.1% · 강적 83% | 평타 4 → 2대마다 블록 · 바 블록당 +3% → +6% · 만해 2 → 1대 |
| 호로 콜리브리 | 강적 80.0% (중앙값 −15.5%p) | 그대로 | **목표 미달** — 몸 차이(끔도 80%, 뇌 물리 몸). 날갯짓 1.5·2·2.5배로 3회 시도 → 80~81%(기여만 4→9%), 수치 그대로 |
| 호로 추파카브라 | 기여 −167.9% (강적 49.5초 / 끔 18.5초) | 그대로 | **목표 미달** — 몸 타입 물리(t4:blood:physical)라 '혈 블록 출현 제외'가 물공(혈) 블록을 전부 지움. 저장 100%·피해 ×1.0 = 사용자 확정값, 저장 상한 50 → 100% 는 결과 같음. 사용자 원안 혈·교 **혼합**(GDD 8-7 호로 혈 물리 → 혼합)이 아직 구현 안 됨(진화 id 종족별 분리 전) — 마스터 결정 필요 |
