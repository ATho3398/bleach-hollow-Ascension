## 3. 공통 규칙 (이 안의 제안)

- **특수 블록**: 조건이 차면 바 맨 뒤 빈 칸에 생긴다. 바가 가득이면 빈 칸이 날 때까지 기다린다(조건 진행은 멈추지 않음). 단독(체인 안 됨), 쓰면 블록 사용 1회로 센다(해방 게이지 +2, 체인 보상 없음). **바 칸 1개를 차지**하므로 들고 있는 동안 바는 7칸 — 이것이 '안 쓰고 들고 있는 비용'이다. 상한 = 동시에 들 수 있는 개수. 전투가 끝나면 사라진다(예외는 그 진화체에 적음).
- **판단 축**(진화체마다 '판단' 줄에 표시): [빈칸] 바가 빌수록 큼 · [바] 바에 있는 블록 구성에 따라 값이 바뀜 · [보유] 쌓아 둔 것이 상시 이득이라 쓰면 잃음 · [적] 적 체력·적 디버프에 따라 값이 바뀜 · [해방] 해방 중·밖 효과가 다름 · [리스크] 리스크를 주고받음(전투 밖까지 이어짐) · [이월] 다음 전투로 들고 감 · [키우기] 들고 있는 동안 커짐.
- **지킨 금지 규칙**(8-7): 맞으면 초기화·멈추면 0·연속 적중·'n초 안에' 조건 없음 / 막기·보호막·받는 피해 감소·회피 능력 없음 / 소모품 연결 없음 / 짧은 타이밍 창(반응속도) 없음. 스택은 전부 '전투 동안 유지'이고 줄어드는 것은 **내가 특수 블록이나 블록을 써서 쓸 때뿐**이다.
- **해방** = 레스렉시온/만해 때만 바뀐다(호로 폭주형 프레네시는 해방 없음 — 사용자 v6.113)(영력 해방·한정 해제는 4단계 그대로). 해방 시작 때 쌓인 값은 이어받는다(옛 초안 ① 확정). 특성은 해방해도 그대로.
- **특성**: 일반 18종 = 진화체마다 한 줄 상시 효과. 히든 = 기획서 8-6 의 히든 특성 그대로.
- 화상 = 걸린 적을 때리면 추가 피해(디버프) · 독 = 지속 피해(모았다 터뜨리기 없음) · 허 = 리스크가 높을수록 강함.

## 4. 사신 (20종)

### 현음 `t4:normal:special` · 귀(블록캐) ★추천 — 읊조려 빈 바를 채운다
- 특성: 블록 위력 +8%
- 고유 능력 「영창」: 체인2 이상을 쓸 때마다 영창 +1, 체인1을 쓰면 −1(최대 5). 영창 1당 블록 생성 간격 −4%
- 특수 블록 「현음 칠성」: 생성 = 체인2 이상 3번 사용(체인1을 쓰면 진행 −1) / 사용 = 바 빈 칸을 무작위 블록으로 채움(최대 5개), 같은 블록끼리 붙여 놓음 / 상한 1
- 판단 [빈칸]: 체인을 다 쓰고 바가 텅 빈 순간이 최고점, 바가 가득일 땐 헛방 — 바를 비우는 순서를 계획한다
- 만해(현음칠성창): 생성 3번 → 2번, 채우는 블록 = 지금 바에서 가장 많은 계열(체인3 이 쉽게 생김)

### 천평환 `t4:normal:mixed` · 참(하이브리드) — 저울 한쪽을 다른 쪽으로 옮긴다
- 특성: 평타·블록 피해 +5%
- 고유 능력 「평형」: 바에 블록이 3~5개인 동안 평타·블록 피해 +10%
- 특수 블록 「천평 저울」: 생성 = 평타 12대 + 블록 6회 사용(둘 다) / 사용 = 바 블록이 4개 이상이면 '블록 → 평타'(바 블록 2개를 녹여 1개당 다음 평타 6대 +10%), 3개 이하면 '평타 → 블록'(6초 동안 평타 2대마다 블록 1개) / 상한 1
- 판단 [바]: 바가 넘칠 때는 평타로, 빌 때는 블록으로 — 바 상태를 보고 쓰는 쪽을 고른다
- 만해(백옥천평환): 두 쪽 효과가 동시에 나감, 녹인 블록 1개당 +15%

### 연우 `t4:water:special` · 귀(블록캐) — 바 전체를 적신다
- 특성: 블록 치명타 확률 +8%p
- 고유 능력 「빗줄기」: 블록 치명이 날 때마다 빗물 +1(최대 6). 빗물 1당 블록 치명 피해 +5%
- 특수 블록 「연우」: 생성 = 수 블록 체인2 이상 2번 / 사용 = 지금 바에 있는 블록 전부 '젖음'(쓰면 치명 확정) / 상한 1
- 판단 [바]: 바가 가득일수록 이득이지만 가득이면 생성이 멈춘다 — 채워 둘지 빨리 쓸지
- 만해(청람연우): 생성 2번 → 1번, 젖은 블록 치명 피해 +30%

### 백랑파 `t4:water:mixed` · 참(하이브리드) — 물 블록이 평타 파도를 부른다
- 특성: 치명타 확률 +5%p
- 고유 능력 「물보라」: 평타 치명이 나면 다음 수 블록 피해 +15%(최대 3겹, 수 블록을 쓰면 그만큼 소모)
- 특수 블록 「백랑」: 생성 = 수 블록 4회 사용 / 사용 = 바에 있는 수 블록 1개당 평타 1대를 즉시 부름(치명 확률 +30%p). **수 블록은 소모하지 않음** / 상한 1
- 판단 [바]: 수 블록을 바에 모아 둔 순간에 쓴다 — 수 블록을 바로 쓸지, 백랑을 위해 쌓아 둘지
- 만해(백랑파천): 부르는 평타 1대 → 2대(수 블록 1개당)

### 석양홍 `t4:fire:special` · 귀(블록캐) — 노을이 화상을 키운다
- 특성: 블록 위력 +8%
- 고유 능력 「잔양」: 화상 걸린 적에게 블록이 맞으면 화상 시간 +0.5초(최대 10초)
- 특수 블록 「낙일」: 생성 = 불 블록으로 화상을 3번 걸기 / 사용 = 바의 불 블록 수만큼 '노을' — 8초 동안 블록 적중마다 화상 추가 피해 ×(1 + 0.25 × 노을) / 상한 1
- 판단 [바][적]: 화상이 걸려 있고 바에 불 블록이 많을 때 — 노을 동안 쓸 블록을 미리 모아 둔다
- 만해(석양홍운): 사용 때 바의 불 아닌 블록 2개를 불로 바꾼 뒤 노을을 셈

### 천일야장도 `t4:fire:mixed` · 참(하이브리드) — 들고 있을수록 달궈지는 칼
- 특성: 공격력 +5%
- 고유 능력 「풀무」: 화상 걸린 적을 평타로 때리면 열기 +1(최대 10). 열기 1당 평타 피해 +2%
- 특수 블록 「천일 단조」: 생성 = 불 블록 체인3 1번 / 들고 있는 동안 다른 블록을 1개 쓸 때마다 이 블록 위력 +10%(최대 +100%) / 사용 = 다음 평타 6대가 단조 일격(피해 +50% × 단조 배율, 방어 30% 무시) / 상한 1
- 판단 [키우기]: 칸을 하나 먹은 채 블록을 계속 써서 키울지, 적이 쓰러지기 전에 꺼낼지
- 만해(대야로): 단조 상한 +100% → +150%, 열기 상한 10 → 15

### 만리장 `t4:earth:special` · 귀(블록캐) — 벽돌을 쌓았다 무너뜨린다
- 특성: 블록 위력 +8%
- 고유 능력 「축성」: 흙 블록을 쓸 때마다 체인 수만큼 벽돌 +1(최대 20). 벽돌 1당 흙 블록 피해 +1%
- 특수 블록 「성벽 붕괴」: 생성 = 벽돌 10 / 사용 = 벽돌 전부 소모, 1당 흙 체인1 × 0.5 피해 + 바의 흙 블록 1개당 +10% / 상한 1
- 판단 [보유]: 벽돌 10 에 바로 쓸지, 20 까지 쌓아 큰 한 방(그동안 흙 블록 버프 유지)을 노릴지
- 만해(만리장철옹): 무너뜨린 뒤 벽돌 절반 남음

### 태산압정 `t4:earth:mixed` · 참(하이브리드) — 무게를 실었다 내려찍는다
- 특성: 평타 피해 +8%
- 고유 능력 「누름」: 흙 블록이 맞으면 무게 +체인 수(최대 10). 무게 1당 평타 피해 +3%
- 특수 블록 「태산」: 생성 = 무게 8 이상에서 흙 블록 체인3 / 사용 = 무게 전부 소모, 1당 평타 1.2회분 피해. 적 체력 30% 이하면 ×1.5 / 상한 1
- 판단 [적][보유]: 무게는 평타 버프라 들고 있는 게 이득 — 마무리(적 체력 30% 이하)에 맞춰 꺼낸다
- 만해(천근압): 내려찍은 뒤 무게 절반 남음, 마무리 기준 30% → 50%

### 섬뢰각 `t4:thunder:physical` · 권(평타캐) — 뇌 블록을 발차기로 바꾼다

- 만해(천벌섬뢰각): 연타 확정 평타에 낙뢰 추가(평타 30%)

### 운중뢰 `t4:thunder:special` · 귀(블록캐) ★추천 — 구름 속 묶음을 키운다

- 특수 블록 「무(無)」(기획서 8-8 고정 — 출현표에서 나옴, 무 강화 = 혈+독+허 강화 합): 사용 = 바의 혈·독·허 블록을 전부 삼킴, 1개당 리스크 +3 · 다음 평타 3대가 '무' 피해(평타 +40%, 상성 무시) / 상한 = 출현표 그대로
- 판단 [바][리스크]: 공화(비우기·리스크 낮춤)와 반대 — 많이 삼킬수록 평타가 길게 세지지만 리스크가 오른다
- 레스렉시온(나다): 삼킨 1개당 리스크 +3 → 0, 평타 +40% → +55%

## 7. 사용자 확인이 필요한 것

1. **추천 13종** 중 넣을 것 고르기(나머지는 특수 블록 없는 안).
2. 특수 블록이 **바 칸 1개를 차지**하는 것을 '들고 있는 비용'으로 삼아도 되는지(이 안 전체의 전제).
3. **전투를 넘어 이어지는 것**(카사도르 표식 블록·토르투가 무늬)을 허용할지 — 지금 규칙은 '전투마다 0부터'.
4. 한매 예외 — 바가 가득일 때 맨 앞 블록이 특수 블록으로 바뀌는 것.
5. 허무형 '무(無)' 블록의 사용 효과 — 기획서 8-8 은 이름·강화만 정했고 효과는 비어 있다(이 안은 공화 = 비우기, 나다 = 삼키기).
