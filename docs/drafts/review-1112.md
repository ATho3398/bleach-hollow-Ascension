## 1. 4단계 진화 때 '새 트랙'까지 같이 열린다 — 해금 표와 다름

- **분류** 고칠 점 · **심각도** 상
- **어디서** 3단계(아쥬커스)에서 모험 귀환 → 4단계(바스트로데) 진화 직후 둥지.
- **무엇이 문제**
  - 진화 직후 안내 카드가 본능 수련 2장 → 번호 쟁탈전 2장 연달아 뜨는데, 그 사이에 알림 "새 트랙 — 사신 트랙이 열렸다"가 같이 뜬다. 한 번에 세 가지가 열린다.
  - GDD 241-0 수정 표는 두 번째 트랙을 **해방 클리어(아란칼화/만해)** 줄에 두었다. 코드는 `BALANCE.provisional.twoTrack.openTierIndex: 3`(4단계 도착)이라 표보다 한 단계 빨리 열린다. `src/game.ts:845` 주석은 아직 "5단계"로 적혀 있다.
  - "진화마다 하나씩 열리는 느낌"이 4단계에서 깨진다.
- **추천 해결** 새 트랙 개방을 표대로 해방 클리어로 옮긴다(또는 표를 4단계로 고친다 — 어느 쪽인지는 사용자 결정). 알림은 안내 카드가 끝난 뒤에 띄운다.
- **캡처** `01-tier4-track-toast.png`

## 2. 해금 전인데 상점이 전투 소모품·타일 뽑기를 잠김 표시 없이 판다

- **분류** 고칠 점 · **심각도** 중
- **어디서** 1단계(튜토리얼 직후) 월드맵 → 시장 → 소모품 상점 [전투 소모품]·[타일]·[기타] 탭. 가방 → 소모품 → [전투 소모품]·[출정품].
- **무엇이 문제**
  - 타일(2단계 해금)·전투 소모품(3단계 해금)이 1단계 상점에 그대로 있다: 타일 뽑기 300 · 희귀 타일 꾸러미 60 · 타일 배치 칸 +1 400 · 용기의 물약 90 등. 잠김 줄이 없다. `src/shop.ts:271` 의 해금 판정이 장비·장신구·출정품만 본다.
  - 가방 [전투 소모품] 탭은 "비어 있다. 상점에서 사면 여기에 들어온다"만 나온다(잠김 안내 없음). [출정품] 탭은 "첫 환생 후 출정품이 열린다"와 "비어 있다. 상점에서 사면 여기에 들어온다"가 같이 나와 서로 어긋난다.
  - 상태 화면은 장비가 잠긴 1·2단계에도 "장착한 장비가 없다"로 나온다.
- **추천 해결** 상점 타일·전투 소모품 줄과 가방 전투 소모품 탭에도 같은 해금 판정·잠김 한 줄을 쓰고, 잠긴 탭에서는 "상점에서 사면…" 문구를 숨긴다.

## 3. 장비가 열려도 장비가 0개 — 안내가 글뿐이다

- **분류** 추가할 점 · **심각도** 중
- **어디서** 2단계 → 3단계(아쥬커스) 진화 직후 둥지, 이어서 가방 → 장비 탭.
- **무엇이 문제**
  - "장비가 열렸다" 3장 + "전투 소모품 칸이 열렸다" 2장, 모두 [다음]만 누르는 글 카드다. 첫 카드가 "가방의 [장비] 탭에서 가진 장비를 본다"인데 열어 보면 "장비가 없다"이다. 타일 해금은 3장을 주지만 장비 해금은 아무것도 주지 않는다.
  - 타일도 비슷하다: 둥지 4장 + 모험 준비 5장 = 9장이 모두 [다음]이다. "눌러 고르거나 끌어서 길에 놓아 보자"라고 하면서 실제로 놓게 하지는 않는다.
  - 사용자 지시("해금마다 튜토리얼", 장비 = 장비 탭·착용·강화)에 비해 직접 해 보는 단계가 없다.
- **추천 해결** 장비 해금 때 노멀 무기 1개를 주고, 가방 장비 탭 → 착용까지 따라 누르는 조작 카드로 바꾼다(타일도 한 장 놓기까지).
- **캡처** `04-phone-gear-tab-clipped.png`(빈 장비 탭)

## 4. 폰 크기(796×384)에서 화면이 잘리고 겹친다

- **분류** 고칠 점 · **심각도** 중
- **어디서** ① 3단계, 가방 → 장비 탭. ② 2단계, 월드맵 → 모험 → [타일 배치]에서 타일 하나 놓고 [저장].
- **무엇이 문제**
  - ① 오른쪽 분류 줄(전체·무기·방어구·신발·장신구·펫)의 마지막 '펫'이 오른쪽 끝에서 잘린다.
  - ② 타일 카드 '영혼 웅덩이'의 설명 끝("시간 소모")과 수량 "×1"이 겹친다. 배치 프리셋 목록은 둘째 줄이 반쯤 잘려 흰 테두리만 보인다. 맨 위 안내 줄("타일 고르기 → 빈 칸 누르기")은 제목 줄 구분선에 붙어 있다.

- **추천 해결** 분류 줄은 칸 너비를 줄이거나 가로로 넘기게 하고, 타일 카드 수량은 설명과 다른 줄로 내리고, 프리셋 목록 높이를 줄 단위로 맞춘다.

## 5. 첫 포식 화면 — 설명과 실제가 어긋나고 절반이 빈다

- **분류** 개선점 · **심각도** 중
- **어디서** 튜토리얼 각본 전투 승리 → 첫 포식(사신 = 첫 정화 흡수) 화면. 두 종족·두 크기 같음.
- **무엇이 문제**
  - 안내 카드 1/2 가 갈래 4개의 차이(블록+능력치 / 블록만 / 능력치 두 배 / 놓아주기)를 가르친 직후, 화면 문구가 "이번 첫 포식은 연습이다. 어느 갈래를 골라도 모든 능력치가 똑같이 오른다"이다. 방금 배운 선택이 의미 없다.

- **추천 해결** 연습 문구를 갈래 설명 칸 안으로 옮기고, 갈래마다 실제로 얻을 것을 미리 보여 주거나 "이번만 같다"를 안내 카드에서 먼저 말한다. 남는 자리에는 쓰러뜨린 적 그림을 둔다.

## 6. 배부름이 가득해도 먹이가 그냥 소모된다

- **분류** 개선점 · **심각도** 중
- **어디서** 튜토리얼 직후 둥지(배부름 98~100) → [먹이] → 주먹밥.
- **무엇이 문제**
  - 배부름 98 에서 주먹밥(+8)을 누르면 바로 먹는다. 세이브 확인: 주먹밥 9 → 8, 배부름 100. 알림·확인이 없어 먹이와 10분 3번 횟수를 버린다.
  - 버튼의 "먹이 2/3"이 무엇인지(10분 동안 남은 횟수) 화면 어디에도 설명이 없다.
  - 하나 먹일 때마다 먹이 목록이 닫혀, 여러 개 먹이려면 매번 다시 연다.
  - 먹이 칸에는 배부름·교감만 보이고 체력 +3% 는 안 보인다(가방 쪽 설명에는 있다).
- **추천 해결** 넘치는 만큼은 "배부름이 가득하다" 알림으로 막거나 한 번 묻고, 먹인 뒤 목록을 열어 두고, 횟수 옆에 '10분' 표시를 붙인다.

## 7. 돌봄 요청이 지금 상태와 어긋난다

- **분류** 개선점 · **심각도** 중
- **어디서** 튜토리얼 직후 둥지. ① 캐릭터를 8번 누른 뒤 잠시 기다림. ② 둥지에 2~3분 머무름.
- **무엇이 문제**
  - ① 7·8번째 터치에 "건드리지 마라. (교감 −1)"이 나온 직후, 교감 버튼에 요청 배지(!)가 뜬다. 싫다면서 쓰다듬어 달라는 꼴이다. 요청이 없을 때 [교감]을 누르면 "손 치워라. 지금은 싫다"가 나오는데, 터치를 싫어하는 대사와 같아 구별이 안 된다.
  - ② 컨디션 100·배부름 100 인데 "…졸리군. 재워라." 요청이 뜬다. `src/engine/nest.ts` `tickCareRequest` 가 상태와 무관하게 확률로 재우기/쓰다듬기를 고른다.
  - 같은 화면의 상태 설명 창 문구도 어색하다: "상태마다 지금 구간 한 줄 — 자세한 구간은 상태 화면의 ⓘ에서 본다"(개발 메모 말투), "컨디션 100 → 75~100: 공허 블록 확률 +0~4%p"(좋은지 나쁜지 알 수 없음).
- **추천 해결** 터치 횟수가 싫어하는 구간이면 쓰다듬기 요청을 미루고, 컨디션이 가득이면 재우기 요청을 내지 않는다. 설명 창 첫 줄은 플레이어 말투로 바꾼다.

- **어디서** 둥지에서 저장 → 10~11분 뒤 [이어하기].
- **무엇이 문제** "10분 만에 돌아왔다 — 비운 동안 줄어든 것: 배부름 −1" 창이 떠서 [확인]을 눌러야 둥지를 만질 수 있다. 잠깐 나갔다 올 때마다 뜬다. 21분 뒤에는 대기 보상(골드 +30 · 진화 걸음 +16)과 같이 떠서 그때는 쓸모가 있다.

## 9. 문구·표기 불일치 묶음

- **분류** 고칠 점 · **심각도** 하
- **어디서 · 무엇이 문제**
  1. 확인 창 버튼: 종족 선택은 [아니요][네], 그 밖의 공통 확인 창(`confirmDialog` 기본값 — 처음 화면으로, 상점 등)은 [아니오][예]. '아니오'는 맞춤법상 '아니요'가 맞다.
  2. 둥지에서 뒤로: 창 제목은 "처음 화면으로", 본문은 "시작 화면으로 돌아간다". 같은 화면에 이름이 둘이다.
  3. 단축키 도움말(`src/ui/shortcutMap.ts:135`): "1 / 2 / 3 = 이어하기 / 새로 시작 / 불러오기"인데, 241-A 1 로 순서가 바뀌어 실제로 2 를 누르면 불러오기가 열린다.
  4. 공격 이름 3가지: 튜토리얼 "일반 공격은 자동이다", 상태 화면 "평타 치명", C.405 이후 "기본 공격".
  5. 사신 튜토리얼 회복 안내 4/5: 제목·버튼은 '식사'인데 본문은 "먹이를 먹여 채워 주자".
  6. 상태 화면 노력치 줄: "노력치 4 / 204 (이 단계 상한 · 능력치 하나 142) · 튜토리얼 +18 상한 밖 / 초록 +n = 노력치(와 환생 계승)" — 한 번에 읽히지 않는다.
  7. 임시 이름 노출: 스킨 "망령(가칭)", 번호 쟁탈전 "보유자 A ~ J".
  8. 이름 칸 글자 수: 빈칸 "0/12" → 한글을 치면 "4/14"로 분모가 바뀐다.
  9. 접근성 라벨에 소수 노출: "상태 보기: 배부름 99.98394262699176".
- **추천 해결** 확인 창 기본값을 [아니요][네]로 통일하고, 나머지는 위 목록대로 한 번에 고친다(7번 이름은 [미정]이면 사용자 확인).

## 10. 시장 — 대장장이 안내·건물 그림·잠긴 칸 이유

- **분류** 개선점 · **심각도** 하
- **어디서** 월드맵 → 시장(1~3단계), 가방 → 장비 탭(3단계).
- **무엇이 문제**
  - 대장장이를 누르면 "대장장이는 아직 문을 열지 않았다"만 나온다. 언제 열리는지 없고, 건물도 잠긴 모양이 아니라 열린 곳처럼 보인다. 강화는 가방 장비 창([강화 +1 · 골드 30])에서 이미 되므로 대장장이가 무엇을 하는 곳인지도 알 수 없다.
  - 소모품 상점만 건물 그림이 없고 흐린 + 표시다(다른 네 곳은 건물).
  - 가방 장비 탭에서 잠긴 장신구 칸을 누르면 "잠겨 있다"만 나온다. 장비 상점·월드맵처럼 "○○ 클리어 후 열린다"가 나와야 한다(펫 칸도 같은 모양).
  - 상점 구매 창의 사는 버튼 글이 "골드 120"뿐이다. 설명 줄 "힘 또는 지능 1줄 · 노멀 · ★ = 지금 단계 권장 · 능력치 무작위 → 가방 장비 탭에서 착용"도 읽기 어렵다.
  - 상점은 "노멀 무기 / 평범한 송곳니"로 파는데 가방에서는 "노멀 무기"로만 보인다.
- **추천 해결** 대장장이는 여는 조건을 알림에 넣고 잠김 모양으로 표시하고, 소모품 상점 그림을 채우고, 잠긴 칸은 `gateHint` 문구를 그대로 쓴다.
- **캡처** `10-phone-market-smith.png`
