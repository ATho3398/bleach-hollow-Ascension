## 설계 방침

- **자원 하나 원칙**: 4단계 진화체마다 '쌓이는 값' 하나(영창·전하·균열·안개·반딧불 등)를 두고, 고유 능력 = 그 값을 쌓는 법 + 상시 효과, 특수 블록 = 그 값이 가득 찰 때 꺼내 쓰는 한 방. 읽기 쉽고 UI 게이지 1개로 표시 가능.
- **계통 = 무엇이 값을 쌓는가**: 권/조(평타 위주)는 평타 적중이 값을 쌓고 블록은 보조, 귀/탄(블록 위주)은 블록 사용·바 상태가 값을 쌓음, 참/교(혼합)는 평타↔블록 '교대'가 값을 쌓음(왕복·박자·계단·저울).
- **종족 맛**: 사신 = 수련·박자·형(型) — 만해는 '형이 바뀐다'(평타 위주·블록 위주의 손맛 자체를 바꾸는 변경형 12/28). 호로 = 포식·사냥·무리·변이 — 레스렉시온은 '본성이 풀린다'(쌓는 값 한도·속도를 푸는 강화형 16/28), 전투 밖 연결은 광기·배부름·원정 누적.
- **해방 규칙 처리**: 특성은 해방 행에서 늘 '— (그대로)'. 변경형도 쌓인 값은 이어받는다(이어받기 문구 명시). 해방 때만 생기는 블록 없음 → 해방이 풀려도 바에서 사라질 블록이 거의 없음(흑귀 허화 가면만 해방 중 빠짐).
- **리스크·기타**: 전투 밖 리스크는 히든(흑귀·정심·프레네시·칼마·아유노)과 천일야장도·추파카브라에만 — 영압 안정도 미사용. 백련·노도는 사용자 코멘트(221장) 그대로, 토르멘타는 사용자 예시 2개를 정통으로 씀. 실패형(둔도·아라포)은 [임시].
