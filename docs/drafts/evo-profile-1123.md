## 2. 맞추는 방식 · 자동 분류 규칙 (provisional)
- ① **넓이(총점)** = Σ 칸 무게 × 12칸 점수, 칸 무게 = 투자(무투자 0.2·노력치 0.25·블록 0.25·둘 다 0.3) × 콘텐츠(일반 0.5·강적 0.3·보스 0.2). 같은 단계·같은 타입 중앙값 ±10%(특성 곡선 -20%까지) — 밖 = ◆.
- ② **모양**: 같은 단계·**같은 타입**(물리·특수·혼합) 중앙값 대비 — 몸 타입 차(물리 몸 = 전투 앞쪽이 셈, 특수 몸 = 블록이 쌓이는 뒤쪽이 셈)가 모양을 덮지 않게. 곡선 특징(log 비, 콘텐츠 가중): 저점 lo = 무투자, 고점 hi = 둘 다, 노력치 이득 ev = 노력치만 − 무투자, 블록 이득 blk = 블록만 − 무투자, 같이 키움 상승 syn = (둘 다 − 무투자) − ev − blk.
- 곡선 = 특징 ÷ d(0.15)와 **방향(코사인 유사도)이 가장 가까운** 원형: 평탄 곡선(lo 1·hi -1·ev -1·blk -1·syn 0) · 노력 곡선(lo -1·hi 1·ev 2·blk 0·syn 0) · 블록 곡선(lo -1·hi 1·ev 0·blk 2·syn 0) · 동반 곡선(lo -1·hi 1·ev 0·blk 0·syn 2) · 특성 곡선(lo -1·hi -1·ev 0·blk 0·syn 0). 확신도 높음 = 유사도 ≥ 0.8 이고 중앙에서 1.5d 이상, 중간 = 0.6·0.75d, 나머지 낮음(같은 타입 중앙값 근처 — 곡선이 뚜렷하지 않음).
- 성향 = 점수(특징 ÷ 문턱)가 가장 큰 것, 1 미만이면 성향 없음. 문턱: 한방 성향 0.25 · 강적 성향 0.15 · 잡몹 성향 0.15 · 선공 성향 0.15 · 생존 성향 0.4 · 해방 성향 0.2 (log 비). 한방은 강적 승률이 중앙값보다 높으면 ×0.5, 생존은 처치 속도가 중앙값 +5% 넘으면 ×0.5. 확신도 높음 ≥ 2 · 중간 ≥ 1.4.
- ③ **바닥** = 칸마다 승률 최저선(일반 90% · 강적 50% · 보스 25%) · **천장** = 같은 단계에서 12칸 전부 1등 금지(1등 칸 ≤ 11).
- 목표 비교 가드(balanceProfile 이 있는 몸만, balance:check — 목표가 든 단계만 잼): 곡선 조건(평탄 = 저점 ≥ +5% · 둘 다 이득 ≤ 중앙값 / 노력 = 노력치 이득 ≥ +15% · 블록 이득 이상, 시간 제한 능력(timed, GDD v6.178)이면 고점 ≥ +10%도 / 블록 = 대칭 / 동반 = 상승 ≥ +10% · 둘 다 이득 ≥ +10% / 특성 = 저점·고점 ≤ -5%) · 목표 성향 점수 ≥ 1 · 넓이 · 바닥 · 천장. 곡선 null = 성향만 정한 몸. 목표가 비어 있는 몸은 C.520 중앙값 ±10%p 가드 그대로.
