## 2. 자동 분류 규칙 (provisional)
- **기준 묶음**: 모양(곡선·성향) = 같은 단계·**같은 타입**(물리·특수·혼합) 중앙값 대비 — 몸 타입 차(물리 몸은 전투 앞쪽이 세고 특수 몸은 블록이 쌓이는 뒤쪽이 셈)가 모양을 덮지 않게. 가치 총량·표 4의 숫자 = 같은 단계 전체 중앙값 대비(타입 차가 그대로 보임).
- 곡선 특징(log 비, 콘텐츠 가중 일반 0.5·강적 0.3·보스 0.2): 저점 lo = 무투자, 고점 hi = 둘 다, 노력치 이득 ev = 노력치만 − 무투자, 블록 이득 blk = 블록만 − 무투자, 같이 키움 상승 syn = (둘 다 − 무투자) − ev − blk.
- 곡선 = 특징 ÷ d(0.15)와 **방향(코사인 유사도)이 가장 가까운** 원형: 평탄 곡선(lo 1·hi -1·ev -1·blk -1·syn 0) · 노력 곡선(lo -1·hi 1·ev 2·blk 0·syn 0) · 블록 곡선(lo -1·hi 1·ev 0·blk 2·syn 0) · 동반 곡선(lo -1·hi 1·ev 0·blk 0·syn 2) · 특성 곡선(lo -1·hi -1·ev 0·blk 0·syn 0). 확신도 높음 = 유사도 ≥ 0.8 이고 중앙에서 1.5d 이상, 중간 = 0.6·0.75d, 나머지 낮음(중앙값 근처 몸 — 곡선이 뚜렷하지 않음).
- 성향 = 점수(특징 ÷ 문턱)가 가장 큰 것, 1 미만이면 성향 없음. 문턱: 한방 성향 0.25 · 강적 성향 0.15 · 잡몹 성향 0.15 · 지구전 성향 0.15 · 선공 성향 0.15 · 생존 성향 0.4 · 해방 성향 0.2 · 체인 성향 0.3 (log 비). 한방은 강적 승률이 중앙값보다 높으면 ×0.5, 생존은 처치 속도가 중앙값 +5% 넘으면 ×0.5. 확신도 높음 ≥ 2 · 중간 ≥ 1.4.
- 가치 총량 = Σ 투자 가중(무투자 0.2·노력치 0.25·블록 0.25·둘 다 0.3) × 콘텐츠 가중 × 상대 칸 값. 같은 단계 중앙값 ±15% 밖 = ◆(총량 차 큼).
- 목표 비교 가드(balanceProfile 이 있는 몸만, balance:check): 평탄 = 저점 ≥ +5% · 둘 다 이득 ≤ 중앙값 / 노력 = 노력치 이득 ≥ +15% · 블록 이득 이상 / 블록 = 대칭 / 동반 = 상승 ≥ +10% · 둘 다 이득 ≥ +10% / 특성 = 저점·고점 ≤ -5%. 목표 성향 점수 ≥ 1. 가치 총량 ±15%(특성 곡선은 특성 매력이 몫이라 총량 검사 밖). 목표가 비어 있는 몸은 C.520 중앙값 ±10%p 가드 그대로.
