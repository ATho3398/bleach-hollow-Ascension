# 진화체 능력 초안 — sonnet 안

> 초안만. 수치 전부 provisional. 같은 내용 엑셀: `블리치_진화체_능력_초안_sonnet.xlsx`

## 설계 방침

- 1. 같은 자리 진화체라도 사신과 호로가 다른 능력 — 사신은 영창·리듬·정돈(번갈아 쓰기·시간 맞추기), 호로는 포식·재생·광기(맞고 먹고 되돌려받기).
- 2. 계통 성격 고정: 권/조 = 평타 위주(공속·평타 스택), 귀/탄 = 블록 위주(생성 속도·바 정돈·특수 블록), 참/교 = 번갈아 쓰기·순서 조건.
- 3. 특수 블록은 쓰이는 곳이 한정 — 평타캐는 대부분 특수 블록 없이 자기 블록 옵션만, 블록캐·혼합 일부만 특수 블록(생성 조건은 누적·연속·체력 유지 등 섞음).
- 4. 해방 능력은 강화(수치·최대치 상향)와 변경(규칙 교체)을 반반 섞음. 해방 시작 때 쌓인 스택·보호막 이어받음, 해방이 풀리면 해방 전용 블록 사라짐, 특성은 그대로.
- 5. 리스크는 사신 = 호로화 게이지, 호로 = 광기 게이지만 사용(삭제된 수치는 쓰지 않음). 모든 수치는 provisional, 실패형(혼백·호로)은 임시.
