## 2. 공용 손잡이 (엔진 1회, 모든 진화체 공용 — 종족 분기 없음)
1. **투자 비례 출처** — 능력 규칙의 `grow.per` 에 쓸 출처 2개 추가: `effort`(그 몸 타입의 주 노력치 투자율 0~1), `blockLv`(그 진화체 속성 블록 강화·공격 특성 투자율 0~1). 값 = 기본값 × (바닥 + 기울기 × 비율).
   - 노력 곡선 = effort 비례 · 블록 곡선 = blockLv 비례 · 동반 곡선 = effort × blockLv · 평탄 곡선 = 비례 없음(기본값 크게, 고점은 캡) · 특성 곡선 = 비례 없음(크기만 낮춤).
2. **켜지는 상황** — 규칙 조건(need)에 `elapsedBelow`(전투 시작 n초 안 = 선공) 추가. 강적·보스(`elite`)·해방 중(`release`)은 이미 있음. 생존 = 보호막·회복 쪽 수치, 한방 = 치명·확률 수치로.

## 3. 조정 순서
1. 손잡이 구현 + `balanceProfiles.json` 채우기 → 실측.
2. 넓이 ◆ 몸 크기 조정(같은 단계 ±10%, 특성 −20%까지): 줄임 = 주홍장 +17 · 석양홍 +16 · 루시에르나가 +15 · 니에블라 +14 · 토르멘타 +11 · 연우 +10 / 올림 = 라나 −22 · 반석 −22 · 에스카라바호 −19 · 마르티요 −18 · 콜리브리 −15 (비보라 +12 → 특성 곡선이라 크게 줄임, 섬뢰각 −14 → 특성이라 허용).
3. 모양: 곡선별 손잡이 기울기 → 성향별 조건. 몸마다 3회 시도, 안 되면 '목표 미달'.

## 4. 측정에서 보인 문제 (조정 전 확인)
- **물리 몸은 블록에 투자하면 오히려 약해진다**: 노력치만 > 둘 다(마르티요 100/90/79 → 70/72/70, 라나·콜리브리·에스카라바호 같음). 특수 몸은 둘 다가 최고(120~135). 그래서 넓이가 타입 따라 갈림(물리 중앙 약 −7% · 특수 약 +9%). 원인(측정 방식인지 — 흡수 특성이 평타 블록 비중을 줄이는지 — 실제 규칙인지)을 먼저 확인. 실제 규칙이면 넓이 비교를 '같은 단계·같은 타입' 기준으로 바꾸고 타입 차는 후반 밸런스 보류 목록으로.
- 바닥 미달 = 프레네시·둔도(보스 0%) — 둘 다 고유 능력 없음, 2차 능력 때.
