## 1. 튜토리얼 카드 + 대기 보상 창 = 진행 막힘 (최상)
- 어디서: 방. 첫 진화 뒤 '모험 타일' 안내 카드가 떠 있는 상태에서 앱을 껐다 켜면(10분 넘게) '○분 만에 돌아왔다' 창이 위에 뜬다.
- 무엇이: [받기]·[나중에] 터치/클릭, 기기 ✓, ◀ 모두 반응 없음. 카드의 [알겠어요]·[건너뛰기]는 창 밑에 깔려 못 누름. 폰 터치·PC 마우스 둘 다 재현(같은 세이브를 lastSeenAt 만 40분 앞당겨 재현).
- 왜: 튜토리얼 입력 막기(`tutorialOverlay.ts` onGuardedEvent)는 `coverTutorials` 를 부른 창(설정·일시정지·처음 화면 확인)만 통과시키는데, 대기 보상 복귀 창(`idleView.ts`)은 안 부른다 → 창 버튼 누름을 막기가 삼킴. 다시 켜도 같은 상황이 반복될 수 있다.
- 추천: 공용 확인 창 부품이 열릴 때 늘 `coverTutorials` 를 걸게(한 번에) + 대기 보상 창은 안내 카드가 끝난 뒤 띄우기. 다른 자동 창(모험 실패 창 등)도 같이 점검.

## 2. 처음 로그인 창
- 무엇이: [게스트로 시작] → '게스트 로그인이 꺼져 있다'(Firebase `auth/admin-restricted-operation` — 실제 서버 응답, 익명 로그인 꺼짐). 창에는 '로그인 없이' 버튼이 없어 ◀ 만이 빠져나가는 길. ◀ 로 넘기면 기억하지 않아(199장 2 설계) 켤 때마다 다시 뜨고, '클라우드 로그인 없이 시작한다' 알림이 매번 화면 가운데를 4~5초 가린다.
- 왜: 로그인 안 하려는 새 사용자가 첫 화면에서 막혀 보인다.
- 추천: Firebase 콘솔 익명 로그인 켜기(사용자 할 일, 1531줄) 확인 + 창에 [로그인 없이 하기] 버튼, 고르면 기억(설정에서 다시 로그인 가능). 알림은 처음 한 번만.

## 3. 대기 보상 창 문구가 사실과 다름
- 무엇이: 배부름 99·컨디션 100인데 '배고프거나 지쳐서 덜 돌았다'. '자동 모험 0바퀴. 받은 것: 골드 +21 · 진화 걸음 +11'. [받기] 뒤 '대기 보상을 받았다' 창이 한 번 더.
- 왜: `idleShortfall` 은 activeHours < hours 면 무조건 배고픔 탓 — 실제로는 튜토리얼 빈사 시간 등이 섞여 조금 모자란 것. 0바퀴인데 보상이 있어 헷갈린다.
- 추천: 덜 돈 진짜 이유(빈사였다 등)를 적고 아주 작은 차이는 안 적기, 0바퀴 줄 빼기, 받은 뒤 창은 없애고 알림 한 줄로.

## 4. 결과 화면 요약 칸이 좁음
- 무엇이: 오른쪽 '모험 요약'이 4줄만 보이고 '▼ 더 있음'이 줄 한가운데를 덮는다. 잃은 블록·잃은 골드·잃은 먹이 같은 중요한 줄이 스크롤 아래. 왼쪽 칸은 아래가 비어 있다(폰·PC 둘 다).
- 추천: 잃은 것 줄을 위로(또는 왼쪽 칸에 '잃은 것' 한 줄), 요약 칸 높이 늘리기, '▼ 더 있음'은 줄을 덮지 않는 띠로.

## 5. 수련장 안내와 실제가 다름
- 무엇이: 튜토리얼 마지막 카드 "…수련장에서 단련하며 다시 모험을 떠나자." 월드맵 수련장엔 자물쇠가 없다. 들어가면 본능 수련 4개·아란칼화 전부 '바스트로데가 되면 열린다'(4단계).
- 추천: 안내 문구를 지금 할 수 있는 것으로(guides.json first-run-room) + 월드맵 수련장에 자물쇠·여는 조건(탑·쟁탈전과 같은 알림).

## 6. 원정 중 다시 켜면 전투가 처음부터
- 무엇이: 전투 중 앱을 다시 켜면 그 전투가 처음부터 — 적 체력 665/665 로 돌아가고 내 체력(12/115)은 그대로. 이기던 판도 처음부터, 지던 판은 다시 켜서 되풀이 가능.
- 추천: 규칙을 정해(전투 상태 저장 또는 '다시 켜면 전투 처음부터' 안내) 화면에 알림. 결정 필요.

## 7. 바퀴 끝 창 용어
- 무엇이: 호로 바퀴 끝 '이번 바퀴: 승리 3 · 흡수 2 · 먹이 1'. 다른 화면은 호로 '포식', 사신 '정화 흡수'.
- 추천: 종족 설정의 흡수 이름을 읽어 쓰기(하드코딩 금지 원칙).

## 8. 체력이 낮아도 소모품을 알려 주지 않음
- 무엇이: 사신이 3바퀴째 체력 12/115로 전투에 들어가 회복약(바퀴당 1번)을 끼운 채 쓰러짐. 소모품 칸은 작고 아무 표시가 없다.
- 추천: 체력 30% 아래에서 소모품 칸을 깜빡이거나 '회복약 쓰기' 말풍선(자동 사용은 아님).

## 9. 스토리 입구가 숨어 있음
- 무엇이: 월드맵 도전의 탑을 누르면 '스토리 1장을 깨면 열린다'. 스토리는 모험 준비 화면 왼쪽 위 '자유 모험 ▼' 드롭다운 안에만 있다.
- 추천: 잠금 알림에 '모험 → 위 메뉴 → 스토리' 길을 적거나 준비 화면에 [자유 모험][스토리] 탭을 나란히.
