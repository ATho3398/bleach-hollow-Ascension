# 진화체 능력 고르기 (사용자 11-12)
- 사신 백련: 기존안
- 사신 노도: 기존안
- 사신 봉수대: 사용자 직접 — 평타 n대당 봉화 1개, 봉화 스택당 추가 피해, 봉화 m개 쌓이면 다음 평타가 폭발로 변경(이름 마스터). 폭발 = 추가 피해 + 평타의 n% 방어 무시 피해, 바에 쌓인 화(불) 블록 1개당 n% 증가. 폭발하면 봉화 0. 해방: 폭발에 필요한 봉화 1개 줄어듦, 봉화 개당 추가 피해를 늘려 해방 전 최대 스택 총합과 같게.
- 사신 금강저: 전부 기각 — "막기로 능력 잡지 마(강적 아니면 쓸모없음), 다시 짜. 금강저는 번개 무기라 흙에 안 맞음 → 이름 바꿈"
- 사신 흙_권(옛 금강저, 이름 바꿈): 사용자 직접 — 기본 공속 n% 느림. 흙 권 블록 1개 생길 때마다 방어막 n%. 방어막 남은 수치 비례 평타 피해 증가. 흙 권 블록 사용하면 방어막 n 삭제(피해로 깎이는 게 아니라 그냥 삭제 — 혼란 방지). 해방: 방어막으로 받은 피해 저장(블록 사용으로 삭제된 방어막은 제외) → 해방 풀릴 때 그 값 비례 피해.
- 사신 주홍장: 사용자 직접 — 잃은 체력만큼 평타 피해·공속 증가. 혈 블록 사용 시 체인 수에 따라 다음 평타 피해의 n%만큼 회복. 해방 지속 2초(예외), 해방 중 체력 1 아래로 안 떨어짐, 해방 중 쌓인 혈 블록 1개당 치명 확률·치명 피해 증가(상한 뚫음).
- 사신 흑귀(호로화형): 사용자 직접 — 호로화 게이지 높을수록 셈. 해방하면 특수 블록 하나 생기고, 새로 생기는 허 블록은 특수 블록에 흡수(기존 허 블록도 전부 흡수) → 특수 블록에 허 블록 스택 쌓임, 사용하면 스택만큼 피해, 해방 끝날 때까지 안 쓰면 자동 사용.
- 사신 추성(사냥꾼): 사용자 직접 — 펫 하나 더 끼울 수 있음(2번째 펫 피해 70%). 평타마다 표식 스택(최대 10), 스택당 펫 공격력 증가. 해방: 표식 1스택당 내 치명 피해도 증가, 최대 12스택.
  - 보충(사용자): 표식 스택은 순환식 — 최대치(10, 해방 12)를 채우면 다음 공격에서 0개로 돌아감.
- 봉수대 이름(마스터): 쌓이는 것 = '봉화', 바뀐 평타 = '봉수 폭렬'. 수치(provisional): 평타 3대당 봉화 1, 봉화당 평타 추가 피해 +6%, 봉화 5개 → 다음 평타 '봉수 폭렬'(추가 피해 + 평타의 50% 방어 무시 피해, 바에 쌓인 불 블록 1개당 +10%), 폭발 뒤 봉화 0. 해방: 필요 봉화 4개, 봉화당 +7.5%(최대 총합 30% 유지).
