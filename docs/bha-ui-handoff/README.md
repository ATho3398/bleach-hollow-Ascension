# 블리치 할로우 어센션 — LCD 인게임 UI 핸드오프

> **이 파일부터 끝까지 읽고 시작할 것.** 이 폴더는 디자인 확정본이다. 게임 코드에 UI를 옮길 때 이 문서의 규칙이 기준이다.

## 0. 한 줄 요약
- 화면 크기: **LCD 640×330** (기기 844×390 안쪽). 기기 껍데기·물리 버튼(∧ ∨ ✓ <)은 범위 밖.
- 스타일 원본: `design/bha.css` 하나. 클래스는 전부 `bha-` 접두, 색·간격·글자·모션은 CSS 변수 토큰.
- 테마 2개: 루트에 `.bha-hollow`(호로) 또는 `.bha-soul`(사신) 클래스. **레이아웃은 같고 색 토큰과 이름만 바뀐다.**
- 화면 마크업: `design/screens/*.dc.html` (디자인 툴 형식 — 아래 2절 읽는 법 참고).

## 1. 폴더 구성
```
README.md                 ← 이 문서
design/bha.css            ← 토큰 + 모든 컴포넌트 스타일 (그대로 가져다 쓸 것)
design/screens/*.dc.html  ← 화면 14종 (각 파일이 theme·variant로 여러 장면을 그림)
design/sheets/Tokens.dc.html       ← 토큰 표 (현재 값 → 조정안)
design/sheets/Components.dc.html   ← 컴포넌트 시트 (블록·타일·아이템 카드, 탭, 모달, 게이지, 버튼)
design/sheets/BlockStyles.dc.html  ← 스킬 블록 확정안 구조도·글자 표·상태
design/canvas.json        ← 디자인 캔버스 배치 정보 (참고용, 구현엔 불필요)
captures/                 ← 기존 빌드 캡처 10장 + 톤 참고 1장 (0-tone-reference는 색 톤만 참고)
```
※ `.dc.html` 안의 `./bha.css` 경로는 디자인 툴 기준이다. 이 폴더에선 `design/bha.css`.

## 2. `.dc.html` 읽는 법 (실행 파일 아님 — 마크업·스타일 참고용)
- `<x-dc>` 안이 실제 화면 마크업. `<helmet>`은 폰트 링크뿐.
- `{{이름}}` = 아래 `<script data-dc-script>`의 `renderVals()`가 돌려주는 값. 거기서 테마별 이름·변형별 데이터를 계산한다.
- `<sc-if value="{{조건}}">` = 조건부 렌더, `<sc-for list="{{목록}}" as="x">` = 반복.
- `data-props`의 `theme`(hollow/soul), `variant` = 그 화면의 장면 변형.
- `support.js`는 디자인 툴 런타임이라 포함 안 됨. **게임 프레임워크의 컴포넌트로 옮겨 쓰면 된다.**
- `[n]`, `[이름]`, `[효과 한 줄]` 등 대괄호 = 실제 게임 데이터로 채울 자리 표시.

## 5. 확정 규칙 (반드시 지킬 것)
**공통**
- 글자 최소 12px. 터치 대상 44px 이상(작은 버튼·탭 36px 이상). 글자 대비 4.5:1 이상.
- 글자 크기 토큰 12/13/14/16/18. 제목 = 세리프 표시체(Noto Serif KR), 본문 = Pretendard(폰트 파일 미포함 → 없으면 Noto Sans KR).
- 모서리 6/10px. 면 = 얇은 밝은 테두리 + 안쪽 어두운 면(`.bha-panel`).
- 가장 밝은 색은 글자와 선택 상태뿐. 역할 색은 토큰만 사용(형광·순색 금지).
- `--bha-text-3`(흐린 글자)는 bg-3까지만 — bg-4 위에선 대비 미달.
- 포커스(기기 버튼 커서) = 밝은 흰 테두리, 선택 = 강조 면. 둘을 같은 색으로 쓰지 말 것.
- 캐릭터는 왼쪽을 본다. 적 자리 = 검은 실루엣. 그림은 전부 자리 표시(도트 그림이 들어옴).

**전투 (가장 중요)**
- 화면을 **필드(위 200px, `.bha-field`)** 와 **스킬창(아래 130px, `.bha-skillpanel`)** 으로 완전히 나눈다. 필드 위에 UI 패널을 띄우지 않는다.
- 필드: 위 한 줄(적 이름+칩, 속성 칩, 남은 초, [그만두기][로그][일시정지][도움말]) / 나·적 그림 / 체력 바 / 강공격 예고 띠 / 피해 숫자.
- 스킬창: 맨 윗줄 범례(+해방 중 표시) → 블록 바 8칸(왼쪽, top 46px) → 영력 해방 카드(오른쪽 128px 세로).
- 없는 것: 배속, 필살/응축 게이지, SP, "짧게 눌러 떼기" 안내문(도움말로).

**스킬 블록 = "각인 컷" 확정** (`.bha-block`, 상세는 sheets/BlockStyles)
- 어두운 칸 + 속성 색 이중 테두리. 안쪽 판 오른쪽 위를 **22px 사선으로 잘라** 그 자리에 **계열 글자 1자**(13px 세리프).
- 배치: 체인 점 = 판 왼쪽 위 / 계열 글자 = 오른쪽 위 컷 / 아이콘 30px = 사선 아래 / 약점 = 오른쪽 아래 금색 삼각형. 네 요소가 겹치지 않게 고정.
- 블록 이름은 화면에 쓰지 않고 `aria-label`(화면 낭독)로만.
- 마크업 순서: `face → pips → icon → glyph → name`.
- 계열 글자: 공격 조·탄·교 / 참·귀·권, 막기 **방**, 회복 **회**, 공허 **허**, 콤보 **콤**, 해방 **해**, 봉인 **봉**.
- 색: 공격 블록 = 속성 색(노멀은 회색 베이지), 막기·회복·공허·콤보·해방 = 고정 색. 속성 막기·속성 회복은 없다. "노멀_조" 같은 속성 접두 금지.
- 같은 속성+같은 계열이 붙으면 `.bha-chain`(체인2 금색 / 체인3 주황 `.bha-chain--3`)으로 묶고 위에 탭.

**용어**: 웨코문도, 아쥬커스, 세군도 에타파, 레스렉시온, 만해, 붕옥, 영옥(꾸밈 재화), 골드. "덱"이라는 말 금지 → "가진 타일".

## 6. 미정 / 확인 필요
- `[n]`·`[이름]` 등 자리 표시는 실제 데이터로.
- 해방 중 바에 섞이는 블록 이름을 "해방"으로 임시 지정.
- 광기·자아의 사신판 처리(현재는 두 테마 동일).
- 결과 화면 수치, 특성 이름, 이벤트 문구, 일부 가격.

## 7. 구현 권장 순서
1. `bha.css` 토큰 + 컴포넌트를 프로젝트 스타일에 들여오기(이름 유지).
2. 공통 컴포넌트: 버튼 4종, 칩, 탭, 게이지, 패널, 모달, 토스트, 알림 띠.
3. 스킬 블록(`Battle.dc.html`의 블록 마크업 + BlockStyles 시트)과 전투 필드/스킬창 분리.
4. 나머지 화면을 `screens/` 순서대로. 테마는 루트 클래스 토글로만.
