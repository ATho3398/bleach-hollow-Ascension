## 부록 A. 밸런스 설정 분리 원칙 (코드 세션 필수)
- 모든 수치는 `src/config/balance.ts` 한 곳에 둔다. 코드에 숫자를 박지 않는다.
- 수치를 바꾸면 `BALANCE_VERSION`을 올린다. 세이브 구조를 바꾸면 `SAVE_FORMAT_VERSION`을 올리고 마이그레이션한다.
