기획서 값 / 실제 값 / 이유
- 일반 적 체력 6회분, 강적 10~12회분(11) / 데이터는 그대로 `hpInMatches` 6, 11 / 실제 HP = hpInMatches × `hpMatchScale`(3.2, 임시) × 매칭 1회 데미지. 플레이어는 한 턴에 연쇄로 매칭 여러 번을 얻어 1:1이면 2~3턴에 끝나서(봇 시뮬), 일반 적이 봇 평균 5~6.5턴이 되게 맞췄다. 봇은 사람보다 빠르므로 사람은 6~8턴 목표에 근접할 것으로 본다.
- 강적 ≈ 1분 30초 / 봇 평균 8.4턴 / 사람 기준 검증은 실제 플레이 후.
- 임시값(`BALANCE.provisional.battle`): 플레이어 체력 100(실드 매칭 10회분), 실드 매칭당 10, 기술 위력 데미지 매칭 4회분, 공허 생성률 10%, 공허 데미지 2배, 공허 매칭당 리스크 +5, 최대 25턴(넘기면 패배). 적 공격력은 데이터의 `attackInMatches`(실드 매칭 N회 분량).
- 해석한 규칙(기획서에 명시 없음): "3타일 = 매칭 1회 분량"으로 환산(4매치·폭발로 딸려 나간 타일도 효과에 포함), 영력 게이지는 영력 *줄* 개수로 셈, 기술은 턴을 쓰지 않는 즉시 행동, 적의 자동 매칭은 보드만 바꾸고 효과 없이 고정 공격만 한다.

기획 세션에서 정할 것
1. **약점의 의미**: 지금은 "약점 색 타일을 매칭하면 그 매칭이 1.5배로 적을 타격한다(데미지 타일이 아닌 색도 약점이면 타격 1배×1.5)". 약점이 영력·실드·흡수일 수 있는지, 공허를 약점으로 둘지.
2. **적 턴 규칙**: 적의 자동 매칭이 효과를 갖는지(예: 적이 공허/실드를 얻는지), 적 공격 주기·패턴.
3. **기술 비용**: 기술을 쓰는 데 턴을 쓸지(현재 무료), 영력 게이지 상한.
4. **턴 한도 패배**(현재 25턴) 유지 여부, 보드가 막혔을 때 섞기 규칙.
5. 매칭 환산(3타일 = 1회, 연쇄·4매치 가산) 방식과 `hpMatchScale` 보정을 기획서에 어떻게 적을지.
6. 흡수 타일 매칭 → 흡수 게이지 환산, 공허 매칭 → 리스크 값 환산(P3 입력).

사용 모델: Sonnet (Opus 승격 없음).

### C.3 전투 규칙 보완 (GDD 3-4, 코딩2)
한 일
- **약점**: 데미지·영력·실드 3색만(`WEAKNESS_ROLES`, 적 데이터 검증도 3색으로 제한). 약점 색 매칭은 그 매칭의 효과 1.5배(데미지=피해량, 영력=게이지 증가, 실드=실드량). 예전의 "어느 색이든 타격 1.5배" 제거. 기존 적 3종 약점(데미지/실드/영력)은 이미 3색이라 데이터 변경 없음.
- **적 턴**: 자동 매칭은 보드 변화만. 공격은 플레이어 `enemyAttackEveryTurns`(임시 2)턴마다 `attackInMatches × 실드 매칭량`, 실드가 먼저 흡수. 화면에 "적 공격 N턴 후" 표시.
- **기술**: 발동하면 그 턴을 쓴다(턴 +1, 적 턴·턴 한도 검사가 이어짐). 영력 게이지 상한 = 기술 2회분(`spiritGaugeCapInSkills`).
- **턴 한도** 25 유지. 교환이 없으면 무료로 섞는다(`reshuffleBoard`: 같은 타일을 다시 배치, 즉시 매치 없고 움직일 수 있는 배치. 50회 실패 시 새 보드).
- 원정 대비로 `BattleParams`에 `riskSpawnBonus`, `damageEffectMultiplier`, `shieldEffectMultiplier`, `reshuffleEachTurn`(기본값은 효과 없음) 추가.
- 테스트 추가·수정(약점 3종, 3색 제한, 공격 주기, 기술 턴 소모, 게이지 상한, 섞기). `CLAUDE.md` 기획서 버전 v0.4로 고침.

기획서 값 / 실제 값 / 이유
- `hpMatchScale` 3.2 유지 지시 → **2.1로 조정**. 기술이 턴을 쓰고 적 공격이 2턴 주기로 느려져 봇 평균이 일반 7.8·9.1턴, 강적 15턴으로 목표(일반 5~7, 강적 8~10)를 벗어나서 3.2→2.4→2.2→2.1 로 3번 시험(지시한 2회를 1회 초과, 최종값을 정하려는 미세 조정). 결과 봇 200판: test-a 5.3턴, test-b 6.2턴, test-elite 10.1턴, 승률 100%, 턴 초과 0. `BALANCE_VERSION` 3→4.

사용 모델: Sonnet (Opus 승격 없음).

**임시로 정한 규칙 (마스터 보고용, 모두 `BALANCE.provisional`·`provisional: true`)**
1. 타일 배치: 각 길 칸(1~11) 옆에 슬롯 1개(둥지 칸 0 은 슬롯 없음). 전투·휴식 진행 중이 아닐 때 언제든, **지금 위치보다 앞쪽 칸**의 빈 슬롯에, **손에 든(원정 중 획득한) 타일만** 놓을 수 있다. 둥지 칸 선택 중에도 가능(다음 바퀴용). 한 번 놓으면 원정 동안 유지되어 **매 바퀴** 그 칸을 지날 때 발동한다.
2. 타일 = 덱: 둥지에서 덱(8장, 보유 수량 이내)을 편성하고, 보상 타일은 **덱에서 무작위(복원 추출)** 로 뽑힌다. 시작 보유량·덱은 임시 구성. 귀환하면 얻은 타일이 보유에 더해지고, 패배하면 마지막 바퀴 분을 잃는다.
3. 전투 횟수: 바퀴 기본 횟수(2/3/4)는 놓은 전투 타일이 대신하고(`야생 전투` 칸을 줄임), 전투 타일이 기본 횟수보다 많으면 그만큼 전투가 는다(“놓은 타일 수에 따라 변동”). 환경 타일 칸은 일반 적 전투 + 전투 조건 변경. 휴식 타일 칸은 전투 없음.
4. 타일 보상: 바퀴 첫 승리 1장 + 바퀴 완주 1장 + 강적(소굴·조합) 승리 시 +1장, 바퀴 합계 상한 3장(`tilesPerLap.max`). “흡수 시 1장”은 P3.
5. 허기: 칸당 +0.4, 전투당 +1, **6바퀴째는 칸당 +4**. 허기 100이면 **탈진 → 패배 처리**(마지막 바퀴 획득물 상실, 쇠약 상태). 이것이 “강제 귀환 유도”의 구현.
6. 휴식 타일: 허기 −25, 컨디션 +20, 2칸 이동 시간 소모. 전투당 컨디션 −2.
7. 바퀴 강화: 적 hp +12%·공격 +8% / 바퀴(1바퀴 기준). 5바퀴째부터 공허 생성률 +4% / 바퀴. 컨디션 0이면 공허 생성률 +15%(선형).
8. 환경 프리셋: 안개=매 턴 보드 섞임, 황무지=데미지 ×1.3, 결계=실드 ×1.5, 폐가=공허 생성률 +10%p.
9. 조합: 같은 `comboGroup` 타일 3칸 인접 → 3번째 칸에서 강적 확정(바퀴당 강적 1마리 한도 안에서). 한도를 넘으면 일반 적.
10. 둥지: 시작 허기 20·컨디션 80, 방치 시 시간당 허기 +6(상한 90), 먹이 −35, 재우기 컨디션 +30(쇠약 해소), 쓰다듬기/참백도 손질 컨디션 +8, 패배 후 컨디션 ≤15·허기 +10.
11. 전투마다 플레이어 체력은 새로 시작(원정 중 체력 이월 없음). 원정 도중 새로고침하면 그 원정은 사라진다(둥지 상태·보유는 원정 종료 때만 저장).

**임시로 정한 규칙 (마스터 보고용, 모두 `BALANCE.provisional`·`provisional: true`)**
1. 흡수 임계값 4. 전투 승리 + 흡수 게이지 ≥ 4 일 때만 흡수 화면이 뜬다(패배 전투는 불가). 연습 전투에서는 흡수 안 함(가능 여부만 표시).
2. 후보: 그 적 계통의 아직 없는 특성 중, 일반 적은 1~2개 무작위·강적은 2개. 희귀 개체는 그 계통 희귀 특성이 첫 후보로 확정. 후보가 없으면 특성 없이 흡수 효과만 얻는다.
3. 희귀 확률은 적 데이터 `rareChance`(일반 A·B 10%, 강적 25%), 조우 때 시드로 굴린다. 희귀 특성은 계통마다 1개(희귀 개체에서만).
4. 같은 특성은 한 번만(중복 불가). 슬롯 3칸 고정. 가득 차면 슬롯 하나와 교체(옛 특성은 보유에 남아 둥지에서 다시 장착) 또는 포기(특성 없이 효과만).
5. skill 이 여럿 장착되면 기술을 쓸 때마다 슬롯 순서대로 돌아가며 쓴다. 기본 기술은 skill 이 하나도 없을 때만. passive 는 데미지·영력·실드 매칭 효과에 곱(같은 역할은 곱연산). part 는 표시만.
6. 계통 보너스: 슬롯 안 같은 계통 3개 → 그 계통 skill 위력 +50%. 상극 규칙은 없다(`conflictingTried` 항상 false).
7. 흡수 효과: 허기 0으로 리셋, 리스크 + 적 hpInMatches × 0.55, 보상 타일 +1(바퀴 합계 상한 3 안에서 바퀴 완주 보상 1장은 남김).
8. 놓아주기: 리스크 −8, 안정 수치 +6. 휴식 타일: 리스크 −15. 5바퀴째부터 칸 이동마다 리스크 +(바퀴−4)×0.5. 둥지 행동(리스크/안정): 먹이 −5/+2, 재우기 −10/+3, 쓰다듬기(참백도 손질) −10/+8.
9. 한계 돌파(리스크 ≥ 100): 원정당 1번 `breakthrough` 이벤트·런 로그 기록(최고치·횟수·귀환하면 생존). 임시 페널티: 그 원정 남은 동안 공허 생성률 +0.2, 둥지 복귀 시 안정 수치 −25, 게이지는 60 아래로 가라앉는다(바로 또 돌파하지 않게). 정식 결과(폭주·진화 정체·가면 분기)는 만들지 않았다. 게이지 값은 원정 상태에 두고 귀환/패배 모두 둥지 저장값으로 합친다(패배해도 게이지는 유지).
10. 안정 수치는 둥지 0~100, 시작 50. 지금은 표시와 돌파 페널티뿐, 다른 효과 없음.
11. 원정은 둥지의 리스크·안정 수치·빌드로 시작한다.
