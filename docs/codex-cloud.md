# Codex Cloud 개발 인수인계

## 대상과 역할
- 저장소: https://github.com/ATho3398/bleach-hollow-Ascension
- 기준 브랜치: main. 클라우드 준비 문서 브랜치: codex/cloud-preparation.
- 마스터 채팅: 할로우 어센션 개발 마스터. 요구사항, 단계별 작업 지시, 완료 조건, 결과 검토를 담당한다.
- 코드 채팅: 지정된 단계 구현, 검증, 결과 보고를 담당한다.
- 확정 방향: 호로를 성장·진화시키는 육성 게임. 귀여운 펫 게임 방향으로 해석하지 않는다.
- 이번 작업 범위는 GitHub 및 클라우드 개발 준비까지다. 게임 기능 구현은 다음 작업 지시 후 시작한다.

## 기존 문서와 구현
README.md, CLAUDE.md, docs/automation.md, docs/game-design.md, docs/planning-handoff.md를 먼저 읽는다. 기존 기획서는 계속 docs/game-design.md를 기준으로 유지하고 중복 기획서를 만들지 않는다.
현재 main에는 TypeScript/Vite 기반 웹 뼈대, Vitest, 밸런스 점검 및 GitHub Pages 워크플로가 있다. 게임 내용과 1단계 상세 기획은 미정이다.

## Codex 적용 범위
- 기존 문서의 Sonnet/Opus, get_session, send_later는 이전 Claude 환경의 규칙이다. Codex에서 해당 모델이나 기능을 사용할 수 있다고 가정하지 않는다. 현재 계정의 기본 모델과 실제 제공 도구를 사용한다.
- 채팅 전달·결과 회수 가능 여부는 실제 도구 응답으로 확인한다. 자동 연동이나 알림을 설정하지 않았다면 활성화되었다고 보고하지 않는다.
- GitHub 문서와 PR을 인계 기록으로 사용한다. 코드 변경 시 기존 기획서 부록 C에 구현·검증 결과를 남긴다.
- 이번 준비 작업에서는 main 병합, 게임 배포, 게임 버전 변경을 하지 않는다. 마스터 문서 변경은 작업 브랜치에서 검토한다.

## 클라우드 환경 설정
- 환경 이름 제안: bleach-hollow-ascension
- 체크아웃 저장소: ATho3398/bleach-hollow-Ascension
- Node.js: 22 (현재 CI와 동일)
- 설치 명령: npm ci
- 필요 비밀값: 현재 package.json 기준 없음. 비밀값은 공개 저장소에 기록하지 않는다.
- 개발 서버가 필요한 경우: npm run dev -- --host 0.0.0.0
- 환경 준비 검증 순서:
  1. node --version 및 npm --version 기록
  2. npm ci
  3. npm run typecheck
  4. npm test
  5. npm run balance:check
  6. npm run build
- 위 명령을 실제 클라우드 환경에서 실행하고 결과를 확인한 뒤 환경 준비 완료로 보고한다. 문서 작성만으로 실행 환경 연결이 완료되는 것은 아니다.

## 첫 코드 채팅 지시
이 저장소의 클라우드 준비 상태를 점검하라. 위 문서를 읽고 현재 브랜치 및 커밋 SHA를 확인하라. Node 22 환경에서 설치와 네 가지 검증 명령을 실행하라. 게임 기능을 추가하거나 main에 푸시하거나 배포하지 말라. 완료 보고에는 실행 환경이 클라우드인지, 저장소/브랜치/커밋, 명령별 결과, 실패 원인, 다음 작업을 위한 준비 상태를 한국어로 적어라. 실행 도구나 저장소 접근이 없으면 추정하지 말고 필요한 사용자 조치를 구체적으로 보고하라.
