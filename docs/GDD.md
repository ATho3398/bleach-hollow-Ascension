# 호로 / 사신 키우기 — 기획서 v0.2 (Claude Code 인수인계용)

> 프로젝트 이름: 블리치 할로우 어센션 (Bleach Hollow Ascension). 변경 이력과 결정 기록은 12장.

> 이 문서는 기획 세션에서 확정된 내용만 담고 있다.
> **[미정]** 표시가 붙은 항목은 아직 결정되지 않은 것이다. 임의로 정하지 말고, 구현에 필요하면 먼저 질문할 것.
> 원작 용어 표기는 이 문서를 기준으로 통일한다 (웨코문도, 아쥬커스, 세군도 에타파 등).

---

## 0. 한 줄 정의

블리치 세계관의 **호로** 또는 **사신**을 키우는 다마고치형 로그라이크 육성 게임.
**둥지에서 돌보기 → 루프 원정 → 매치3 전투 → 흡수(빌드) → 진화·승급**을 반복한다.
호로 버전과 사신 버전은 **엔진이 완전히 동일**하고, 종족 설정 파일(faction config)로 이름·외형·규칙 일부만 바뀐다.

---

## 1. 핵심 루프

```
[둥지/대원실]  허기·컨디션·자아 관리, 타일 덱 편성, 흡수 특성 슬롯 정리
     │ 출발
[원정 = 루프]  캐릭터가 12칸 원형 길을 자동 순회. 플레이어는 지형 타일을 길 옆에 배치해 무엇을 만날지 설계
     │ 적 조우
[전투 = 매치3]  6×6 보드, 5색 타일, 턴제
     │ 승리
[흡수]  쓰러뜨린 적을 흡수할지 / 놓아줄지 선택 → 특성 획득 or 리스크 게이지 회복
     │ 바퀴 반복 … 둥지 칸에서 귀환 선택 or 패배
[둥지]  획득물 정착, 진화 판정
```

- 원정 1회 = 로그라이크 1런. 귀환하면 획득물 전부 보존.
- 패배 시 사망 없음. **"가면이 깨져 쇠약"(호로) / "영력 고갈"(사신)** 상태로 둥지 복귀, **마지막 바퀴에서 얻은 것만 잃는다.**
- 매 바퀴 둥지 칸을 지날 때 귀환 가능. "한 바퀴 더 돌까"가 핵심 리스크 결정.

## 2. 템포 (확정 수치)

### 2-1. 원정

| 항목 | 값 | 비고 |
|---|---|---|
| 루프 길이 | 12칸 (둥지 칸 1 포함) | |
| 이동 속도 | 1칸 약 5초 (전투 없는 칸) | 배속 옵션 제공 |
| 한 바퀴 | 약 2분 | 전투 3~4회 포함 |
| 기본 런 | 4바퀴 ≈ 8분 | |
| 최대 런 | 6바퀴 ≈ 12~15분 | 6바퀴째부터 허기·리스크 게이지 급상승 (강제 귀환 유도) |
| 바퀴당 전투 | 1바퀴 2회 → 2바퀴 3회 → 3바퀴 이후 4회 | 플레이어가 놓은 타일 수에 따라 변동 |
| 바퀴당 타일 획득 | 2~3장 | 전투 승리 1 + 바퀴 완주 1 + 흡수 시 1 |

바퀴별 리스크/보상 곡선:
- 1~2바퀴: 안전, 보상 적음
- 3~4바퀴: 적정. 강적 소굴 개방, 흡수 보상 상승. **대부분 여기서 귀환하도록 설계**
- 5~6바퀴: 보상 1.5~2배, 공허 타일 생성률 ↑, 리스크 게이지 ↑

### 2-2. 전투 (1판 1분 내외)

| 항목 | 값 | 비고 |
|---|---|---|
| 보드 | 6×6 | |
| 타일 색 | 5종 | 아래 3-1 참조 |
| 플레이어 턴 | 평균 6~8턴, 턴당 5~7초 | |
| 적 턴 | 즉시 처리 1~2초 | 적도 같은 보드에서 자동 매칭 → 보드가 바뀜 |
| 일반 적 체력 | **평균 매칭 6회 분량** | 플레이어 공격력 기준 자동 보정 |
| 강적 체력 | 평균 매칭 10~12회 분량 (≈1분 30초) | 바퀴당 최대 1마리 |
| 기술 게이지 | 영력 타일 매칭 3회 → 기술 1회 발동 | 전투당 기술 1~2회 리듬 |
| 특수 타일 | 4매치 → 줄 폭발, 5매치 → 해당 색 전체 제거 | 일반 매치3 문법 |
| 약점 | 적마다 약점 색 1개 (외형으로 힌트). 약점 색 매칭 1.5배 | |

**밸런스 원칙**: 적 체력·공격력은 절대값이 아니라 "매칭 N회 분량"으로 정의한다. 육성 수치가 올라도 비율이 유지되게.

### 2-3. 목표 플레이 시간
- 하루 2~3런, 20~30분
- 진화 1단계 ≈ 런 8~12회 (3~4일)
- 육성 5단계 ≈ 2~3주, 등급·히든 포함 1~2개월 콘텐츠

## 3. 전투 상세

### 3-1. 타일 5종

| 역할 | 호로 명칭 | 사신 명칭 | 효과 |
|---|---|---|---|
| 데미지 | 파괴 | 참격 | 적 체력 감소 |
| 기술 게이지 | 영력 | 영력 | 3회 매칭 시 기술 발동 가능 |
| 실드 | 가면 | 귀도(결계) | 피해 흡수 |
| 흡수 게이지 | 포식 | 정화 | 전투 후 흡수 가능 여부 결정 |
| 리스크 | 공허 | 공허 | 데미지 大, 리스크 게이지 상승. 보드에 자연 생성 |

### 3-2. 육성 → 전투 반영
- 캐릭터 스탯은 **매칭 1회당 데미지 배율**로만 반영 (손기술 = 매칭 효율, 육성 = 숫자 크기)
- 컨디션 나쁘면 시작 보드에 공허 타일 증가
- 기술 = 흡수한 특성 (슬롯에 장착된 것)

### 3-3. 등급 파트에서의 전투 변주 (해방)
- 호로: 아란칼 진입 후 **레수렉시온** 해금 → 전투당 1회, 가면 타일이 참백도 타일로 변환되는 등 보드 룰 변경
- 사신: 석관 진입 후 **만해** 해금 → 전투당 1회, 참백도 계통에 따라 보드 룰 변경
- 해방은 **새 능력이 아니라 육성에서 완성한 계통의 변주**다. 계통마다 해방 변주 규칙 1개씩만 정의. [미정] 구체 규칙

## 4. 흡수 시스템 (전투 밖, 육성의 핵심)

엔진 로직은 양쪽 동일: **승리 → 흡수/안 함 → 특성 후보 1~2개 → 슬롯 장착 → 계통 보너스**

| 항목 | 호로 | 사신 |
|---|---|---|
| 행위 이름 | 포식 | 정화 흡수 (잔류 영력을 참백도가 기억) |
| 슬롯 위치 | 본체 (초기 3칸, 진화마다 +1) | 참백도 (초기 3칸, 진화마다 +1) |
| 외형 변화 | **본체 파츠 변함** (뿔, 꼬리, 가면 무늬) | 본체 그대로. **참백도 외형**이 변함 |
| 특성 종류 | 기술 / 패시브 / 외형 파츠 | 시해 능력 / 패시브 / 참백도 파츠 |
| 계통 보너스 | 같은 계열 3회 → 계열 기술 강화 | 같은 속성 3회 → 참백도 속성 확정 |
| 흡수 안 하면 | 자아 ↑ | 영압 안정도 ↑ |
| 흡수하면 | 허기 리셋, 광기 소량 ↑ (강할수록 많이) | 허기 리셋, 호로화 소량 ↑ |

- 희귀 개체는 흡수 전 표시되고 특성 확정 등장
- 능력은 육성 1단계부터 존재한다 (호로: 본체 능력 / 사신: 시해). 레수렉시온·만해는 등급 파트에서만.
- [미정] 계통 종류와 개수, 특성 풀

## 5. 리스크 게이지

| | 호로 | 사신 |
|---|---|---|
| 이름 | 광기 | 호로화 |
| 상승 | 강한 적 흡수, 공허 타일 매칭, 5바퀴 이후 | 과도한 흡수, 공허 타일 매칭, 5바퀴 이후 |
| 한계 돌파 | 자아 상실 → 폭주 / 진화 정체 | 가면 생성 → 숨은 분기 (바이자드 계열) |
| 하락 | 놓아주기, 휴식 타일, 둥지 쓰다듬기 | 정화만 하고 흡수 안 함, 휴식 타일, 참백도 손질 |

[미정] 실제 수치, 상승·하락량, 한계값

## 6. 원정 지형 타일

| 종류 | 효과 | 호로 스킨 | 사신 스킨 |
|---|---|---|---|
| 먹잇감 둥지 | 약한 적 출현 | 떠도는 영혼, 하급 호로 | 하급 호로 출몰지 |
| 강적 소굴 | 강한 적 + 좋은 보상 | 상급 호로, 다른 메노스 | 메노스 출현 지점 |
| 환경 | 전투 조건 변경 | 안개(보드 섞임), 황무지(화력↑) | 결계(실드↑), 폐가(공허↑) |
| 휴식 | 허기·리스크 회복, 시간 소모 | 영혼 웅덩이 | 전령신기 보급소 |
| 조합 | 인접 배치 시 변형 | 둥지 3개 → 호로 무리(길리안 합체 이벤트) | 출몰지 3개 → 집단 출현 사건(진화 시험 이벤트) |

- 바퀴를 돌 때마다 길 전체가 조금씩 강해짐 (루프 히어로식 시간 경과)
- 타일은 **덱**이다. 집에서 가져갈 타일을 고르고, 원정 중 획득한 타일만 배치 가능
- 사냥터: 호로 = 웨코문도, 사신 = 현세 순찰 구역 / 루콘가이
- 적 테이블은 양쪽 공유 (어느 쪽이 적으로 뜨는지만 다름)

## 8. 단계·등급 체계 (확정)

### 8-1. 육성 5단계 (진화 시스템)

| 순서 | 호로 | 사신 |
|---|---|---|
| 1 | 호로 | 혼백 |
| 2 | 길리안 | 영술원 학생 |
| 3 | 아쥬커스 | 견습 대원 |
| 4 | 바스트로데 | 평대원 |
| 5 | 아란칼 | 수석 대원 |

- 길리안·아쥬커스·바스트로데는 모두 **메노스 그란데** 안의 단계다.
- 5단계 도달 = 1차 해방 완성 (레수렉시온 / 만해 해금은 등급 파트 진입 후)
- [미정] 각 단계 진화 조건 (흡수 횟수·계통·게이지·이벤트 형태)

### 8-2. 등급 4단계 (별도 시스템, 육성과 다른 구조로 구현)

| 순서 | 호로 | 사신 |
|---|---|---|
| 1 | 에스파다 No.10 | 석관 |
| 2 | 에스파다 No.7 | 부대장 |
| 3 | 에스파다 No.4 | 대장 대행 |
| 4 | 에스파다 No.1 | 대장 |

- 호로: 현 보유자에게 **도전해서 번호를 뺏는** 약육강식 구조. 지면 하락 가능
- 사신: 조건 충족형 **승진**. 한번 올라가면 하락 없음
- [미정] 등급전 실제 룰, 전투 형태 (도전 선언 → 준비 → 결전 구조 검토 중)

### 8-3. 특별 해금 등급 (히든, 조건 비공개)

| 호로 | 사신 |
|---|---|
| 에스파다 0번 | 총대장 |
| 웨코문도의 왕 | 0번대 |
| 에스파다 No.100 | 대귀도장 |

### 8-4. 특별 태그 (등급과 공존 가능, 히든)

| 호로 | 사신 |
|---|---|
| 최초의 호로 | 은밀기동대장 |
| 모든 것을 먹은 자 | 기술개발국장 |
| 세군도 에타파 | 켄파치 |

- 히든 항목은 등급 트리에 안 보이고 **달성 시에만 공개**되는 도감 칸(물음표)으로 표시
- [미정] 모든 히든 조건. 단, 조건이 "플레이 기록 기반"이 될 것이므로 **런 로그 설계는 지금부터 필요** (9장 참조)

## 9. 런 로그 (히든 조건용, 처음부터 기록)

구현 초기부터 아래 데이터를 영구 저장할 것:
- 흡수 이력: 적 종족, 계통, 횟수, 희귀 여부
- 계통 완성 이력, 상극 조합 시도 여부
- 리스크 게이지 최고치, 한계 돌파 횟수, 돌파 후 생존 여부
- 전투별: 턴 수, 타일 종류별 매칭 비율, 승패, 사용 기술
- 단계 스킵 여부, 특정 단계에 머문 채 격파한 적 등급
- 등급 변동 이력 (획득·상실·재획득)
- 런별: 바퀴 수, 귀환/패배, 획득·상실 목록

## 10. 구현 구조 (권장)

> v0.2: 폴더는 `src/engine/`, `src/data/` 아래에 둔다(12장). 구조와 규칙은 아래 그대로.

```
engine/              루프, 매치3, 흡수, 리스크, 진화 판정, 런 로그 — 종족 무관 공통 로직
data/
  factions/
    hollow.json      티어명, 타일명, 리스크 게이지명, 슬롯 위치=body, 외형변화=true, 등급 방식=challenge
    shinigami.json   티어명, 타일명, 리스크 게이지명, 슬롯 위치=zanpakuto, 외형변화=false, 등급 방식=promotion
  enemies/           양쪽 공유 적 테이블
  traits/            흡수 특성 (표현 텍스트만 faction별 분리)
  tiles/             지형 타일 (faction별 스킨)
  titles/            등급·히든 등급·특별 태그 정의 + 조건 슬롯(조건은 미정, 구조만)
```

- **"이 요소는 엔진인가, 종족 설정인가"**를 항상 구분해서 구현. 종족별 분기가 코드에 하드코딩되면 안 됨.
