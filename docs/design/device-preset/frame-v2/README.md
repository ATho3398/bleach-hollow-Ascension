# 기기 그림 규격 v2 — 그림 만들 때 보는 문서 (UI 묶음 스티커)

> **`layout-guide.png`(UI 묶음 스티커) 한 장만 그림에 그대로 붙이면, 나머지는 전부 자유입니다.**
> 기기 크기·모양(하트·동그라미·비대칭…)·재질·고리·뒷면은 마음대로. 스티커를 그림 어디에 붙였는지만 알려 주세요.

## 스티커에 든 것 (고정)
스티커는 **실제 ×3 크기(2430 × 1080 픽셀), 투명 배경**입니다. 크기를 줄이거나 늘리지 말고 **그대로(1:1)** 그림 위에 얹습니다.
- **파랑 = 화면 구멍**: 1938 × 1080, 안은 **완전 투명**으로 비웁니다(모서리는 반지름 33 정도로 둥글어도 됨).
- **빨강 = 버튼 4개 자리**: 위 · 아래(지름 156) · 확정(지름 192) · 뒤로(지름 132). 구멍과의 거리·위치가 정해져 있으니 스티커 위치 그대로 두세요. 버튼 모양은 이 원 안에 그립니다.
- **보라 = 구멍 둘레 72픽셀**: 여기는 **몸체(그림)가 있어야** 합니다. 버튼 4개 자리도 몸체 위여야 합니다(허공에 뜨면 안 됨).

## 자유인 것 (전부)
- **그림 크기**: 가로·세로 아무 값(한 변 **약 4000픽셀까지**). 스티커보다 훨씬 커도 됩니다.
- **기기 모양**: 직사각형일 필요 없음. 하트, 동그라미, 가면, 비대칭 아무거나. 몸체 밖은 투명.
- **스티커를 붙일 자리**: 그림 안 어디든(가운데가 아니어도 됨). 정한 뒤 **구멍 왼쪽 위 모서리의 픽셀 좌표 (x, y)** 만 알려 주세요 → 게임 데이터 `hole: [x, y]`.
- **고리 구멍**: 그림 안 아무 데나. 중심 좌표(픽셀)를 알려 주세요.
- **재질·색·문양·화면 테두리·버튼 그림**.
- **뒷면**: 앞면을 좌우로 뒤집은 모양, 같은 크기. 가운데 기록 판 자리는 비워 둡니다. (옆면 두께 그림은 선택)

`example-round.png`, `example-heart.png`, `example-wide.png` 는 모양이 달라도 된다는 **예시**(축소 그림)입니다. 파랑 칸이 구멍, 빨강이 버튼, 주황이 고리.

## 게임에서 이렇게 보입니다
- **평소 화면**: 스티커(구멍·버튼)가 지금 기본 화면과 **똑같은 크기·같은 자리**에 놓입니다. 그림이 화면보다 크면 바깥은 잘리고, 기기 모양이 없는 곳은 배경이 보입니다.
- **다마고치 모드(줌아웃)**: 기기 **전체 모양**이 보이고, 뒤집을 때 두께와 키링도 그 모양을 따릅니다.

## 다 그린 뒤 검사
```
python3 docs/design/device-preset/frame-v2/check-device.py 앞면.png 뒷면.png --hole 구멍X,구멍Y --ring 고리X,고리Y
```
좌표는 모두 그림 **픽셀**입니다. `--hole`을 안 적으면 그림에서 투명 구멍을 찾아 씁니다. 틀리면 **어디가 몇 픽셀** 틀렸는지 알려 줍니다(예: "화면 구멍 아래쪽이 375px 작음: y 1523~1897 가 불투명 → 투명이어야 함", "구멍 위쪽 테두리 72px 에 몸체가 없는 곳: …"). 다 맞으면 `items.json`에 넣을 한 줄(`frame: "v2"`, `hole`, `ring` %)도 출력합니다.

## 숫자 근거
기본형(CSS 기기)의 평소 화면을 가로 844×390에서 재서 뽑은 값입니다(LCD 646×360 → ×3 = 1938×1080). 전체 값은 `preset.json`, 기획서 33장·33-2.

## 파일
- `layout-guide.png` UI 묶음 스티커(실제 크기)
- `example-*.png` 예시 모양
- `preset.json` 모든 숫자(기준과 ×3)

- `make-guide.py` 위 파일들을 다시 만드는 스크립트
