# 기기 그림 규격 v2 — 그림 만들 때 보는 문서

> 지금 게임 화면(기본형)의 크기와 자리를 그대로 뽑은 규격입니다. 이 규격에 맞게 그리면, 그 기기를 입어도 **평소 화면이 기본형과 똑같은 크기·같은 자리**로 보입니다.
> (옛 규격 `frame-v1`은 사신대행증 그림에만 쓰이고, 새 그림은 모두 이 v2로 만듭니다.)

## 한눈에 보기
`layout-guide.png`를 그림 프로그램에서 **맨 위 레이어**로 깔고 그 위에 그리세요. 색깔 표시:
- **파랑 = 화면 구멍** (완전 투명으로 비워 둘 곳)
- **빨강 = 버튼 4개 자리** (위 · 아래 · 확정 · 뒤로)
- **초록 = 평소 화면에 보이는 범위**
- **보라 = 구멍 둘레 안전 여백** (몸체가 있어야 하는 곳)
- **주황 = 고리 예시** (어디든 괜찮음)

## 그림 크기
**가로 896 : 세로 442** 비율의 정수배로 만듭니다. 추천은 **×3 = 2688 × 1326 픽셀**(×2 = 1792×884, ×4 = 3584×1768도 됨). 앞면·뒷면 크기가 같아야 합니다. 투명 배경 PNG(또는 WebP).

아래 숫자는 ×1 기준입니다. **×3으로 그릴 때는 모두 3을 곱하세요**(예: 화면 구멍 왼쪽 위 (125, 41) → (375, 123)). 왼쪽 위 모서리가 (0, 0)입니다.

| 무엇 | 위치(왼쪽 위) | 크기 | 비고 |
| --- | --- | --- | --- |
| 화면 구멍 | x 125 · y 41 | 646 × 360 | **완전 투명**. 모서리는 반지름 11 정도로 둥글어도 됨 |
| ∧ 위 버튼 | 가운데 (72, 187) | 지름 52 | 누름 영역. 그림 위에 버튼 모양을 그려 두세요 |
| ∨ 아래 버튼 | 가운데 (72, 255) | 지름 52 | 위 버튼과 같은 세로줄 |
| ✓ 확정 버튼 | 가운데 (824, 191) | 지름 64 | 가장 큼 |
| < 뒤로 버튼 | 가운데 (824, 261) | 지름 44 | 가장 작음, 확정 바로 아래 |

버튼은 **몸체 위에** 있어야 합니다(허공에 떠 있으면 안 됨). 버튼 그림 크기는 위 지름 안에 맞추세요.

## 자유인 곳
- **몸체 바깥 모양**: 평소 화면 범위(초록) 바깥의 **둘레 26 픽셀**은 마음대로입니다. 장식이 튀어나와도 되고 모서리가 둥글어도(권장 반지름 48) 됩니다. 이 둘레는 평소 화면에서는 안 보이고, **다마고치 모드(줌아웃)에서만** 보입니다.
- **재질·색·문양·화면 테두리 모양·버튼 모양**.
- **고리 구멍 위치**: 그림 안 아무 데나. 정한 뒤 **중심 좌표 (x, y)** 를 알려 주세요(검사기가 계산해 줍니다). 키링이 여기에 매달립니다.
- **뒷면**: 앞면 모양을 좌우로 뒤집은 것, 같은 크기. 가운데 기록 판 자리는 비워 둡니다.

## 다 그린 뒤 검사
```
python3 docs/design/device-preset/frame-v2/check-device.py 앞면.png 뒷면.png --ring 고리X,고리Y
```
고리 X,Y는 앞면 그림의 **픽셀** 좌표(예: ×3 그림에서 고리가 (180, 42)이면 `--ring 180,42`). 틀린 곳이 있으면 "화면 구멍 위쪽이 27px 더 큼: y 818~844가 투명 → 불투명이어야 함"처럼 **어디가 몇 픽셀** 틀렸는지 알려 줍니다. 다 맞으면 `items.json`에 넣을 한 줄(`frame: "v2"`, 고리 %)도 알려 줍니다.

## 이 숫자는 어디서 왔나
기본형(CSS 기기)의 평소 화면을 가로 844×390에서 재서 뽑은 값입니다(세로 폰의 회전 출력·PC 배율에서도 같은 비율). 전체 값은 `preset.json`, 기획서 33장.
- 옛 규격(v1)과 다른 점: 구멍이 844:390이 아니라 **646:360**(지금 게임 화면 그대로), 그림 크기·버튼 자리·크기가 모두 바뀜.
- 게임은 이 규격의 그림을 **확대·축소 없이 기본형 몸체 자리에 그대로** 놓습니다.
