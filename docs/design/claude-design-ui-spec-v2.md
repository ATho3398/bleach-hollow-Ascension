## 왜 구형이 나왔나 (옛 `claude-design-prompts.md` ② 와 달라진 점)
- 옛 명세는 **세로 풀화면(543px 폭)** 으로 읽히기 쉬웠다. 실제 게임은 **가로 844×390 기기 안 LCD(약 640×330) 한 장면**이다(세로 폰에서는 화면 전체가 시계 방향 90° 회전돼 보임 — 디자인은 가로 기준으로만).
- 옛 명세에 있던 것 중 **지금 게임에 없는 것**: 배속(1x/2x/4x) 버튼, 필살·응축 일격·저장 게이지, SP, 덱(타일 덱·덱 칸), 칭호 창문 물건, 상점의 골드/영옥 탭 토글, 블록 이름 "속성_계열"(노말_조 등), 블록 등급별 아이콘, 속성 막기·속성 회복.
- 새로 생긴 것: 영력 해방 카드(레스렉시온/만해), 블록 아이콘=계열 모양, 타일 카드·끌어놓기·배치 프리셋, 카테고리 탭+카드 상점, 상품 구매 창, 보관함 카테고리, 광기·자아 설명 패널, 떠돌이 상인, 대기 모드 요약.

## 프롬프트 (그대로 복사해서 캡처 10장과 함께 넣기)

```
모바일 웹 게임 「블리치 할로우 어센션」의 "LCD 화면 안쪽" 인게임 UI를 최신 상태 그대로 디자인해 줘.
첨부한 캡처 10장은 지금 실제로 돌아가는 최신 빌드 화면이다. 캡처가 기준이고, 아래 글과 캡처가 다르면 캡처가 맞다. 캡처에 없는 요소를 만들어 넣지 마. 기기 껍데기·물리 버튼(∧ ∨ ✓ <)은 범위가 아니다.

[게임 한 줄]
블리치 세계관의 호로 또는 사신을 키우는 다마고치형 로그라이크. 방에서 돌보기 → 원정(타일을 길에 놓고 자동으로 걷기) → 실시간 자동 전투 + 블록 눌러 쓰기 → 이기면 포식(또는 놓아주기)으로 특성 얻기 → 진화. 호로판과 사신판은 같은 화면에 색 토큰과 이름만 다르다.

[캔버스 규칙 — 반드시]
- 아트보드는 가로 640×330 (기기 844×390 안의 LCD). 세로 폰용 풀화면·세로 스크롤 화면·543px 폭 화면은 만들지 마. 한 장면은 한 아트보드. 긴 목록은 아트보드 안에서 영역 스크롤.
- 글자 최소 12px, 터치 대상 44px 이상(작은 버튼은 36px 이상), 대비 4.5:1 이상. 외부 라이브러리 없이 HTML/CSS만, 클래스는 bha- 로 시작, 색·간격·글자는 CSS 변수 토큰으로.
- 컬러 도트 LCD 풍, 어두운 바탕. 캐릭터·적·방·사냥터 그림은 자리만(도트 그림이 들어옴). 캐릭터는 왼쪽을 보고, 적 자리에는 검은 실루엣.
- 토큰(지금 값 그대로 쓰고 새 색을 만들지 마): 바탕 #0b0909 #141010 #1c1716 #26201e, 선 #2f2725 #4a3d39, 글자 #efe7da #bdb1a2, 강조(호로 붉은색) #c8303f/#ff5a6a, 공격 #e5484d, 막기 #2fb36b, 회복 #3e8bff, 광기(리스크) #ff4fd8, 약점 #e8c15a, 체인3 #ff8a3d, 희귀 #ffd24d, 위험 #ff6b6b, 삽입 파랑 #6cc4ff, 봉인 보라 #a371f7. 모서리 6/10px. 글자 12/13/14/16/18px. 제목 글꼴은 세리프 계열 표시체, 본문은 Pretendard.
- 두 테마: 호로(뼈·모래·붉은 영압, 웨코문도) / 사신(먹물·흰 하오리·푸른 영압, 소울 소사이어티). 같은 레이아웃, 색 토큰·이름만 바뀐다. 모든 화면을 두 버전으로.
- 용어는 이대로: 웨코문도, 아쥬커스, 세군도 에타파, 레스렉시온, 만해, 붕옥, 영옥(꾸밈 재화), 골드, 광기(호로)·자아, 포식(호로)·놓아주기. 사신판 계열 이름은 참·권·귀, 호로판은 조·탄·교.

[1. 방(둥지)] 캡처 1
- 방 배경 한 장 + 가운데 캐릭터 + 방 물건 5개: 문(라벨 "모험"), 수련장, 책장, 보관함, 상점. 물건마다 아래에 작은 이름표. 물건 크기는 큼직하게(캐릭터와 비슷).
- 캐릭터 머리 위 작은 상태 칩(허기·컨디션·광기 3줄 게이지) — 누르면 상태 화면. 말풍선 한 줄.
- 맨 위 가운데에 얇은 알림 띠(업적·튜토리얼·상인 도착 등, 최대 2줄).
- 맨 아래 독 한 줄: [먹이 주기] [재우기] [교감] 큰 버튼 3개 + 오른쪽 작은 [⋯ 더보기]. 더보기 메뉴 항목 순서: 번호 쟁탈전/석차 도전, 설정, 도움말, 튜토리얼, 붕옥(해금 후에만), 사진, 다마고치 모드, 테스트(테스트 모드에서만), 백업·불러오기, 처음 화면.
- 덱·칭호 창문·골드/영옥 표시 줄은 방에 없다.

[2. 전투] 캡처 2·3  ← 가장 중요. 옛 시안과 가장 많이 다르다
- 위 한 줄: 왼쪽 적 이름 + [임시] 칩, 가운데 속성 칩(예 노멀), 오른쪽 남은 시간 "143 초" 카운트다운, 아이콘 버튼 4개 [그만두기(깃발)] [로그] [일시정지] [도움말]. **배속 버튼은 없다.**
- 무대: 왼쪽 내 캐릭터 + 체력 바(초록, "78 / 108"), 오른쪽 적 실루엣 + 체력 바(빨강, "606 / 656"). 적 위에 가운데 정렬 점선 띠 "강공격 예고" (예고가 뜨면 이 자리에 시전 바가 찬다). 맞을 때 숫자가 떠오른다.
- 범례 한 줄(작은 글자): 공격 · 막기 · 회복 · 공허 · 콤보 블록 (각 색 점). 필살 범례는 없다.
- 블록 바: 8칸 일렬, 빈 칸은 점선 상자. 칸 높이 약 64px. 블록은 시간이 지나면 한 칸씩 생기고 순서는 바꿀 수 없다. **눌러서 사용.**
  · 블록 한 개 = 카드. 아이콘이 카드 중심을 크게(약 34px) 차지하고, 이름은 아래 작게. 위에 체인 점 ●○○ 3개. 약점이면 오른쪽 위 금색 모서리.
  · **블록 이름·아이콘은 계열이다**: 공격 블록은 "조/탄/교"(사신 "참/권/귀")만 쓰고 계열마다 아이콘이 다르다(조=발톱 3줄, 교=이빨, 탄=탄환 궤적, 참=베기, 권=충격, 귀=빔). "노말_조" 같은 속성 접두는 쓰지 않는다. 막기는 방패 아이콘+"막기", 회복은 십자+"회복", 공허는 소용돌이+"공허", 콤보는 금빛 광택+"콤보_계열".
  · **블록 색 = 속성 색**(노멀은 회색 베이지). 막기·회복·공허·콤보는 각자 고정 색. 속성 막기·속성 회복은 없다.
  · 같은 블록(같은 속성+같은 계열)이 붙어 있으면 윗줄에 "체인2/체인3" 금색 탭이 붙고, 붙은 칸들이 금색 테두리로 묶인다.
- 바 위 오른쪽 아래에 **영력 해방 카드**: 제목 "영력 해방"(사신 5단계 이상은 "만해"/호로 5단계 이상은 "레스렉시온") + [임시] 칩 + "게이지 35%" 글자 + 가는 막대. 가득 차면 카드 전체가 [해방] 버튼으로 바뀌어 빛난다. 해방 중(캡처 3)에는 막대가 남은 시간으로 줄고, 해방 블록 몇 칸이 바에 섞여 나온다.
- 없는 것: 배속, 필살/응축 일격 게이지, SP, 저장 필살, "짧게 눌러 떼기 0.3초" 안내문(안내는 도움말에 있음).

[3. 원정 걷기] 캡처 4
- 전체가 걷는 장면: 하늘+땅 2층 시차 배경, 땅 띠가 화면 높이의 약 절반, 캐릭터가 왼쪽을 향해 걷는다. 칸 번호·길 구조는 이 화면에 보이지 않는다.
- 위에 얹는 얇은 상태 줄(배고픔/컨디션/광기 게이지·바퀴 수·[그만두기]), 조우 알림, 바퀴 끝 선택(귀환/한 바퀴 더, 얻은 타일 배치 팝업), 드래프트 3장 중 1장, 이벤트 창(상인·제단·보물·함정).

[4. 원정 출발(배치)] 캡처 5
- 위: 제목 토글 "자유 원정 ▾"(스토리·탑으로 전환), 사냥터 이름, 난이도 ★1~★5 버튼 줄(잠긴 ★는 자물쇠, 권장 ★에 태그), 한 줄 설명.
- 가운데: **왼쪽 = 길**: 6열×2줄 칸 카드(둥지 칸 + 1~11번 칸). 놓은 타일은 타일 색 배경 + 아이콘 + 이름 + 칸 번호, 빈 칸은 점선 + 번호. **오른쪽 = 가진 타일 카드 격자**(카드 하나 = 큰 아이콘 원 + 이름 + 한 줄 효과 + 오른쪽 위 ×장수, 타일 색 그라데이션). 카드를 눌러 고른 뒤 빈 칸을 누르거나 **끌어서 칸에 놓는다**(칸 → 칸 이동·교체, 칸 → 카드 영역 되돌리기). 끌면 아이콘 원이 따라오고 놓을 수 있는 칸이 파랗게 빛난다. 붙은 두 칸은 시너지 이름표.
- 아래: **배치 프리셋 패널**(이름 입력 + [현재 배치 저장], 카드마다 칸 미리보기 띠·[불러오기][덮어쓰기][이름][삭제]; 최대 5개) + 큰 [출발] 버튼.
- 놓을 수 있는 칸 수는 최대 8(+상점 배치 칸). "덱"이라는 말은 쓰지 않는다 — "가진 타일".

[5. 보관함] 캡처 6
- 머리 제목 토글 "보관함 · 타일 ▾"로 슬롯 / 타일 / 물건 전환. 슬롯 = 왼쪽 장착 슬롯 칸, 오른쪽 보유 특성. 타일 = 왼쪽 설명+합성 버튼+프리셋 패널, 오른쪽 길+가진 타일 카드(캡처 5와 같은 컴포넌트). 물건 = 아래 6번.

[6. 상점·보관함 물건] 캡처 7·8
- 머리: 제목 "상점" + 부제 "골드 5200 · 영옥 121". 그 아래 카테고리 탭 줄: 음식 · 소모품 · 장비 · 스킨 · 타일 · 기타 (+ 떠돌이 상인이 와 있으면 "떠돌이 상인" 탭). 골드/영옥 탭은 없다 — 카드마다 가격 앞에 통화 이름.
- 카드 격자: 한 줄 4장, **세로 2줄이 한 화면에 보이는 높이**(카드 높이 약 118px). 카드 = 큰 그림(아이콘·색 견본·스킨 썸네일) + 이름 + 효과 2줄 + 가격 칩, 오른쪽 위 "보유 3/9" 배지, 산 것은 "보관함에서 착용".
- 카드를 누르면 **상품 구매 창**(캡처 8): 왼쪽 큰 그림 + "보유: n", 오른쪽 이름·설명·(쌓는 물건만) 수량 [−][+][최대]·큰 가격 버튼. 스킨은 왼쪽에 "미리보기" 태그와 캐릭터가 입은 그림. 오른쪽 위 [×].
- 보관함 물건 탭도 같은 탭 줄(음식·소모품·장비·스킨·타일·기타, 탭마다 개수)과 같은 카드, 카드를 누르면 같은 상세 창에 [사용]/[장착]/[해제]. 장비는 "준비 중" 빈 상태.
- 떠돌이 상인: 같은 카드·창, 카드 오른쪽 위에 등급 배지(보통/희귀). 티어는 화면에 내지 않는다.

[7. 상태] 캡처 9
- 왼쪽 열: **광기·자아 설명 패널**(광기: 손해 / 오르는 길 / 내리는 길 목록, 자아: 손해 / 오르내림 — 숫자로), 가진 것(먹이·영혼 결정·골드·영옥), 스킨 고르기. 오른쪽 열: 능력치 6줄 + 치명타·속성 피해 줄, 진화 정보 패널(진화체 도감·환생 버튼).

[8. 흡수(포식)] 캡처 10
- 3단계: ① 선택(둘 다 포식 / 속성만 / 스탯만 / 포식 안 함 — 큰 버튼 4개, 각각 얻는 것 한 줄) ② 특성 후보 카드 2~3장 ③ 슬롯이 가득 차면 교체/포기. 위에 광기 게이지(+예상 증가), 다시 뽑기 버튼, 그 적의 약점·속성 칩.

[9. 그 밖 화면 — 같은 컴포넌트로]
결과(귀환/패배/스토리 클리어 톤 3가지), 스토리 대화창, 진화 연출, 책장(진화체 도감·칭호 도감 제목 토글), 수련장(수련치·수련권·본능 대결 4종·훈련 인형·번호 쟁탈전), 설정, 도움말·튜토리얼 카드, 확인 창(모달: 제목+본문+[예][아니오]), 토스트(위쪽 가는 띠), 오버레이 상세 창(상품 구매 창과 같은 모달 규격).
```
