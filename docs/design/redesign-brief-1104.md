## b. 확정 UX 규칙 (디자인이 반드시 지킬 것)

### b-1. 정체성 · 조작
1. **게임 정체성 = '구형 기기로 플레이하는 도트게임'**(122장 1, 사용자 원문 "이 게임은 폰에서 구동하지만 아이덴티티는 '구형 기기로 플레이하는 도트게임'이야"). 웹 페이지·관리 도구처럼 보이는 표·폼·긴 문단 금지(ui-review 관점 7).
2. **기기 버튼 ▲▼✓◀ 은 어떤 화면에서도 사라지지 않고 같은 자리**. 모든 화면은 기기 버튼만으로 끝까지 조작 가능, 터치는 지름길(122장 1, 16-1 2).
3. **초점 이동 = 화면에 보이는 위치 순서**(위→아래, 같은 줄 왼→오, 끝에서 처음으로)(63장, 122장 3). 지금 초점이 늘 보여야 함(bha 포커스 표시).
4. **초점 세부 규칙(176장, C.259)**: 기기 버튼은 '바깥 누름'이 아님(목록·ⓘ가 안 닫힘) · 숨긴 것은 초점 대상 아님 · 새 창은 시작 칸에서(바퀴 끝 = [귀환]) · 뒤로·창 닫기 = 들어갔던 칸으로 · 스크롤 칸 끝 글은 ▼ = 스크롤 · 돌보기 뒤 초점 제자리 · 타일 카드 → 첫 빈 칸 → 다음 카드.
5. 전투: ▲▼ = 머리 버튼 → 막기·소모품·장비 → 블록 칸 왼쪽부터, ✓ = 누름, ◀ = 일시정지(122장 3·4). 생성 게이지는 버튼 아님(178장 1).
6. 방 뒤로 = 처음 화면 확인(124장). 잠긴 흐름(전투·걷기·흡수·결과)은 뒤로로 못 빠짐(16-4, 128장 4).

### b-2. 배치
7. **버튼 자리 고정**(173장 2, 사용자 "버튼 위치 웬만하면 고정 좀 시켜라"): 고른 항목·설명 길이·수치·상태가 바뀌어도 버튼·초점 대상은 안 움직인다. 바뀌는 글은 고정 높이 칸 안에서 줄임·스크롤, 버튼은 칸 밖 고정 자리. 버튼이 없어지는 경우도 자리를 비우거나 흐리게(다른 버튼이 당겨 오지 않게). 예: 흡수 [흡수] y 310 고정, 바퀴 끝 [귀환] 290 고정, 전투 [막기] x 461 고정.
8. **넘치는 칸 = '▼ 더 있음'**(168장 3): ⓘ 창·설명 칸·목록이 넘치면 안에서 스크롤 + 바닥 '▼ 더 있음', 끝까지 내리면 숨김, 기기 ▼로 스크롤(179장 보충도 같은 방식).
9. **ⓘ = 원 안 i 아이콘**, 누르면(PC는 올리면) 작은 설명 창(104장 2). 능력치 설명·상태 설명·리스크 설명은 줄 펼침이 아니라 ⓘ 창 안(160장 7, 165장 2). 계산식 노출 금지 — 쉬운 말 + 대표 값(168장 3).
10. **잠김 표시**: 그림만 흐림 + **자물쇠는 그 물건 그림 칸 안 오른쪽 아래 귀퉁이**(이름표 옆 아님), 방·월드맵 공통 `lockProp`(174장 3, C.265). 누르면 이유 한 줄 토스트.
11. **화면 가득 쓰기**: 월드맵·시장·온천은 화면 전체 장면(위 여백 없음, 머리 줄은 장면 위에 겹침)(155장). 시장은 방처럼 앞뒤 깊이로 자연스럽게(158장 3). 캐릭터는 장소 그림 앞, 그림은 이름표를 덮지 않음(C.253).
12. **목록 = 그림·이름·한 줄(+가격) / 수치는 눌렀을 때 상세 창**(158장 8, 159장 25, ui-review 관점 2). 상점·가방·떠돌이 상인 전부.
13. **튜토리얼 카드는 설명하는 대상 바로 옆, 대상·눌러야 할 버튼을 절대 가리지 않음**, 앞 단계와 같은 쪽 먼저(162장 1, 169장). 회색 덮개 없음(129장 1).
14. **노란 알림 = 화면 맨 위 가운데, 쌓이면 위→아래**, 버튼·조작 줄을 가리지 않음(119장 6).
15. **소모품·일반 장비·재료는 얻어도 알림 없음**(161장, `src/config/notify.ts` — 장비 알림 최소 등급 = 없음). 남는 알림 = 진화·승급·도감 목표·새 장소/트랙·떠돌이 상인 도착·경고.
16. 상태는 칩으로만 — 방 위 경고 띠 없음(177장). 상태이상은 능력치보다 위(160장 5).

### b-3. 그림·강조
17. **강조는 그림 모양대로**(178장 3, 사용자 "오오라나 테두리로 강조할 땐 무조건 투명화된 곳 제외하고 이미지 있는곳만"): box-shadow·outline·사각 배경 빛 금지, 알파 따라 `filter: drop-shadow` 겹치기 등. 캐릭터·적·물건·장소·아이콘 그림 전부. (버튼·칸 같은 UI 상자의 초점 테두리는 상자 모양이 맞음 — 대상이 '그림'일 때의 규칙.)
18. **도트 우선**: 그림은 16×16 도트 느낌(물건·아이콘 16×16 → 10배 최근접 확대, 8~10색, 그라데이션·안티에일리어싱·glow 금지, 1도트 외곽선, 2단계 명암), 투명 배경 강제(`docs/design/claude-design-prompts.md` ③, `docs/ui-handoff.md` 프롬프트 규칙 2·3, 사용자 "그냥 16x16이라고 하라고"). 확대는 `image-rendering: pixelated`(115장 3). 그림 없는 자리는 아이콘(그림 대기 — 지적 대상 아님, ui-review 제외 줄).
19. 블록: **색 = 속성, 모양 = 계열**(79장), 블록 타입 글자 숨김(137장 1), 블록 안 체인 원 없음(137장 4). 전투 배치 = 내 캐릭터 오른쪽·적 왼쪽, 블록 바 오른쪽(138장).

### b-4. 색·글자 (사용자 선호)
20. **톤**(사용자 2026-10-26 22:5x, `claude-design-ui-spec-v2.md`): "약간 어둡지만 확실히 보이는 톤 + 톤에 맞춘 색들. 색 자체는 다양하지만 튀는 톤 없이 ui에 어울리는 색으로 배색" — 따뜻한 먹색·짙은 갈회색 바탕(면마다 명도 차), 완만한 입체(얇은 밝은 테두리·안쪽 어두운 면), 강조색은 같은 명도대(가라앉은 청록·구리·황동·보라), 가장 밝은 것은 글자·선택 상태뿐, 형광·순색·네온 없음. 참고 그림 `docs/reference/ui-tone/tone-reference.webp`(**톤만** 참고).
21. **크기**: 사용자는 "아이콘이 너무 작고…크기도 키워"(34장), "버튼 너무 작아. 3배는 키우고"(47장), "노력치 폰트 굵기나 사이즈 좀 바꿔서 가독성 좋게"(160장 6), "흡수 버튼 너무 커"(158장) — 작아서 안 보이는 것도, 쓸데없이 큰 것도 싫어함. 글자 토큰 12~48px(`--bha-fs-xs` 12 최소), 터치 44px 이상(16-4). 사용자는 **크기·자리를 UI 배치 도구로 직접 잡는다**(175장) — 그 값(방·시장·월드맵 x·y·scale)은 존중.
22. **종족 테마**: 레이아웃은 같고 색 토큰·이름만 다름(HANDOFF 3장). 호로 `theme-hollow.css` = 붉은 기 도는 재/숯 바탕 + 뼈백색 글자 + 짙은 크림슨 포인트(위험·선택·해방에만), 뼈색 주 버튼, 굵고 거친 아이콘 선. 사신 `theme-shinigami.css` = 먹·남빛 바탕 + 차가운 백색 글자 + 은청색 포인트, 은빛 칼날 판 주 버튼. 테마 = 종족 json `theme` → 루트 `data-bha-theme`(전투 v2 = `.bha-hollow` / `.bha-soul`). 3번째 종족이 json 하나로 붙는 구조 유지(CLAUDE.md 2).

### b-5. 문구 (`docs/text-style.md` 1~5절, 111장 4)
23. 설명 문구는 평서 '~다' 체 하나('~요'·'~습니다'·'~함/됨/음' 끝·명령·물음 금지). 한 줄짜리(ⓘ 요약·잠김 이유·토스트 제목·카드 한 줄)엔 마침표 없음. 튜토리얼·한 번 뜨는 안내는 한 줄 한 문장, 2줄 이내, 할 일 줄만 "~해 보자"(157장). 대사·버튼 이름·짧은 라벨은 대상 아님.
24. 수치 줄 = `조건: 효과`, ` · `로 잇기, `+n%`·`−n%`(U+2212)·`+n%p`·`n초`·`×n`·`0~24`.
25. 창 구조 = 제목(명사) → 한 줄 요약 → 소제목 아래 수치 줄. 수치 ⓘ = 하는 일 → 구간별 손해(지금 값 줄에 ◀) → 오르내림. 확인 창 제목 = 명사("지금 귀환").
26. 개발자 말 노출 금지: 칸·틱·회분·provisional·기획 n장·id·`{변수}`·계산식(ui-review 관점 1, 168장 4). 단 이름이 안 정해진 것의 **'임시' 표시는 그대로**(159장 5 사용자).

### b-6. 용어 · 금지어 (5절 + 각 장)
27. 기획서 표기: 웨코문도·아쥬커스·바스트로데·레스렉시온·만해·영압 안정도·빈사·폭주/호로화. 종족마다 다른 이름은 faction json에서(하드코딩 금지).
28. **쓰지 않는 말**: '원정' → **모험**(159장) · '밖으로' → **월드맵**(158장 2) · '장터' → **시장**(130장) · '덱' → 없음(85장 11 '덱 없음', 타일은 '가진 타일'·프리셋) · '한계 돌파' → **폭주 / 호로화**(136장 2) · '빈사 치료제' → **구급상자**(143장) · '배속'(62장 삭제) · '필살기'(83장 → 해방) · '트랙' 말은 더보기 전환 메뉴 외 삭제(159장 32) · 원작 호로 이름 임의 사용 금지(4-2) · '평타캐·블록캐·하이브리드'는 대화 전용, 화면에 안 씀(152장) · 속성 '노멀' / 장비 등급은 기획서 표기 하나로(176장 22, 상태 화면 '노멀 피해').

### b-7. 디자인 시스템 (지금 코드)
29. 클래스는 전부 `bha-` 접두, 색·간격·글자·모션은 CSS 변수 토큰만. **새 색·간격 임의 추가 금지 — 부족하면 토큰 제안으로**(CLAUDE.md 7, 꾸밈 전용 `--bha-cos-*` 선례 25-9).

## c. 바꾸면 안 되는 것 / 이번에 열린 것

### 바꾸면 안 되는 것
- **엔진·데이터·세이브**: `src/engine/`, `src/data/`, `src/game.ts`(세이브 형식·런 로그), `src/config/balance.ts`. 디자인 때문에 규칙·수치·세이브 구조를 바꾸지 않는다. 화면은 엔진 값을 **읽기만**(예: 생성 게이지 = `spawnGaugeOf`, 178장).
- **기기 크기·비율**: 844×390, LCD 비율(약 75%) — 사용자 "지금비율 딱이야 건들지마"(133장 1). 가로 고정(117장). 기기 버튼 4개 자리·크기(122장 1, 133장). 기기 디자인 그림 규격 frame-v2(33장).
- **LCD 기준 좌표**: 방·시장·월드맵 물건 자리 = 장면 % 좌표(`room.layout`·`DEFAULT_MARKET.layout`·`DEFAULT_WORLDMAP.layout`·사신 `worldmap.layout`), **사용자가 UI 배치 도구로 직접 잡은 값**(175장 반영 1·2). 바닥 다각형(`floor.poly`)·캐릭터 발 기준점. 전투 v2 640×330 좌표계.
- **종족 설정 구조**: `src/data/factions/*.json` 키(이름·테마·배치·문구). 종족 분기 하드코딩 금지, 3번째 종족 = json 하나.
- **외부 라이브러리 없음**: DOM/CSS + TypeScript만(11-1). 오프라인 PWA(60장).
- 기능·흐름·화면 수: 디자인이 기능을 빼거나 새 확인 단계를 만들지 않는다. **게임을 디자인에 맞추지 않는다**(사용자 10-21 "왜 ui에 맞춰", ui-handoff.md) — 디자인이 게임에 맞춘다.
- 위 b절 확정 규칙(버튼 고정·기기 조작·강조 그림 모양·알림 규칙·문구 규칙).

### 이번 개편에서 열린 것
- **시각 스타일 전체**: 바탕·면·테두리·버튼·칩·게이지·탭·카드·창·토스트의 생김새, 색 토큰 값(톤 원칙 b-4 안에서), 글자 크기 단계·굵기.
- **LCD 안 레이아웃**: 머리 줄·두 열 비율·상세 창·탭 자리·버튼 줄 모양(단, 버튼 자리 고정 원칙과 사용자 배치 도구 좌표는 지킴).
- **컴포넌트 세트**: 공용 컴포넌트 다시 그리기(지금 `components.css` + v2 두 벌을 하나로 합치는 제안도 열림).
- **아이콘**: `sprite.svg` 아이콘 전체 다시 그리기(도트 규칙 b-3 18). 그림 없는 자리 아이콘 목록 = `docs/drafts/블리치_아이콘_없는_목록.xlsx`.
- 연출 모양(토스트 들고 남·창 열림·초점 표시) — 1배 속도·짧게.
- 산출물은 **토큰 표 + `bha-` 클래스 그대로 쓰는 컴포넌트 시트 + 화면별 두 종족 장면**으로 받으면 코딩 세션이 옮기기 쉽다.
