# Claude Design 프롬프트 (마스터F, 2026-10-20)

두 개로 나눈다. ① 기기(다마고치 본체 + 버튼) ② 인게임 UI(LCD 화면 안). 각각 따로 넣는다.
참고 캡처를 같이 붙이면 좋다: 게임 사이트(https://atho3398.github.io/bleach-hollow-Ascension/)의 지금 화면 캡처 — 방·전투·원정·상점.

---

## ① 다마고치 기기 디자인 프롬프트

```
모바일 웹 게임 「블리치 할로우 어센션」의 "다마고치 기기 본체" 디자인을 만들어 줘.
게임 화면 안쪽(LCD 속 화면)은 이번 범위가 아니다. 기기 껍데기·버튼·실루엣만.

[게임 한 줄]
블리치 세계관의 호로(괴물 영혼) 또는 사신(검사)을 키우는 다마고치형 육성 게임. 어둡고 날카로운 분위기, 고급스러운 수집품 느낌.

[기기 구조 — 반드시 지킬 것]
- 폰을 가로로 눕혀 쓰는 기기. 기준 화면 844×390(최소 740×360) 가로.
- 가운데 큰 LCD 창(가로로 긴 직사각형, 기기 폭의 약 75%).
- 왼쪽: 위/아래 버튼 2개(세로로 나란히).
- 오른쪽: 큰 확정 버튼 1개(가운데) + 그 아래 작은 뒤로(취소) 버튼 1개.
- 버튼에는 글자 없음, 아이콘만(위 ∧, 아래 ∨, 확정 ✓, 뒤로 <). 터치 영역 44px 이상.
- 기기 위쪽에 키링을 거는 고리(구멍) 1개.

[보여 줄 상태 3가지]
1. 확대 화면(지금 게임): LCD와 양옆 버튼이 화면을 꽉 채운 상태.
2. 다마고치 모드(줌아웃): 카메라가 물러나 기기 전체 실루엣이 보이고, 위 고리에 키링이 매달린 상태. 배경은 기기가 놓인 어두운 바탕.
3. 뒷면: 기기를 뒤집은 모습. 가운데 기록 판(이름·단계·플레이 시간·환생 ★·처음 시작한 날·제조 번호)이 들어갈 자리, 나사·배터리 덮개 같은 장난감 디테일.

[디자인 변형]
- 기기 디자인 3~4종 시안(예: 뼈·가면 느낌의 호로풍, 먹물·검 느낌의 사신풍, 금박 한정판, 기본형). 모양은 같은 틀(화면 구멍·버튼 위치 동일)에 몸체 모양·무늬·색만 다르게.
- 키링 시안 6종(호로: 가면 조각·뼈 방울·영옥 구슬 / 사신: 지옥나비·방울·영옥 구슬). 각 키링은 고리에 매달 위치(위쪽 끝 점)가 분명하게.

[출력 형식]
- 앞면·뒷면은 각각 투명 배경 PNG로 뽑을 수 있게, LCD 화면 자리는 비워 둘 것(투명 구멍). 체크무늬 배경을 그림에 넣지 말 것.
- 각 시안마다: 화면 구멍의 위치·크기(px), 고리 위치(px), 버튼 4개 위치(px)를 표로 적어 줘.
- 색은 CSS 변수로 정리(이름은 --bha-로 시작). 외부 라이브러리 없이 HTML/CSS만.
- 한국어 표기.
```

## ② 인게임 UI 디자인 프롬프트 (LCD 화면 안)

```
모바일 웹 게임 「블리치 할로우 어센션」의 "LCD 화면 안쪽" 인게임 UI를 다시 디자인해 줘.
기기 껍데기·물리 버튼은 이번 범위가 아니다(따로 디자인함). 화면 안에 그려지는 것만.

[게임 한 줄]
블리치 세계관의 호로 또는 사신을 키우는 다마고치형 로그라이크. 둥지에서 돌보기 → 원정(12칸 원형 길에 타일 배치) → 실시간 자동 전투 + 블록 체인 → 적 흡수(특성) → 진화. 호로판과 사신판은 같은 화면에 테마(색·이름)만 다르다.

[화면 크기·규칙 — 반드시 지킬 것]
- LCD 영역 가로 약 640×330(CSS px, 기기 844×390 기준). 세로 스크롤 없이 한 화면에.
- 글자 최소 11px, 터치 대상 44px 이상, 대비 4.5:1 이상.
- 컬러 도트 LCD 풍 + 어두운 바탕. 캐릭터·배경 그림은 자리만(나중에 도트 그림으로 교체).
- 두 테마: 호로(뼈·모래·붉은 영압, 웨코문도) / 사신(먹물·흰 하오리·푸른 영압, 소울 소사이어티). 같은 레이아웃에 색 토큰만 바뀌게.
- 용어: 웨코문도, 아쥬커스, 세군도 에타파, 레수렉시온, 만해, 붕옥, 영옥(꾸밈 재화), 골드.
- 클래스 이름은 bha- 로 시작, 색·간격·글자는 CSS 변수 토큰으로. 외부 라이브러리 없이 HTML/CSS만.

[화면 목록 — 우선순위 순]
1. 둥지(메인): 방 장면 + 가운데 캐릭터 + 방 물건(문=원정, 제단=진화, 책=도감, 상자=덱, 창문=칭호, 수련 제단), 위 한 줄 상태 바(허기·컨디션·리스크), 아래 독(먹이 주기·재우기·쓰다듬기·더보기 ⋯), 말풍선.
2. 전투: 나/적 그림과 체력 바, 남은 시간·배속·일시정지, 블록 8칸 일렬(블록마다 속성 아이콘+계열 글자, 같은 계열 3개 붙으면 체인 표시), 저장 필살 게이지, 강공격 예고, 범례(공격·막기·회복·필살·공허·콤보).
3. 원정: 왼쪽 12칸 원형 길(타일 아이콘·현재 위치), 오른쪽 상태·보유 타일·조작, 이벤트 창(상인·제단·보물·함정·갈림길), 드래프트 3장 중 1장.
4. 흡수: 3단계(선택 → 특성 후보 카드 2~3장 → 교체), 다시 뽑기 버튼.
5. 상점: 골드/영옥 탭, 품목 카드(이름·효과·가격·사기/착용), 꾸밈 견본.
6. 결과(귀환/패배/스토리 클리어), 스토리 대화창(LCD 아래 이름표+대사), 진화 연출, 도감, 설정.

[출력]
- 화면마다 호로·사신 두 버전.
- 상태별(기본·선택됨(위/아래 버튼으로 고른 하이라이트)·눌림·잠김) 컴포넌트 시트.
- 토큰 표(색·간격·글자 크기·모션 시간)를 따로 정리.
- 한국어 표기.
```
