## ① 다마고치 기기 디자인 프롬프트 (v2, 2026-10-20 — 한 번에 하나, 모양 자유)

1차 시도(4종 묶음·사각형 고정)는 사용자 거부. 아래를 **디자인 하나마다 한 번씩** 넣고, 【 】 칸만 바꾼다.

```
게임 「블리치 할로우 어센션」의 다마고치 기기 디자인을 딱 1개만 만들어 줘. 여러 개 시안을 한 장에 모으지 마.

【모티브】: 사신대행증 — 원작의 오각형 나무패 모양, 가운데 해골 문양 (참고 그림 첨부)

[모양]
- 기기 외곽 모양은 자유다. 사각형으로 만들지 말고 모티브의 실루엣을 그대로 살려라(오각형 패, 가면, 칼코등이 등).
- 지켜야 할 건 딱 5가지만:
  1. 게임 화면이 들어갈 가로로 긴 화면 창 1개 (가로:세로 약 2:1, 기기 앞면 넓이의 절반 이상)
  2. 버튼 4개: 위·아래(나란히 2개), 확정(가장 큼), 뒤로(작음). 글자 없이 아이콘(∧ ∨ ✓ <)만. 위치는 모양에 맞게 자유.
  3. 키링을 거는 고리 1개 (위치 자유)
  4. 원작 로고·글자는 내가 제시한 것만 그대로 넣는다. 제시하지 않으면 넣지 마.
  5. 실물 게임기처럼 보여야 한다. 재질감(예: 낡은 나무패 + 금속 테두리), 음각·양각, 버튼의 눌리는 두께감, 화면 창 테두리의 단차를 적극적으로 표현.

[뽑을 것 — 이 순서로, 각각 따로]
1. 앞면 정면 1장
2. 같은 기기 뒷면 정면 1장 (가운데에 기록 판이 들어갈 빈 자리: 이름·단계·플레이 시간 같은 글이 들어감)
3. 같은 기기 옆면(두께) 1장 — 기기를 옆에서 본 얇은 띠. 앞·뒷면과 같은 재질, 세로 길이는 앞면 높이와 같게. 뒤집을 때 옆면으로 쓴다.
- 셋 다 투명 배경 PNG, 화면 창 자리는 투명하게 비워 둠. 체크무늬 배경을 그림에 그리지 마. 그림자·키링·손·배경 없이 기기만.
- 큰 해상도(가로 1600px 이상), 정면(기울이지 않음).

[같이 적어 줄 것] (앞면 그림 픽셀 기준)
- 화면 창: x, y, 너비, 높이
- 버튼 4개 각각: x, y, 너비, 높이
- 고리 중심: x, y
```

## ② 인게임 UI 디자인 프롬프트 (LCD 화면 안)

```
모바일 웹 게임 「블리치 할로우 어센션」의 "LCD 화면 안쪽" 인게임 UI를 다시 디자인해 줘.
기기 껍데기·물리 버튼은 이번 범위가 아니다(따로 디자인함). 화면 안에 그려지는 것만.

[게임 한 줄]
블리치 세계관의 호로 또는 사신을 키우는 다마고치형 로그라이크. 둥지에서 돌보기 → 원정(12칸 원형 길에 타일 배치) → 실시간 자동 전투 + 블록 체인 → 적 흡수(특성) → 진화. 호로판과 사신판은 같은 화면에 테마(색·이름)만 다르다.

[화면 크기·규칙 — 반드시 지킬 것]
- LCD 영역 가로 약 640×330(CSS px, 기기 844×390 기준). 세로 스크롤 없이 한 화면에.
- 글자 최소 11px, 터치 대상 44px 이상, 대비 4.5:1 이상.
- 컬러 도트 LCD 풍 + 어두운 바탕. 캐릭터·배경 그림은 자리만(나중에 도트 그림으로 교체).
- 두 테마: 호로(뼈·모래·붉은 영압, 웨코문도) / 사신(먹물·흰 하오리·푸른 영압, 소울 소사이어티). 같은 레이아웃에 색 토큰만 바뀌게.
- 용어: 웨코문도, 아쥬커스, 세군도 에타파, 레수렉시온, 만해, 붕옥, 영옥(꾸밈 재화), 골드.
- 클래스 이름은 bha- 로 시작, 색·간격·글자는 CSS 변수 토큰으로. 외부 라이브러리 없이 HTML/CSS만.

[화면 목록 — 우선순위 순]
1. 둥지(메인): 방 장면 + 가운데 캐릭터 + 방 물건(문=원정, 제단=진화, 책=도감, 상자=덱, 창문=칭호, 수련 제단), 위 한 줄 상태 바(허기·컨디션·리스크), 아래 독(먹이 주기·재우기·쓰다듬기·더보기 ⋯), 말풍선.
2. 전투: 나/적 그림과 체력 바, 남은 시간·배속·일시정지, 블록 8칸 일렬(블록마다 속성 아이콘+계열 글자, 같은 계열 3개 붙으면 체인 표시), 저장 필살 게이지, 강공격 예고, 범례(공격·막기·회복·필살·공허·콤보).
3. 원정: 왼쪽 12칸 원형 길(타일 아이콘·현재 위치), 오른쪽 상태·보유 타일·조작, 이벤트 창(상인·제단·보물·함정·갈림길), 드래프트 3장 중 1장.
4. 흡수: 3단계(선택 → 특성 후보 카드 2~3장 → 교체), 다시 뽑기 버튼.
5. 상점: 골드/영옥 탭, 품목 카드(이름·효과·가격·사기/착용), 꾸밈 견본.
6. 결과(귀환/패배/스토리 클리어), 스토리 대화창(LCD 아래 이름표+대사), 진화 연출, 도감, 설정.

[출력]
- 화면마다 호로·사신 두 버전.
- 상태별(기본·선택됨(위/아래 버튼으로 고른 하이라이트)·눌림·잠김) 컴포넌트 시트.
- 토큰 표(색·간격·글자 크기·모션 시간)를 따로 정리.
- 한국어 표기.
```

## ③ 홈(둥지·대원실) 그림 프롬프트 (마스터G, 2026-10-20 — 한 번에 하나)

지금 홈은 그림이 없어 도형(자리표시)으로 나온다. 필요한 그림 = **배경 2장 + 물건 7종 × 종족 2 = 16장**. 아래 공통 프롬프트에 【 】만 바꿔 **한 장씩** 뽑는다.
파일명: 배경 `scene-cave.png`(호로)·`scene-room.png`(사신), 물건 `prop-<종족>-<id>.png`(예 `prop-hollow-dummy.png`) → `public/art/` 에 넣거나 대화에 올리면 그림 세션이 넣는다. (종족별 물건 파일은 C.79 이후 인식 — 그 전엔 `prop-<id>.png` 하나를 두 종족이 같이 씀)

### ③-a 물건 공통 프롬프트
```
게임 「블리치 할로우 어센션」(블리치 세계관 다마고치형 육성 게임) 홈 화면에 놓을 물건 그림 1개만 만들어 줘.

【종족·장소】: 호로의 둥지 — 웨코문도 사막 동굴 (하얀 뼈·모래·푸른 달빛)
【물건】: 뼈 인형 — 훈련용 허수아비. 뼈를 엮어 만든 사람 모양, 맞은 자국
[규격]
- 176×160 px(또는 그 정수배 352×320), 투명 배경 PNG, 그림자 없음(바닥 그림자는 게임이 그림)
- 도트(픽셀아트) 16비트 휴대용 게임기 느낌, 캐릭터 그림(256×256 도트)과 같은 해상도감. 테두리 1px 어두운 외곽선
- 약간 위에서 본 정면(3/4), 바닥 접지면이 캔버스 아래쪽 약 10% 위
- 작은 화면에서 한눈에 무엇인지 알아볼 실루엣. 글자·로고 넣지 마
- 배경·다른 물건 없이 그 물건 하나만
```

### ③-b 물건 목록 (【물건】 칸에 넣을 말)
| id | 호로 (`prop-hollow-…`) — 웨코문도 동굴 | 사신 (`prop-shinigami-…`) — 호정 13대 대원실 |
|---|---|---|
| `door` 원정 출발 | 둥지 입구 — 뼈 기둥 사이 모래 바람이 부는 동굴 입구 | 대원실 문 — 미닫이 나무 문(쇼지), 위에 대 번호 나무패 |
