너는 모바일 웹 도트게임 「블리치 할로우 어센션」의 UI/UX 전체를 새로 디자인한다. 첨부한 zip 안의 캡처(지금 화면 전체, 호로·사신 두 종족)와 토큰 파일, 톤 참고 그림을 먼저 모두 본 뒤 작업해라. 지금 디자인을 다듬는 게 아니라 전체 시각 스타일을 새로 짜되, 아래 "바꾸면 안 되는 것"과 "확정 규칙"은 반드시 지킨다.

첨부 zip 구성: 1-captures-hollow / 2-captures-shinigami = 지금 화면 전체(1배 844×390, 파일 이름 = 화면 이름, 화면 안의 '원정'·'장터' 글자는 옛 이름이 남은 캡처 이름일 뿐 게임 안 표기는 '모험'·'시장') · 3-captures-battle-absorb-spa = 전투·흡수·온천·모험 준비 탭 · 4-tone-reference = 톤만 참고 · 5-current-tokens = 지금 토큰 이름과 값. 캡처 위쪽의 '테스트' 꼬리표와 노란 알림 일부는 캡처용 테스트 모드 표시라 디자인 대상이 아니다.

# 1. 게임 한 줄 설명
블리치 세계관의 호로(또는 사신)를 키우는 다마고치형 로그라이크 육성 게임. 방(둥지/대원실)에서 돌보고 → 월드맵에서 장소를 고르고 → 모험(타일을 깐 길을 걷기 → 실시간 자동 전투 + 스킬 블록 → 흡수) → 진화한다. 호로판과 사신판은 화면 구조가 같고 색 테마와 이름만 다르다.

# 2. 정체성 (가장 중요)
- "폰에서 돌아가지만 정체성은 '구형 휴대 기기로 플레이하는 도트게임'". 웹 페이지·관리 도구처럼 보이는 표·폼·긴 문단 금지.
- 화면은 가로 고정. 기기 껍데기 844×390 안에 LCD(약 75% 크기)가 있고, 모든 게임 화면은 LCD 안에서만 그린다. 기기 왼쪽에 ▲▼, 오른쪽에 ✓, 그 밑에 작은 ◀(뒤로). 이 4개 버튼은 어떤 화면에서도 같은 자리·같은 크기로 남는다.
- 모든 화면은 기기 버튼만으로 끝까지 조작할 수 있어야 하고, 터치는 지름길이다. 지금 초점(커서) 위치가 늘 눈에 보여야 한다. 초점 이동 순서 = 화면에 보이는 위치 순서(위→아래, 같은 줄은 왼→오).

# 3. 톤 (사용자 원문)
"약간 어둡지만 확실히 보이는 톤 + 톤에 맞춘 색들. 색 자체는 다양하지만 튀는 톤 없이 ui에 어울리는 색으로 배색"
- 따뜻한 먹색·짙은 갈회색 바탕, 면마다 명도 차로 층 구분. 완만한 입체(얇은 밝은 테두리 + 안쪽 어두운 면).
- 강조색은 같은 명도대의 가라앉은 색(청록·구리·황동·보라 등). 가장 밝은 것은 글자와 선택 상태뿐. 형광·순색·네온·glow 없음.
- 첨부 tone-reference.webp 는 톤(밝기·채도·배색 느낌)만 참고하고, 모양·레이아웃은 따라 하지 않는다.
- 종족 테마: 레이아웃은 같고 색 토큰·이름만 다르다.
  - 호로: 붉은 기 도는 재·숯 바탕, 뼈백색 글자, 짙은 크림슨 포인트(위험·선택·해방에만), 뼈색 주 버튼, 굵고 거친 아이콘 선.
  - 사신: 먹·남빛 바탕, 차가운 백색 글자, 은청색 포인트, 은빛 칼날 판 같은 주 버튼.

# 4. 크기 (사용자 불만 원문 반영)
- "아이콘이 너무 작고…크기도 키워", "버튼 너무 작아. 3배는 키우고", "노력치 폰트 굵기나 사이즈 좀 바꿔서 가독성 좋게", 그런데 "흡수 버튼 너무 커" — 작아서 안 보이는 것도, 쓸데없이 큰 것도 싫어한다.
- 글자 최소 12px, 단계 12·13·14·16·18·22·28·36·48. 터치 대상 44px 이상(작은 버튼 36px 이상). 글자 대비 4.5:1 이상.

# 5. 그림 규칙
- 그림은 16×16 도트 느낌: 1도트 외곽선, 8~10색, 2단계 명암, 그라데이션·안티에일리어싱·glow 금지, 투명 배경, 확대는 최근접(pixelated).
- 강조는 그림 모양대로: 캐릭터·적·물건·장소·아이콘 그림을 강조할 때 사각 테두리·box-shadow·사각 배경 빛 금지, 그림의 불투명한 부분 윤곽만 따라 빛나게(drop-shadow 겹치기). 버튼·칸 같은 UI 상자의 초점 테두리는 상자 모양이 맞다.
- 캐릭터·적·물건 그림 자체는 따로 그려지는 중이니 그리지 마라. 그림 자리(틀·크기·이름표 자리)만 정한다. 그림이 없는 곳은 지금처럼 아이콘 자리로 둔다.
- 아이콘(지금 약 85개, i-* 스프라이트)은 위 도트 규칙으로 새 세트를 제안해도 된다.

# 6. 확정 UX 규칙 (반드시 지킬 것)
1. 버튼 자리 고정: 고른 항목·설명 길이·수치·상태가 바뀌어도 버튼·초점 대상은 움직이지 않는다. 바뀌는 글은 고정 높이 칸 안에서 줄이거나 스크롤하고, 버튼은 칸 밖 고정 자리. 버튼이 없어질 때도 자리를 비우거나 흐리게 해서 다른 버튼이 당겨 오지 않게.
2. 넘치는 칸 = 안에서 스크롤 + 바닥 '▼ 더 있음' 한 줄(끝까지 내리면 숨김), 기기 ▼로도 스크롤.
3. ⓘ = 원 안 i 아이콘. 누르면 작은 설명 창. 능력치·상태·위험 설명은 줄 펼침이 아니라 ⓘ 창 안. 계산식 노출 금지(쉬운 말 + 대표 값).
4. 잠김 표시: 그림만 흐리게 + 자물쇠는 그 물건 그림 칸 안 오른쪽 아래 귀퉁이(옆 물건 이름표 근처 금지). 누르면 이유 한 줄.
5. 월드맵·시장·온천은 화면 전체가 장면(위 여백 없음, 머리 줄은 장면 위에 겹침). 시장은 방처럼 앞뒤 깊이로 물건이 놓인다. 캐릭터는 장소 그림 앞, 그림은 이름표를 덮지 않는다.
6. 목록 = 그림·이름·한 줄(+가격). 수치는 눌렀을 때 상세 창에서만(상점·가방·떠돌이 상인 전부).
7. 튜토리얼 카드는 설명하는 대상 바로 옆, 대상·눌러야 할 버튼을 절대 가리지 않는다. 회색 덮개 없음.
8. 노란 알림(토스트) = 화면 맨 위 가운데, 여러 개면 위→아래로 쌓임, 버튼·조작 줄을 가리지 않음. 진화·승급·도감 목표·새 장소·떠돌이 상인 도착·경고만 알림(소모품·일반 장비 얻기는 알림 없음).
9. 방 위에 경고 띠 없음 — 상태는 캐릭터 머리 위 칩으로만. 상태이상은 능력치보다 위.
10. 전투: 내 캐릭터 오른쪽, 적 왼쪽. 블록 = 색은 속성, 모양은 계열, 블록 안에 계열 글자 1자. 블록 타입 글자·체인 원 표시 없음. 블록 칸은 정사각형.
11. 문구: 설명은 '~다' 체 하나, 한 줄짜리(요약·잠김 이유·토스트·카드 한 줄)엔 마침표 없음. 수치 줄은 `조건: 효과`를 ` · `로 잇기, `+n%` `−n%` `×n` `n초`. 개발자 말(칸·틱·id·계산식) 금지. 이름이 안 정해진 것의 '임시' 표시는 그대로 둔다.
12. 쓰지 않는 말: 원정(→ 모험), 밖으로(→ 월드맵), 장터(→ 시장), 덱(없음, '가진 타일'·프리셋), 한계 돌파(→ 폭주/호로화), 배속, 필살기(→ 해방). 용어는 웨코문도·아쥬커스·레스렉시온·만해·영압 안정도·빈사 표기 그대로.

# 7. 화면 전체 목록 (호로 이름 / 사신 이름)
## 홈
- 방 (둥지 / 대원실): 방 배경 위 물건 4개 — 책장, 월드맵(문), 가방(배낭), 진급 시험(번호 쟁탈전 / 진급 시험, 책장 바로 아래, 4단계 전 잠김). 가운데 캐릭터(누르면 반응·말풍선), 캐릭터 아래 체력 막대("체력 n / max"), 머리 위 상태 칩(배부름·컨디션·광기/호로화·영압 안정도·상태이상) + ⓘ. 모험 중이면 [모험 이어하기]. 사망이면 [부활].
- 아래 돌보기 줄(고정): 먹이/식사 · 재우기 · 교감/손질 (캐릭터가 청한 것만 강조, 먹이는 누르면 위로 종류 고르기 줄) + 대기 보상 시계 + 더보기 ⋯(설정·도움말·사진·다마고치·종족 전환·붕옥·백업·불러오기·처음 화면 아이콘 격자).
- 상태 화면: 상태이상 칸(있을 때) → 능력치(굵은 +n 노력치, 각 ⓘ) → 진화 정보 → [도감][도움말][환생].
- 가방: 탭 장비(무기·방어구·신발·장신구 2 + 전투 소모품 칸) · 슬롯(장착 블록·특성, 끌어 놓기) · 타일(배치 편집·프리셋) · 소모품 · 스킨(하위 탭) · 펫 · 기타(재료 등). 목록 → 상세 창.
- 책장: 제목 토글 진화체 도감 / 칭호 도감, 왼쪽 목록 → 오른쪽 상세.
- 진급 시험: 왼쪽 번호 사다리, 오른쪽 지금 상대 + [도전].
- 대기 보상 창, 사진(액자 고르기·저장), 붕옥·합체, 환생 확인 2단계.
## 월드맵
- 월드맵 (웨코문도 / 소울 소사이어티): 하이앵글 지도 한 장, 장소 6곳(홈·시장·수련장·모험·도전의 탑·온천). 캐릭터가 걸어가서 페이드 전환. 시장엔 떠돌이 상인이 왔을 때 '상인' 배지.
- 시장: 소모품 상점·장비 상점·스킨 상점·특성 상점·대장장이·떠돌이 상인(와 있을 때만) + 왼쪽 앞 월드맵(지도) = 나가기.
- 상점 4곳 + 떠돌이 상인: 카테고리 탭 + 큰 카드 격자(그림·이름·한 줄·가격) → 상세 창 [사기].
- 온천: 화면 전체 온천 장면, 캐릭터가 탕에 앉음(물 높이 아래 몸이 비침), 왼쪽 위 작게 [방으로 돌아가기]·ⓘ, 머리 위 체력·배부름.
- 수련장: 제목 토글 수련 · 훈련 인형. 수련 = 수련치·수련권·종목 카드 4개 → 미니게임. 훈련 인형 = 상대 목록(필터) → 연습 전투.
- 도전의 탑: 지금 층·최고 층·다음 층(적·★·보상) + [도전].
## 모험
- 모험 준비: 머리 탭 [자유 모험] / [스토리]. 자유 모험 안에 [준비] / [타일 배치] 탭. 준비 = 사냥터·난이도 ★·설명·길 미리보기 + 오른쪽 프리셋(불러오기·저장·이름·삭제) + 아래 [출발] 띠. 타일 배치 = 길(가로 한 줄 전체 폭) + 가진 타일 카드(한 줄 4장, [출발] 위에서만 스크롤 + '▼ 더 있음'). 첫 진화 전이면 타일 탭 없음.
- 스토리: 장 목록 → 화 목록 → 대화창(LCD 아래 이름표 + 글, [건너뛰기]).
- 걷기: 캐릭터가 왼쪽을 보고 걷고 배경이 층별로 흐름. 위 상태 줄(바퀴·체력·컨디션) + [가방] + [귀환하기] + 도움말. 앞쪽에서 적·휴식 장소가 다가옴.
- 조우 연출, 강적·보스 WARNING(위아래 붉은 사선 띠 약 1.5초), 이벤트 창(선택지 버튼), 폭주 연출.
- 바퀴 끝 창: 타일 뽑기(카드 뒤집기)·손·배치판 + [귀환] / [한 바퀴 더] 같은 크기, 창 높이 고정.
- 전투: 위 오른쪽 남은 시간·그만두기·로그·일시정지·도움말. 내 체력/적 체력 막대, 강공격 예고, 광기/호로화 칩. 아래 스킬창 약 130px = 범례 줄 + 버튼 줄 [생성 게이지][막기][소모품][장비](못 쓸 때도 자리 그대로 흐리게) + 블록 바 8칸(정사각). 해방 = 캐릭터 누르기, 해방 중 표시·컷인(레스렉시온 / 만해). 일시정지 창(계속·설정·그만두기).
- 흡수 (포식 / 정화 흡수): 왼쪽 상대 카드 → 갈래 4개(각 아래 작은 위험 +n) → 설명 칸(고정 높이, 안에서 스크롤 + '▼ 더 있음') → [○○하기] 버튼(맨 아래 고정). 다음 특성 고르기(후보 + [다시 뽑기] 고정 자리) → 슬롯 교체. [내 상태] 창.
- 결과(귀환·패배 등 승리/패배 톤, 성장 요약) → 진화 연출(단계 이름·진화체 이름·외형 변화).

# 8. 바꾸면 안 되는 것
- 기기 크기 844×390, LCD 비율, 가로 고정, 기기 버튼 4개 자리·크기. 사용자 원문 "지금비율 딱이야 건들지마".
- 방·시장·월드맵 물건 위치·크기(사용자가 배치 도구로 직접 잡은 장면 % 좌표). 디자인은 물건 생김새·이름표·잠김 표시만.
- 기능·흐름·화면 수: 기능을 빼거나 확인 단계를 새로 만들지 않는다. 게임을 디자인에 맞추지 말고 디자인이 게임에 맞춘다.
- 구현은 외부 라이브러리 없이 DOM/CSS. 클래스는 전부 `bha-` 접두, 색·간격·글자·모션은 CSS 변수 토큰(`--bha-*`)만. 지금 토큰 이름(첨부 tokens.css, 약 208개)을 가능한 한 그대로 쓰고 값을 새로 정한다. 새 토큰이 필요하면 이름과 용도를 따로 표로 제안한다.
- 3번째 종족이 테마 파일 하나로 붙을 수 있는 구조(종족 = 루트 테마 클래스 + 토큰 값 덮어쓰기).

# 9. 열려 있는 것 (마음껏 바꿔도 됨)
- 바탕·면·테두리·버튼·칩·게이지·탭·카드·창·토스트의 생김새, 색 토큰 값(3절 톤 안에서), 글자 크기 단계·굵기.

# 11. 산출물 (이 순서로)
1. 토큰 표: 지금 `--bha-*` 토큰 이름별 새 값(공통 + 호로 + 사신 3열), 새 토큰 제안은 따로.
2. 컴포넌트 시트(두 종족): 버튼(주·보조·위험·작은·아이콘, 초점·눌림·비활성), 칩, 탭, 제목 토글, 게이지, 체력 막대, 카드(타일·상점·아이템), 목록 줄, 창(상세·확인·고르기·ⓘ, '▼ 더 있음' 포함), 토스트, 튜토리얼 카드, 잠김 표시, 상태 칩, 스킬 블록(정사각, 속성 색·계열 모양·계열 글자, 체인 묶음), 이름표. 각각 `bha-` 클래스 이름을 붙여서.
3. 화면 장면(844×390 기기 안, 두 종족 각각): 방, 월드맵, 시장, 상점, 온천, 모험 준비 [준비]·[타일 배치], 걷기, 전투(평소·해방 중), 흡수, 바퀴 끝 창, 결과, 가방, 상태 화면, 설정. 각 장면에 기기 초점(커서)이 어디 있는지 하나씩 표시.
