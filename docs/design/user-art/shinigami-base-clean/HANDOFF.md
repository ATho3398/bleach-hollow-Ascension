# 사신·아란칼 기본형 도트 정리본 — 모션 프레임 생성툴 인수인계

> **사용자 확정 (2026-10-27, 사용자가 직접 보낸 1배 그림 두 장, 원문 "얘네 둘 각각 사신, 아란칼 기본형으로 기억하고 있어.")**
> **사신 기본형 = `shinigami-base.png`(37×81, 8색), 아란칼 기본형 = `arrancar-base.png`(37×81, 13색).** 1칸 = 1px, 바닥 줄 y=80.
> 이 두 장은 사용자 손질본이며 그대로 기준이다(재양자화·정리 금지). 아래 '정리본' 설명과 `tone1.py` 결과는 이전 단계 기록이고, 그 결과물은 `*-prev.png` 로 남겼다.

> 앞으로 사신·아란칼 캐릭터는 이 두 몸에 머리·가면·포인트만 바꿔 통일하고, 모션 프레임도 이 두 장이 기준이다.

사용자 시트(720×552, 6px 격자)를 격자 그대로 복원(120×92)한 뒤 정리했다. 사용자 평: "지금 이거 딱 좋거든" → **디자인은 바꾸지 말고 정리만** 한 것이 기준 프레임이다.

## 파일
- `shinigami-base.png` 36×80, `arrancar-base.png` 37×80 — 투명 배경 네이티브 도트(1칸=1px). 모션 프레임의 **기준(idle) 프레임**.
- `*_x6.png` 확인용 6배 / `compare_before_after.png` 전후 비교 / `palettes.json` 팔레트
- `source-native-120x92.png` 정리 전(24색) / `clean.py`·`build.py` 처리 스크립트(Pillow+numpy, `python -I`)

## 규격
- 키 80도트(레퍼런스 약 60도트보다 큼 — 게임에 넣을 때 크기 결정 필요). 왼쪽 45° 바라봄, 대기 자세.
- 색: 사신 8색, 아란칼 9색(원본 각 12색). 외곽선 단색 `#0e0a10` 하나, 안쪽 굵은 선도 같은 색. **모션 프레임도 이 팔레트 안에서만 칠할 것**(새 색 추가 금지).
- 외곽선은 얇게 만들지 않는다(사용자가 거절한 적 있음). 계단 모서리 정리만 했다.

## 한 일
1. 비슷한 색 병합(작은 면적부터), 2. 낱개로 떨어진 점 제거(주변 다수 색 흡수), 3. 외곽선 바깥쪽 L자 겹침 모서리 제거(두께는 유지), 4. 아란칼 가슴 구멍을 4×3 검은 사각형 → 지름 5 원형(반지름² ≤ 5, 중심 x16·y35)으로 교체. 칼라 선과 안 닿게 한 칸 띄움.

## 모션 프레임 만들 때 주의
- 기준 프레임에서 **같은 발 위치(바닥 y=79 줄)와 같은 외곽선 두께**를 유지. 프레임마다 팔레트 재양자화 금지.
- 아란칼 가슴 구멍은 모든 프레임에서 원형 유지(몸이 움직이면 같이 이동).
- 눈·마스크 같은 작은 부분은 자동 정리에서 지워질 수 있으니 프레임별로 눈으로 확인.
- 세부 디테일 추가(근육·머리결)는 Python으로 만들 수 없음 — 필요하면 새 시트가 필요.
- 이 정리본은 호로 쪽 규칙(격자 재도트 안 함)과 별개. 호로 그림(아란칼 36, 아쥬커스 8, skin-*)은 건드리지 않았다.
