# 종이인형 부위 시트 (GDD 96장)

- `shinigami-sheet.png`, `arrancar-sheet.png` — 1배 시트(1칸 = 1픽셀). 이걸 도트 툴에서 고친다.
- `*-sheet-x8.png` — 확인용. 바깥 회색 상자 = 부위 칸 전체, 안쪽 노란 상자 = 원래 그림 범위, 빨간 점 = 관절(돌아가는 중심).
- `*-sheet.json` — 칸 위치·원래 자리. **부위 칸 위치·크기는 바꾸지 말 것**(되돌릴 때 이 값으로 제자리를 찾는다).

## 손질할 때
- 노란 상자 밖 여백(사방 4칸)에 그려도 된다: 어깨·엉덩이·목 관절 겹침 여분, 팔이 가리던 몸통 부분 등.
- 머리(head)는 사신·아란칼 공통이라 두 시트에 같은 그림이 들어 있다. 한쪽만 고치면 그쪽이 반영된다(둘 다 고치면 나중에 되돌린 쪽이 남음).
- 다 고치면 시트 png 를 그대로 보내면 된다 → `python3 scripts/rig/sheet.py unpack <시트.png>` 로 게임 부위 파일에 되돌린다.
