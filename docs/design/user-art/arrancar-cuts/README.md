# 아란칼 그림 컷 (사용자 시트 9장, 2026-10-21, 256×256 투명, 발 기준선 아래 8%)

파일 이름 = `<속성>-<칸>.png`, 칸 번호는 시트의 읽는 순서 **1 2 / 3 4** (왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래).
칸의 뜻(프롬프트 기준): 1 = 물리형 · 2 = 특수형 · 3 = 혼합형 · 4 = 물리형 변주(덩치 큰 인물 등).

| 파일 접두 | 한국어 | 비고 |
|---|---|---|
| normal | 노멀 | `t5:normal:*` |
| water | 물 | `t5:water:*` |
| fire | 불 | `t5:fire:*` |
| earth | 흙 | `t5:earth:*` |
| thunder | 뇌 | `t5:thunder:*` |
| blood | 혈 | `t5:blood:*` (누더기·털칼라·전투복·붕대 재작성판) |
| poison | 독 | `t5:poison:*` |
| kyo | 허 | `t5:kyo:*` |
| hidden | 히든 | 1 한계 돌파 `h5:limit` · 2 절제 `h5:restraint` · 3 강적 사냥꾼 `h5:hunter` · 4 환생 `h5:reborn` |

예: `blood-3.png` = 혈 3번(혼합형), 사용자 표기 "혈3"에 해당. 가짜 투명(혈·허)은 배경을 지우고 잘랐다.
