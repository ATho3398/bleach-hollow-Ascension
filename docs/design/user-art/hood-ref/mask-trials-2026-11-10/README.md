# 길리안 가면 새 디자인 시도 (2026-11-10, 시트만 — 편집기·게임에 안 넣음)

사용자 원문: "혹시 지금 길리안 시트에서, 가면 디자인 파이썬으로 다른 디자인 만들어볼 수 있어?? 한번 시도해서 나한테 보여줘봐. 툴에 넣지 말고 시트만 먼저."

- 지금 머리 그림(hd/head.png 42×29)에서 가면(흰·분홍·붉은 눈 + 그 윤곽)을 지워 두건만 남기고(두건 안 = 검정 그늘), 같은 얼굴 자리(x 11~22, y 2~16)에 새 가면을 그림.
- 디자인 = `designs.py` 글자 판(W 흰·p 그늘·o 검정 안쪽·R 붉은 눈), 윤곽·아랫변 그늘은 `make.py` 가 저절로. 같은 색 5개(원래 도트 색)만 씀. 턱(hd/jaw)·입 속은 원래 그대로라 입 벌림도 그대로 맞음.
- 디자인: 뿔 해골(horn) · 갈고리 부리(hook) · 외눈 가면(cyclops) · 가시 늑대(wolf).
- 파일: `preview.png`(쉬는 자세 몸 전체 + 머리 6배 + 입 벌림), `heads-1x.png`·`heads-x8.png`(원래 + 4개, 1배 머리 조각), `head-<id>.png`(머리 조각 1배).
- 다시 만들기: `python3 -I make.py` (lib.py·designs.py 같은 폴더, 출력 out/).
