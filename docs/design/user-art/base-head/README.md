## 상태
- **아직 게임에 넣지 않았다.** 지금 게임의 사람형 종이인형 머리는 16×19칸(`docs/design/rig-draft/humanoid/head_bald.png`)이라 크기가 다르다. 사용자가 이 머리에 맞춘 **전신 시트를 다시 짜서 주기로 함** — 그 시트가 오면 이 머리를 기본 머리(남·여 공통)로 삼아 몸·머리 모양을 맞춘다.
- 새 도트(사신·대장·초월자)의 머리 크기 기준도 이 머리로 본다.
