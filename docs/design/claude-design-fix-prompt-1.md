# 인게임 UI 디자인 아티팩트 수정 프롬프트 1차 (UI담당자A, 2026-10-21 00:58 사용자에게 전달)

대상: 「BHA 인게임 UI」 캔버스 https://claude.ai/artifact/NLpaVnQvzC1yc9xnHznvXZ (27개 아트보드). 원칙: 게임을 디자인에 맞추지 않고 디자인이 게임에 맞춘다(사용자 "왜 ui에 맞춰"). 근거: 코드·도움말 문구와 비교(전투 블록 조작 = src/data/help/tutorial.json, 더보기 메뉴 = src/ui/roomView.ts, 붕옥 입구 = app.ts onHogyoku, 상점 = shopView.ts, 설정 = settingsView.ts, 종족 표기 = src/data/factions/*.json).

```
「BHA 인게임 UI」 캔버스를 실제 게임 기능에 맞게 고쳐 줘. 아래에 적은 곳만 고치고, 나머지 아트보드·토큰·색·레이아웃은 건드리지 마. 게임이 기준이고 디자인이 게임에 맞춘다. 지금 게임에 없는 요소는 지우고, 있는 것은 아래 내용대로 바꿔 줘. 호로판·사신판 두 버전 모두 같은 수정을 적용해 줘.

[1] 「11 전투」 + 「19 도움말·튜토리얼(19-3)」 — 블록은 자동 발동이 아니라 "눌러서 사용"이야
- 전투 아트보드 안내 문구 "순서 고정, 왼쪽부터 자동 발동"을 지우고 이렇게 바꿔 줘: "블록 바: 눌러서 사용 · 시간이 지나면 블록이 한 칸씩 생기고, 순서는 바꿀 수 없고 나온 순서대로 놓여요".
- 19-3 튜토리얼 카드의 "블록은 왼쪽부터 차례로 나가요"를 이렇게 바꿔 줘: "블록을 톡 누르면 바로 사용돼요. 같은 계열 공격 블록이 나란히 붙어 있을 때 누르면 붙은 블록이 함께 발동해 체인이 돼요. 순서는 바뀌지 않아요".
- 블록 바에서 블록 하나가 "눌림" 상태로 보이는 장면을 전투 시트에 하나 넣어 줘(붙은 같은 계열 블록 3개에 체인 표시가 같이 켜진 상태).

[2] 「02 둥지」 — 게임에 없는 요소 제거
- 왼쪽 위 이름표(진화체 이름·단계)와 오른쪽 위 골드·영옥 표시는 게임 둥지에 없으니 지워 줘. 둥지 위쪽에는 "원정 이어하기 줄"(원정 중일 때만)만 남겨. 캐릭터 머리 위 상태 칩(허기·컨디션·리스크)은 그대로.

[3] 「02 둥지 2-3」 더보기 ⋯ 메뉴 항목을 실제 순서로 고쳐 줘
위에서부터 순서대로: ① 등급전 항목(호로 "번호 쟁탈전" / 사신 "석차 도전" — 종족 표기를 따름) ② 설정 ③ 도움말 ④ 튜토리얼 ⑤ 붕옥(붕옥 탭이 열린 뒤에만 보임 — 숨김/표시 두 상태) ⑥ 사진 ⑦ 다마고치 모드 ⑧ 테스트(테스트 모드일 때만) ⑨ 백업·불러오기 ⑩ 처음 화면. 지금 시트에 있는 "백", "처" 같은 한 글자 아이콘은 그대로 써도 되지만 항목 이름은 위와 똑같이 써 줘.

[4] 「00 화면 흐름도」
- "등급전 입구: 명세에 입구 없음 … 확인 필요" 태그를 지우고, 등급전(14-1)의 입구를 "더보기 ⋯ → 번호 쟁탈전/석차 도전"으로 연결해 줘.
- 붕옥(5-H1~H5)의 입구를 "수련장 탭"이 아니라 "더보기 ⋯ → 붕옥(해금 후)"으로 고쳐 줘.

[5] 「05 수련장」·「05 붕옥」 — 붕옥은 수련장 탭이 아니야
- 수련장 머리줄(5-1, 5-2)에서 [붕옥] 탭을 지워 줘. [해방 수련] 한 화면이므로 탭 줄도 없애고, 오른쪽에는 [진화 정보] 버튼만 둬.
- 붕옥 아트보드(5-H1~H5)는 수련장 안이 아니라 독립 화면이야. 머리줄의 "‹ 수련장"을 "‹ 뒤로"(둥지로 돌아감)로, 머리 제목은 "붕옥"으로 바꾸고 [진화 정보][해방 수련][붕옥] 탭 줄은 지워 줘. 영혼 결정 보유량은 머리줄 부제로 옮겨 줘.

[6] 「10 원정 걷기」
- "배경 3겹 시차(먼 0.2·가까운 0.5·바닥 1.0)"를 "배경 2겹 시차(하늘 0.15 · 땅 1.0), 땅 띠가 화면 높이의 약 50%"로 고쳐 줘. 장면 그림 자리도 하늘+땅 2층으로 단순화해 줘.

[7] 「00 토큰 표·원칙」 + 「00 공통 컴포넌트」 입력 규칙
- "선택이 탭에 있을 때 ✓ 를 누르면 다음 탭으로 넘어간다"는 규칙을 지워 줘. 실제 규칙: 선택(하이라이트)이 탭에 있을 때 ✓ 는 그 탭을 누른 것과 같아(그 탭이 켜진다). 탭을 눌러 화면이 새로 그려져도 선택은 방금 누른 탭에 그대로 남는다.
- 위/아래로 선택을 옮기는 순서를 "화면 위 → 아래, 왼쪽 칸 → 오른쪽 칸, 탭은 맨 마지막"으로 고쳐 줘(탭은 목록 항목들 뒤에 선택돼).

[8] 「07 상점」 — 레이아웃이 달라
- 왼쪽 "분류 칸 1 : 품목 줄 3" 구조를 지워 줘. 실제는 왼쪽 칸 : 오른쪽 칸 = 1 : 1, 머리줄에 가진 골드·영옥 + [골드][영옥] 탭이 있어.
- 골드 탭: 왼쪽 칸 = 먹이 5종, 오른쪽 칸 = 소모품·편의·덱 칸(정화제, 각성제, 수련권, 희귀 타일 꾸러미, 다시 뽑기권, 타일 덱 칸 +1). "희귀 타일 꾸러미" 줄이 지금 빠져 있으니 추가해 줘.
- 영옥 탭: 분류 제목이 붙은 묶음을 양쪽 칸에 나눠 놓아. 묶음 제목 줄 = 분류 이름 + 작은 글씨 "기본" 또는 "착용 중 · [해제]로 기본". 분류는 스킨 · 오라 · 색조 · 발밑·잔상 · 공격 이펙트 색 · 블록 바 · 이름표 테 · 등장 연출 · 진화 연출 · 흡수 연출 · 컷인 띠 · 승리 연출 · 말풍선 팩 · 키링 · 기기 디자인(그림 있는 것만). 이 중 일부 묶음만 보여도 되지만 이름은 위와 똑같이.
- 이 종족이 입을 스킨이 없으면 스킨 묶음 안에 "○○이(가) 입을 수 있는 스킨은 아직 없다." 한 줄(호로/사신 종족 이름)이 나와.

[9] 「20 사진 · 21 다마고치 모드」
- 21-1 기기 디자인 목록은 "가진 디자인 + 기본형"만 나와. "[디자인 B] 상점 영옥 20" 같은 못 가진 줄을 지워 줘. 목록은 이 3줄: 기본형 / 사신대행증(기본 제공 · 착용 중 표시) / 십일번대(기본 제공). 기기 디자인은 상점 영옥 탭의 "기기 디자인" 묶음에서도 사.
- 하단 3버튼 줄은 [뒤집기] [디자인] [화면 확대] 그대로 둬.

[10] 「18 설정·백업」
- 설정에서 [배경 확인] 줄을 지워 줘(게임에 없음). 화면 확대(맞춤·1.25·1.5)는 "PC에서만 적용" 작은 글씨를 붙여 줘(폰에서는 안 보여). 전투 효과(피해 숫자·진동·효과음·화면 흔들림)와 음악(켬/끔·음량 단계)은 그대로.
- 백업은 설정의 탭이 아니라 더보기 ⋯ 의 "백업·불러오기" 항목에서 들어와. 설정 머리줄의 [설정][백업] 탭 줄을 지우고, 백업 화면(18-2) 머리줄 뒤로는 둥지로 가게 해 줘.

[11] 「22 테스트 모드 패널」
- 탭은 6개가 아니라 5개야: 진화체 · 능력치 · 특성 · 바로 전투 · 둥지·속도("둥지·속도"가 탭 하나).

[12] 「03 상태」 — 실제 내용을 더해 줘
- 머리줄 부제에 "사냥터 ○○ · 원정 n회 · 귀환 n"을 추가해 줘.
- 능력치 칸 아래에 "치명 n% · 치명 피해 ×n" 한 줄과(붕옥을 해방했으면) 보유 보너스 한 줄("전 능력치 +5%")을 넣어 줘.
- 지난 원정에서 졌으면 상태 칸 위에 경고 박스 한 줄: 종족 패배 상태 이름(호로 "가면이 깨져 쇠약" / 사신 "영력 고갈") + "(재우기)로 회복한다". 두 상태(평소 / 패배 후)를 보여 줘.
- 능력치 6종 이름은 체력·힘·지능·방어·정신력·속도 그대로 써.

[끝으로]
- 위 [1]~[12]를 고친 뒤, 바뀐 아트보드 이름을 한 줄씩 정리해서 알려 줘. 안 고친 곳은 건드리지 않았다는 말도 같이.
```

확인하지 못한 곳(프롬프트에서 뺌): 흡수 12-1 "‹ 뒤로 = 놓아주기" 동작, 토스트 겹침·지속 시간, 색·간격 등 시각 값의 토큰 일치.
