00

방향 · 호로 / 사신 비교

같은 HTML, 같은 클래스. 루트 속성만 다릅니다. 호로는 뼈백색 판과 크림슨, 둥근 모서리와 굵은 선, 균열 질감. 사신은 은청색 판, 반듯한 모서리와 가는 선, 마름모 격자 질감. 종족 이름(둥지/대원실, 자아/영압 안정도, 광기/호로화 등)은 종족 설정에서 오는 값입니다.

05

게임 전용 컴포넌트

블록 · 블록 바 · 저장 필살기 · 원형 길 · 타일 칩. 블록을 눌러 보면 발동 이펙트가 나옵니다.

블록 — 종류 × 체인 단계 × 상태.bha-block --attack|--guard|--heal|--basic|--special|--void

역할은 색 + 아이콘 + 표면 무늬(공격=사선, 막기=가로 판, 회복=점)로 구분. 위쪽 점 ●○○ / ●●○ / ●●●은 체인 단계(is-chain2, is-chain3). 약점 계통은 금색 안테두리 + 오른쪽 위 금빛 모서리(is-weak).

HTML 보기
<div class="bha-block bha-block--attack is-chain2 is-weak">
  <span class="bha-block__pips"><i></i><i></i><i></i></span>
  <span class="bha-block__icon"><svg class="bha-icon"><use href="#i-attack"/></svg></span>
  <b class="bha-block__abbr">찢는 발톱</b>        ← 특성 이름 약어 (최대 2줄)
  <span class="bha-block__weak"><svg class="bha-icon"><use href="#i-weak"/></svg></span>
</div>
상태 클래스: is-weak · is-pressed · is-dragging(--drag-x/--drag-y) · is-nudge-l/r · is-held · is-sealed · is-disabled · is-popin · is-fire
아이콘: attack=i-attack · guard=i-guard · heal=i-heal · basic=i-basic · special=i-special · void=i-void
블록 바 (8칸) — 묶음 표시.bha-tray

묶음 = 노란 테두리 + 아래 연결선 + 위 꼬리표 "체인2". 체인3은 주황, 더 강한 글로우. JS는 묶음마다 --start(시작 칸 1~8)와 --len만 넣습니다. 칸 = 바 폭 ÷ 8 (360px 화면에서 44px), 높이 68px.

블록 바 — 드래그 · 봉인 · 일시정지 · 들었다 놓음.bha-tray.is-*
드래그 중: 블록은 28px 위로 떠서 손가락을 따라감, 파란 삽입 막대, 옆 블록은 살짝 밀림
봉인 (생성 정지): 보라 잠금 오버레이
일시정지: 바 흐림
오래 누름(0.3초 초과): 사용 안 됨 + 회색 안내

들었다 놓았다 — 사용하지 않음

저장형 필살기 버튼.bha-stored
충전 0 (비활성) 충전 1 (준비됨 · 글로우) 충전 3 (가득)
원형 길 (12칸) · 타일 칩.bha-ring · .bha-tilechip

칸·슬롯·표식 위치는 CSS가 각도로 계산합니다. JS는 칸/슬롯에 --i, 표식과 링에 --pos(현재 칸, 소수 가능)만 넣습니다. 놓을 수 있는 슬롯은 is-can(파란 맥동).
