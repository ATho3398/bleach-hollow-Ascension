# 혈쇄 이치고 — 사슬 이펙트 (도트 세션 작업본, 사용자 확인 2026-11-16 "좋다 이정도면 충분")

몸에 그려져 있던 붉은 촉수(사슬)를 전부 지우고, 사슬을 **이펙트로만** 그린다. 자리는 목 · 두 손목 · 두 발목 다섯 군데뿐이다(팔의 것은 없앰).

## 파일
- `body.png` — 붉은 촉수를 지운 옛 몸 그림 1배(61×111). **사용자가 2026-11-16 에 새 조각 시트를 줬다 — 몸은 그 시트를 쓴다**(이 파일은 이펙트 위치 참고용).
- `back/back-01..16.png` — 몸 뒤 레이어(풀린 끝 + 날아가는 조각 + 빛무리). 칸 97×121, 몸은 (18,10). 프레임당 120ms.
- `front/front-01..16.png` — 몸 앞 레이어(목·손목·발목에 두른 사슬 띠와 그 빛무리).
- `chain.py` — 위 PNG 를 만든 계산식. `chain-ichigo*_x4.gif` 확인용.

## 이펙트 구성 (`chain.py`)
- 사슬 띠(몸 앞): 꺾은선을 따라 반지름 1.25칸. 고리 무늬 = 거리 2.2칸마다 붉은색 `#ac313b` / 어두운 붉은색 `#5f141e` 교대. 달아오른 점이 띠를 따라 흐른다(sin(2π(거리/9 − t/16)) > 0.45 주황 `#ec6e3c`, > 0.88 밝은 노랑 `#ffbe5a`).
- 풀린 끝(몸 뒤): 띠마다 한 줄기, 길이 5~6칸, **검정 외곽선 없음**, 위아래로 크게 흔들지 않는다(목은 흔들림 0.25배). 끝 절반은 고리가 끊어지고 주황 → 밝은 노랑.
- 날아가는 조각: 끝마다 6개가 차례로 떨어져 바깥 위쪽으로 흔들리며 날아가고 11프레임에 걸쳐 식는다(노랑 → 주황 → 붉은색, 뒤로 갈수록 반투명).
- 빛무리: 사슬·조각 둘레 1칸과 2~3칸에 반투명 붉은 빛 `#e1282d`(알파가 16프레임에 한 번 맥박).
- 옛 몸 그림 좌표의 자리: 목 띠 (28,40)→(31,41)→(34,41)→(37,40), 풀린 끝은 (37,40)에서 오른쪽(등 쪽) 한쪽으로만. 왼손목 (13,62)→(16,64)→(20,63), 오른손목 (45,62)→(48,64)→(51,62), 왼발목 (19,100)→(24,102)→(29,100), 오른발목 (37,100)→(41,102)→(45,100).

## 종이인형에 붙일 때
- 띠는 조각에 붙인다: 목 = 머리와 몸통 사이(목 폭에만), 손목 = 아래팔 끝, 발목 = 정강이 끝. 풀린 끝과 조각은 그 띠의 한쪽 끝에서 나온다.
- 눈·머리카락에는 빛을 넣지 않는다(사용자 지시).
