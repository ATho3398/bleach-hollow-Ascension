# 초월자 '태초'(zero-sage) 모델 그림 — 검은 구슬 + 흰 후광

사용자 2026-11-12 19:0x: "이거 캐릭터거든? 초월자 태초 모델이니까 마스터한테 넘겨서 일단 태초 모델로 넣어"

| 파일 | 내용 |
|---|---|
| `orb_black_64.png` | 몸 = 광택 없는 완전한 검정 구슬 64×64 (투명 배경, 1배) |
| `aura-01.png` ~ `aura-32.png` | 후광 32프레임, 128×128 (투명, 1배). 구슬은 빠져 있고 **구슬을 (32, 32)에 얹으면 딱 맞는다** |
| `aura-sheet.png` | 후광 32프레임 가로 시트 4096×128 |
| `with-orb_x3.gif` | 미리보기 (구슬 + 후광, 3배, 어두운 바탕) |
| `holy.py` | 생성 스크립트 (PIL). 길이·속도·빛줄기 수는 맨 위 상수 |

- 재생: 32프레임, 프레임당 100ms(한 바퀴 약 3.2초), 이음매 없이 반복.
- 후광은 빛 효과라 **실제 반투명(알파 8단계 + 디더)** — 배경 위에 그대로 겹치면 된다. `image-rendering: pixelated`.
- 사용자 확정 사항: 구슬에 광택 없음(공허 같은 검정) · 불꽃이 아니라 성스러운 후광 · 빛줄기는 폭이 일정하고 끝이 뾰족하지 않게 서서히 사라짐 · 퍼지는 넓이는 지금 크기(처음의 절반).
- 게임 연결(그림 키·크기·위치)은 아직 안 했다 — 이 폴더는 원본 보관용.
