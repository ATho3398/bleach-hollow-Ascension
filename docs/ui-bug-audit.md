## 남은 것 · 한계

- 세로 회전은 주요 흐름(방·설정·가방·원정 출발·빈사·전투·소모품 전투·결과·상태·테스트 패널)만 돌렸다 — 기기 화면이 통째로 도는 구조라 안쪽 배치는 가로와 같고, 다른 것은 화면 좌표로 자리를 재는 코드뿐. 새 코드가 `getBoundingClientRect` 로 자리를 잴 때는 `elementLocalRect`(src/ui/bha/viewport.ts)를 쓴다.
- 전투 상태 흔들기는 글자·클래스를 직접 넣어 본다(엔진 상태는 안 건드림). 실제 경직·해방은 15초 관찰·소모품 전투 관찰로만.
- 1차 남은 것(결과 화면·세로 회전·긴 이름·소모품 전투·전투 상태 칩)은 2차에서 모두 다룸.
