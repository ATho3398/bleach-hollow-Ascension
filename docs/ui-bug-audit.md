# UI 코딩 에러 전수 검수 (GDD 110장 2, C.182)

- 검사: `npm run ui-audit` (`scripts/ui-audit/` — Playwright, 가로 844×390 1배, 테스트 모드 `?test=1`, 두 종족). CI 에는 안 넣는다.
  - 옵션: `UI_AUDIT_URL`(이미 뜬 주소, 없으면 vite 를 띄움) · `UI_AUDIT_ONLY=<화면 이름 일부>` · `UI_AUDIT_FACTION=0`(호로만) · `UI_AUDIT_SHOTS=<폴더>`(화면마다 캡처) · `UI_AUDIT_OUT=<json>` · `UI_AUDIT_DUMP=1`(버튼 목록) · `UI_AUDIT_DEBUG=1`.
- 도는 화면: 시작(설정 4탭·슬롯·종족) · 방(ⓘ·더보기·먹이 줄·돌보기) · 설정(방, 4탭 × 토글 전부 — 음악 목록 포함/뺌) · 상태(ⓘ 5개·스킨) · 가방 5탭(장비 칸·카드 고르기) · 상점 · 책장(두 도감) · 수련장(세 보기) · 원정 출발(지역·난이도·타일 고르기·놓기·프리셋·손패, 스토리·탑 보기) · 원정 걷기 · 테스트 패널(8보기) · 도움말 · 사진 · 방 빈사·사망(테스트 값 0·+48시간) · 포식 3단계·둥지 도착·귀환 확인·귀환 결과 창 · 전투(15초 관찰·숫자 칸 바꿈·로그·일시정지) · 슬롯 지우기.
- 점검: ① 상태 바꾸기(탭·토글·체크·선택·삭제·ⓘ 열기·보기 전환) 전후 버튼 bounding box — 다른 버튼이 1.5px 넘게 움직이면 에러(크기가 바뀐 원인 요소도 적음) ② 시간 흐름(전투) 중 버튼 이동 ③ 버튼·글자 잘림(조상 overflow·LCD 밖, 스크롤로 닿는 것 제외, 0.6초 뒤에도 남는 것만) ④ 버튼끼리 겹침 ⑤ 가려진 버튼(지금 고를 수 있는 칸만) ⑥ 가로 스크롤 ⑦ ▼ 를 돌려 닿지 않는 버튼·버튼이 아닌 누름 칸(목록-상세는 '고른 행 ✓ → 상세' 길 확인).

## 남은 것 · 한계 (2차에서 이어서)

- 원정 결과 화면(`.bha-resultpage`, 완주·패배)은 검수 흐름이 닿지 않음 — 이번엔 귀환 확인 창·귀환 결과 창까지 점검. 2차에 패배·완주 흐름 추가.
- 세로 폰 회전 출력(LCD 90° 회전)은 안 돔 — 가로 844×390 기준만.
- '긴 이름'은 프리셋 이름 바꾸기로 2차에 추가(지금 화면들의 긴 글자는 말줄임·줄바꿈 점검으로만 봄).
- 소모품·발동 장비를 실제로 낀 전투는 글자 넣기로 대신 확인(엔진 상태는 건드리지 않음).
- (마스터 지시 18:22Z, 1차에서 못 다룸) 전투 상태 칩('공허 1회 ⓘ' 등)이 생기고 없어질 때 범례 줄 오른쪽 [막기][소모품][장비][영력 해방] 줄이 움직이는지 — 칩 자리를 버튼 줄과 분리하거나 고정. 게이지 참/빔·소모품 0/n·장비 쿨·해방·경직·칩 생김 전후 비교를 `screens.cjs` 전투 흐름에 추가하고, 고친 전투 버튼 줄 캡처 1장(c177/01·03·04 비교 기준).
- 2차는 새 세션에서(코딩128 컨텍스트 30만 넘김). 시작: `npm i` 후 `npm run ui-audit`(전체 약 30분, `UI_AUDIT_ONLY=전투 UI_AUDIT_FACTION=0` 로 좁혀 돌림).
