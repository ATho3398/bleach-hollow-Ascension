# R198 — 노력치 흡수 '안 됨' 표시 조사 (GDD 186장 2, 코딩198, 조사만 — 코드 안 고침)

사용자 원문: "-노력치 흡수 왜 안되게 뜨는지 파악해서 보고"

## 사용자가 본 화면 ('안 됨')
흡수 화면에서 **[능력치 흡수/포식] 버튼이 흐려짐** + 설명 칸 빨간 줄 **"노력치가 가득 찼다. 능력치는 오르지 않는다."**
(`src/ui/absorbView.ts` `evCapped` → `EV_FULL_TEXT`, 버튼 `aria-disabled`). [포식/정화 흡수]를 골라도 같은 빨간 줄.

## 원인 (두 가지, 둘 다 버그 아닌 규칙대로 — 단 2번은 표시가 헷갈림)
1. **합계 상한 36 이 진짜로 금방 참** — 튜토리얼 보상이 6종 각 +3 = 18 (상한의 절반). 남은 18 은
   '능력치 흡수'(×2, 한 번 4) **4~5번**, '둘 다'(한 번 2) **9번**이면 끝. 1바퀴 = 전투 약 2번이라 원정 2~3번이면 가득.
   진화(1→2단계)는 걸음 40 필요 → 진화 전에 가득 찬 채로 한참 흡수하게 됨.
2. **능력치 하나 상한 18 에 먼저 닿음 (합계는 남았는데 '가득')** — 초반 적(일반형)은 노력치를 힘 또는 지능 한 가지로만 준다.
   '능력치 흡수' 4번이면 힘 3→7→11→15→18. 이때 합계 33/36 인데 힘만 주는 적이면 흡수 화면은 **"노력치가 가득 찼다"**,
   상태 화면은 **"노력치 33 / 36"** — 서로 어긋나 보여 "아직 남았는데 왜 안 돼?"가 된다. 문구가 '합계 가득'과 '그 능력치만 가득'을 구분하지 않음.

## 확인한 것
| 경우 | 결과 |
|---|---|
| 새 게임 → 튜토리얼 실제 진행(Playwright, 기기 ✓) | 노력치 6종 각 3 = 18 (호로·사신 같음) |
| 흡수 반복(엔진 시뮬, 두 종족) | '능력치 흡수' 6번째부터 가득 · '둘 다' 10번째부터 가득 |
| 능력치 하나 18 (힘만 주는 적) | 합계 33/36 인데 '가득' — 재현됨 (캡처 perstat) |
| 2·3·4단계 | 같은 구조(상한 44·70·88, 하나 22·35·44). 진화하면 상한이 올라 다시 받음 |
| 진화 직후 | 노력치 유지·상한만 오름 → 문제 없음 |
| 부활(사망 후) | 1단계로 내려가며 노력치 50~70% 유지 → 2·3단계였으면 바로 1단계 상한 근처/초과일 수 있음(시뮬: 3단계 노력치 66, 교감 낮음 손실 50% → 30/36) |
| 환생 | 노력치 0 + 계승분(carry, 상한 밖) → 문제 없음 |
| 옛 세이브(C.280 전) | 상한은 실행 중 계산이라 불러오면 36 적용, 변환 필요 없음 |
| 배포 | 지금 사이트 = C.282, evCapTotal [36,44,70,88] 확인. C.280 배포 04:48, 사용자 말 15:5x — 옛 캐시(24) 가능성은 낮음(새 버전 띠를 안 눌렀다면 가능) |
| 표시-판정 어긋남(다른 원인) | 없음. 빈사(×0.5)·허우적(×0.25)은 양만 줄고 '가득' 오판 없음 |

## 고치는 방법 추천 (마스터 결정)
- **A. 표시만 (수치 그대로, 추천)**: 흡수 화면 문구를 나눈다 — 합계 가득이면 "노력치가 가득 찼다 (36/36)",
  그 능력치만 가득이면 "힘은 이 단계 상한(18)이라 오르지 않는다 — 다른 능력치 적은 받는다". 상태 화면 능력치 옆에 노력치 n/18 표시.
- **B. 수치 (provisional)**: 튜토리얼 18 을 상한 계산에서 빼거나(따로 칸) 1단계 합계 상한 더 올리기, 능력치 하나 비율 0.5 → 0.7 등.
  밸런스 점검 필요(C.280 때 바퀴 곡선 가드).
