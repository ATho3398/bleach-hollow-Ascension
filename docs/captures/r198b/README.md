# R198b — '첫 바퀴부터 능력치 흡수가 안 됨' 후속 조사 (코딩198, 조사만 — 코드 안 고침)

사용자 원문: "첫바퀴부터 능력치 흡수는 왜 안되는건지 설명해" · 사용자 상태 화면 `docs/drafts/user/1104-status-cut.jpg`
(호로, 웨코문도 모험 4·귀환 4, 노력치 체력 3·힘 7·나머지 3 = 합 22, 1단계 상한 36·하나 18 → 여유 있음)

## 실제 재현 (현재 main = C.296, Playwright, 새 게임 → 튜토리얼 기기 ✓ 진행 → 첫 모험 ★1 첫 바퀴 첫 전투 흡수)
| 종족 | 튜토리얼 뒤 | 첫 적 | [능력치 포식/흡수] | 설명 칸 |
|---|---|---|---|---|
| 호로 | 6종 각 3 (합 18) | 흙 일반 1 (earth-basic, 노력치 표 힘 2) | **흐리지 않음** | 능력치 힘 +4 · 광기 +1 (0 → 1) |
| 사신 | 6종 각 3 (합 18) | 물 일반 1 (water-basic, 노력치 표 지능 2) | **흐리지 않음** | 능력치 지능 +4 · 호로화 +1 (0 → 1) |
기본(첫 갈래 고른 상태) 화면도 네 갈래 모두 보통 모양(`shinigami-2-first-absorb-default.png`).
→ **'첫 바퀴부터 흐림/가득' 은 재현되지 않음.**

## 코드 점검 (흐림 조건 = absorbView `evCapped`: 능력치 갈래인데 previewAbsorb 노력치가 0)
- 적 53종 전부 노력치 표가 있음(0 인 적 없음). 1바퀴 풀 = basic·heavy-seal.
- 배율: ★ 보상 배율 ≥ 1, 빈사 ×0.5, 이어하기 ×(1+0.25×(바퀴−1)), 허우적 ×0.25 — 0 이 되는 경우 없음(반올림 0 도 없음: 최소 0.5).
- 튜토리얼 흡수 연습 화면도 어느 갈래든 6종 +3 미리보기 → 흐림 없음.
- 귀환 때 원정 노력치 → 세이브 복사 정상(game.ts applyExpeditionEnd).
- 사용자 노력치 22 상태에 대입해도 상한(합 36·하나 18)에 안 닿음 → 이 상태에서 '가득' 이 뜰 길이 코드상 없음.

## 사용자가 본 것일 가능성
1. 노력치 22 = 튜토리얼 18 + 4 → 모험 4번에 노력치를 준 흡수가 한 번(능력치 포식 1번 또는 포식 2번) 뿐. 슬롯 빈칸 3(1104-walk-cut)이라 블록도 안 받음
   → 대부분 **놓아주기·속성 포식**을 골랐거나 흡수 화면 전에 귀환. 그러면 "능력치가 안 오른다" 로 느낄 수 있음(화면 문제 아님).
2. 상태 화면 큰 숫자(53)는 그대로고 옆 +n 만 오르므로 "능력치 흡수가 반영 안 된다" 로 보였을 가능성.
3. 그 외(흐림 화면 자체)는 사용자 흡수 화면 캡처가 있어야 판정 가능.

## 추천
- **사용자에게 흡수 화면 캡처 1장 요청**(흐린 버튼·빨간 줄이 보이는 순간) — 그게 없으면 원인 단정 불가.
- 화면 쪽 작은 개선(선택): 흡수 결과 한 줄에 '노력치 22 → 26 / 36' 처럼 합계·상한을 같이 보여 주면 "오르는지" 가 바로 보임(R198 추천 A 와 같이).
