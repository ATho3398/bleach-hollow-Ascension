# R213 — 노력치 흐림([능력치 포식] 버튼) 사용자 상태 재현 (GDD 190장 1, 코딩213 · 조사만 — 게임 코드 안 고침)

사용자 원문: "첫바퀴부터 능력치 흡수는 왜 안되는건지 설명해" → 마스터 질문에 "1번임"(흡수 화면 [능력치 포식] 버튼이 흐려 못 누름).
사용자 상태(`docs/drafts/user/1104-status-cut.jpg`): 호로 · 웨코문도 · 모험 4(튜토리얼 1 포함) · 귀환 4 · 패배 0 · 노력치 체력·지능·방어·정신력·속도 +3 · 힘 +7(합 22) · 블록 슬롯 0/3.

## 결론
**재현 안 됨.** 지금 코드(main C.300, 배포 C.302 — `evCapTotal [36,44,70,88]` 같음)에서는 사용자 상태(합 22 · 힘 7 · 1단계 상한 합 36·하나 18)로
[능력치 포식]이 흐려지는 길이 없다. 흐림(`absorbView.evCapped`)은 엔진 `previewAbsorb` = 상태 복제본에 실제 `chooseAbsorb` 를 돌린 차이라
**흐림 판정과 실제 지급은 이미 같은 계산**이다(아래 테스트로 고정). 원인이 확인되지 않아 게임 코드는 바꾸지 않았다.

## '4번 다녀와 슬롯 0/3 · 노력치 +4 뿐' 설명 (추정)
- 모험 4 중 1번은 튜토리얼(보상 = 6종 +3). 진짜 원정은 3번.
- 시뮬에선 원정 1번에 흡수 기회가 약 2번(1바퀴 전투 2번). 3원정이면 약 6번인데 노력치는 힘 +4(능력치 포식 1번 분량)뿐 → 나머지 흡수는 **놓아주기**였거나, 흡수 화면 전에 원정이 끝났거나(귀환), **중간 저장 원정이 버려진** 경우(밸런스 버전이 바뀐 배포 뒤 이어하기 = 원정 통째로 사라지고 기록도 안 남음, `restoreExpedition` 'version') 중 하나.
- 슬롯 0/3: 블록을 얻는 갈래(포식·속성 포식)를 고르지 않았거나, 노멀 적(가진 속성 = 강화만, 새 블록 없음)이었으면 슬롯이 안 찬다.
- **확정하려면 사용자 세이브 백업 글(설정 → 백업)** 한 개면 된다: 런 로그 `absorbs`(갈래·노력치)·`runs`·`battles` 에 그 4번이 그대로 남아 있다(9장).
