> 사용자 원문(2026-10-28): "그리고 상태 설명 추가된건 좋은데 상태별 설명 문구 말투가 다달라. 말투 통일시켜. 아예 모든 설명관련된건 말투랑 서식같은거 좀 통일시켜;"
>
> 새 설명 문구를 쓸 때 이 문서를 따른다. 테스트 `tests/c185.test.ts` 가 규칙 일부를 지킨다.

## 1. 대상

- **대상**: 상태 ⓘ 창 · 도움말(화면 요약·용어 사전) · 한 번 뜨는 안내·튜토리얼 · 특성/블록/아이템/장비/타일/펫 설명(데이터 json 포함) · 포식 화면 안내 · 설정 설명 · 잠김 이유 · 확인 창 본문 · 테스트 패널 안내 · 종족 설정(json) 설명 문구.
- **대상 아님**: 캐릭터 대사(말풍선·방 혼잣말·스토리·컷인), 버튼 이름, 짧은 라벨(칩 이름·'비어 있음'·'없음' 같은 값), 전투 기록·외침(“강공격 예고!”), 사냥터·초월체 분위기 글(flavor).

## 2. 말투

- 평서 **'~다' 체 하나**. 예: "먹이를 주면 오른다."
- 쓰지 않는다: '~요'체(“~해요”), '~습니다'체, '~함/~됨/~음' 명사형 끝(“저장됨”), 명령·청유(“~하세요”, “~해 두자”), 물음(“~할까요?”).
- 문장은 짧게, 주어 '나/내 캐릭터'는 생략한다.
- **마침표**: 여러 문장이 될 수 있는 본문(도움말·안내·특성 설명·확인 창 본문)은 문장마다 `.` 를 찍는다. 한 줄짜리 줄(ⓘ 창의 요약·줄, 잠김 이유, 토스트 제목, 카드 한 줄)과 수치 줄에는 찍지 않는다.
- 안내·튜토리얼(guides·tutorial json)은 **한 줄에 한 문장**(C.126 규칙 그대로), 튜토리얼 본문은 2줄 이내.

## 3. 수치 줄

- `조건: 효과` 한 줄씩. 효과가 여럿이면 ` · ` 로 잇는다. 예: `광기 100: 폭주(원정당 1번) · 주는 피해 +30% · 받는 피해 +60%`
- 숫자 표기: `+n%` · `−n%`(빼기 기호 **−** U+2212, 하이픈 아님) · `+n%p`(확률 가산) · `n초` · `n회` · `n/100` · 배수 `×n` · 범위 `0~24`.
- 효과 칸에는 명사구도 된다(“회복약 사용 불가”). 단 '~함/~됨/~음'으로 끝나는 동사 명사형은 쓰지 않는다(“멈춤” → “정지”, “되돌림” → “반사”).
- 헬퍼: `src/data/help/textFormat.ts` — `numLine(조건, ...효과)` · `signed(n)` · `pctDelta(0.2)` · `multPct(1.3)` · `times(m)` · `range(a, b)` · `zonesBy(0, 100, 값→문구)`(같은 손해가 이어지는 값끼리 구간) · `zoneLine` · `MINUS` · `SECTION`(소제목 이름).

## 4. 창 구조

제목(명사) → 한 줄 요약('~다') → 소제목(명사) 아래 수치 줄. 같은 종류 창은 소제목 이름·순서가 같다(`SECTION`).

| 창 종류 | 소제목 순서 | 어디 |
|---|---|---|
| 수치 상태 ⓘ (배부름·컨디션·영압 안정도·광기·교감) | 하는 일 → 구간별 손해 → 오르내림 | `src/ui/bha/statusInfo.ts` (방 칩·상태 화면·전투 광기 칩) |
| 상태 이상 ⓘ (쇠약·피곤·빈사·사망) | (손해) → 풀리는 법 | 같은 곳 (상태 화면 줄·방 칩) |
| 전투 칩 ⓘ (공허 블록·체인3·폭주) | 하는 일 | `src/ui/battleView.ts` |
| 방 상태 ⓘ (칩 전부 한 창) | 칩마다 한 묶음(구간별 손해 줄 / 손해·풀리는 법 줄) | `roomStatusInfo` |
| 도움말 용어 광기·영압 안정도 | 요약 → **하는 일** → **구간별 손해** → **오르내림** (ⓘ 창과 같은 줄) | `glossary.json` + `helpVars` |

- '구간별 손해'는 0~상한을 빈틈없이 덮고 지금 값이 든 줄에 ◀ 가 붙는다. 문턱은 BALANCE 값에서 만든다(숫자 하드코딩 없음).
- 확인 창: 제목은 명사(“지금 귀환”, “슬롯 2 덮어쓰기”, “합체 최종 확인”), 본문은 '~다.' 문장.

## 5. 용어

- 기획서 표기를 따른다. 사용자 표기 '영압 안정도'·'빈사'·'폭주'·'레스렉시온' 유지(옛 표기로 되돌리지 않는다).
- 종족마다 다른 이름(광기/호로화, 먹이 주기/식사 / 영력 보급, 교감/참백도 손질 등)은 faction json 에서 읽는다. 조사는 `이(가)`·`(으)로` 로 쓰고 `fixParticles` 가 고친다.
- 뜻(수치·규칙)은 바꾸지 않는다.
