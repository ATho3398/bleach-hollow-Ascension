# depixel — AI 도트풍 그림 → 진짜 도트 PNG

```
python3 scripts/depixel/depixel.py 그림.png [그림2.png ...] [--split] [--cell 14.8] [--out 폴더]
```
- 색이 바뀌는 위치의 반복 간격으로 칸 크기·시작 위치를 가로·세로 따로 찾고, 칸마다 가운데 부분의 중간값 색 하나를 뽑는다.
- 출력 `<out>/<이름>/`: `<이름>-dot.png`(1칸=1픽셀, 도트 툴에서 바로 편집), `<이름>-x8.png`(확인용), `--split` 이면 떨어진 캐릭터마다 `<이름>-<번호>.png`.
- "맞음" 값이 낮으면(0.3 이하) 격자가 흐린 것 — 결과를 확인하고, 틀리면 `--cell` 로 칸 크기를 직접 준다.
- 이미 256으로 줄인 그림보다 **AI가 처음 만든 큰 원본**에 돌려야 깨끗하다.
