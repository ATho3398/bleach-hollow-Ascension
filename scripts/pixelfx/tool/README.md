## 치는 쪽 캐릭터 (02:5x "종이인형 세션에서 캐릭터 도트랑 모션 가져와서 구현할 수 있게 수정(아란칼 남, 녀, 사신 남, 녀, 호로 각 하나씩만 있으면 됨) 맞는 쪽은 필요 없음")

- `characters.ts`: 아란칼 남·여(arrancar-base / -f), 사신 남·여(shinigami-base / -f) = 게임 종이인형(`bindAnim` → `bindRigAnim`, humanoid.json·motions.json), 호로 = 게임 프레임 애니 `char.hollow.2`(공격 동작이 있는 단계).
- 무대 배경은 내 캐릭터를 숨긴 캡처(`C268_BG=1 C268_NOHERO=1`), 캐릭터는 게임 자리(기본 상자 150 × fieldScale, 기준점 (587, 216))에 얹는다. 맞는 쪽은 캡처 그대로.
- 첫 타격(0ms)마다 게임처럼 블록 공격 = 특수 동작(종이인형은 계열 몸동작 `families[].motion` 묶음), 타격 프레임부터(`fromHit`). 특수 동작이 없는 그림(호로)은 공격 동작으로 미리 본다.
- 묶기: 게임 코드가 vite `import.meta.glob` 을 써서 build.mjs 가 vite 로 묶는다(`__ART_FILES__`·`__ART_ANIMS__` 는 vite.config 와 같은 규칙). 캐릭터 그림 70장은 data URI 로 싣고 `<img>.src` 상대 주소를 바꿔 끼운다.

## 블록마다 몸동작 (03:1x "각 블록당 종이인형 모션도 설정할 수 있게 연동시키고, 종이인형에 새로운 공격모션 추가되면 여기도 자동으로 업데이트되게 시켜. 원하는 모션 원하는 타이밍에 발현할 수 잇게")

- 블록 값 `body`('' = 게임 기본: 첫 타격에 계열 몸동작을 타격 프레임부터) · `bodyAt`(ms, 첫 타격 = 0, 시전 속도로 나눔) · `bodyFromHit`. [타격 프레임을 첫 타격에 맞추기] = 동작을 처음부터, 그 동작의 타격 프레임(motions.json hit)이 0ms 에 오도록 `bodyAt = -hit`.
- 목록 = 게임 `src/data/art/rig/motions.json` 의 동작 전부(이름표 없는 새 동작은 '새 동작 (id)'), 프레임 그림 캐릭터(호로)는 그 그림의 동작. **종이인형 세션이 새 동작을 게임 데이터에 넣으면 도구를 다시 만들어 올리면(build.mjs) 저절로 목록에 들어간다** — 아티팩트는 저장소를 직접 못 읽어 다시 올리는 것까지는 이쪽이 한다.
- 게임 쪽: `PlayOptions.motionId`(src/ui/bha/animPlayer.ts) — 종이인형 재생기가 그 동작 id 를 그대로 튼다(없는 id 면 예전 그대로). 테스트 tests/fxtool-motion.test.ts.
- 블록당 이펙트 최대 5개(03:1x "블록당 이펙트 5개로 늘리자").
